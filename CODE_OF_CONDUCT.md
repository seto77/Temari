# Code of Conduct

This is a small scientific-software project. The expectations are short.

## Expected behaviour

- Be respectful. Disagree with the argument, not with the person.
- Be specific. In a project about numerical reproducibility, "this is wrong" is
  not a report; a command line, a version and an output are.
- Assume competence and good faith. Contributors come from physics, microscopy
  and software backgrounds and will not share the same vocabulary.
- Respect the licensing boundaries described in
  [CONTRIBUTING.md](CONTRIBUTING.md): do not post data copied from published
  tables or from restrictively licensed codes.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory remarks, deliberate disruption, and
publishing others' private information.

## Enforcement

Report problems privately to the maintainer ([@seto77](https://github.com/seto77)).
Reports are handled confidentially. The maintainer may edit, hide or delete
comments, and may block accounts, at their discretion.

This document is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/), shortened to fit
a project of this size.
