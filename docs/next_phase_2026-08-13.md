#### ★★★ 外部参照ゼロの決着 — **T11b（組み立ては白）**

作者指示（2026-08-13）「**外部参照に一切頼らない検証は二重に価値がある**」に対する回答。

水素 1s → 連続の GOS は **(q, ω) 全面で閉形式**を持つ（Bethe 1930 / Stobbe）:

    df/dω = (256/3)·(1+k²)(1+k²+3q²) / ([1+(q−k)²][1+(q+k)²])³ · e^{−2θ/k}/(1−e^{−2π/k})
    k = √(2ε), ω = (1+k²)/2, θ = atan2(2k, q²+1−k²)

⚠ **式は写す前に 3 方向で独立検算した**（Zhang 式 38 の印字ミスで σ が 21 倍になった前科がある）:

| 検算 | 期待 | 実測差 |
|---|---|---|
| 閾値 k→0, q→0 で 256/3·e⁻⁴ | 1.5629345185 | **4.4e-14** |
| 双極子極限の連続和 ∫(df/dω)dε | 0.4349958（= T11 の 1−ΣLyman と**独立に同じ数**） | **6.2e-06** |
| 尾根 ω=q²/2 に沿って → 8/(3πq)（= 1s の Compton プロファイル J(0)） | 1.0000 | q=80 で比 1.0000 |

⚠ **`atan` は必ず 2 引数**。q² < k²−1（まさに尾根の外側）で分母が負になり、
1 引数だと π の枝を落として Stobbe 因子が壊れる。

**結果 — `gos_surface` は閉形式を全面で再現した:**

| | 最悪相対誤差 |
|---|---|
| 面全体 | **4.4e-03** |
| **尾根帯 (0.8 ≤ ρ < 1.5、23 点)** | **3.2e-03** |

⇒ **尾根での 10–20 % の組み立てバグは、外部参照ゼロで排除された。**
`selftest` の **T11b** として恒久ゲート化した（`h1s_gos_exact` + 全面比較）。
⚠ T11 は双極子極限と和則しか見ておらず、どちらも ΔE 方向に積分した量なので
**「尾根で 20 % 高く翼で低い」なら和則 1 のまま通ってしまう**。尾根の形は
一度も検査されていなかった。

**排除できたもの**（非相対論 1s 経路）: 連続状態のエネルギー規格化 / 動径積分・
球ベッセル・q 内挿 / 部分波の列挙と 3j 係数 / λ 和・占有数・2ΔE/q² の前因子。
⚠ **排除できないもの（混同しないこと）**: 多電子 SCF・遮蔽・交換・Latter 尾 /

2. **多重極 (L) 別の分解**。双極子域だけ合って ridge で開く形は、終状態場よりも
   **多重極の規約**（2L+1 の係数・reduced matrix element の規約・m 平均と占有数和）の
   食い違いが自然に作る。**L=1 だけ全 q で合い、高 L から開くなら規約を疑う**。
   実装は `l4_angular.jl` の `legendre_sum` に λ 別の内訳を返す診断経路を足す
3. **束縛状態側の 2 段トグル**（codex 助言。⚠ **CLI には無い軸**）。
   実測で確認済: `--frozen` は束縛軌道を変えず（`v_bound` とキャッシュ鍵を共有）、
   `--nodscf` は**場**を変えるだけで束縛は依然 `solve_dirac_bound`。したがって
   **「同じ場で束縛を Schrödinger で解く」は一度も試されていない**。
   `:large_only`（F_b=0）と `:schrodinger` を分ければ、「明示的な小成分 F_bF_c の寄与」と
   「大成分の形の差」を分離できる。
   ⚠ **E_th・ε 格子・連続状態・κ 角度因子は固定する**（固有値まで変えると尾根位置が混ざる）
4. **★ PWIA 対照（いまや最有力）**。T25 で「高 q では衝撃極限に乗る」ことが確定した以上、
   残るのは**比較帯 (ρ≈1) に残る終状態の歪み**。終状態を V=0（平面波）にした版を
   同じ (q, ω) で走らせ、**歪みの寄与そのものの大きさ**を測る。
   それが 12–36 % に届かないなら、我々の側にその大きさの余地は無い
5. **ridge 周辺の直接密 q スキャン**。`--nqout` を 4 倍にしても ≤2.2 % だったが、
   **「格子から内挿した値 vs 直接計算した値」は突き合わせていない**

⚠ **ρ の定義に使う q_ridge は全損失 ΔE のままで正しい**（自由電子反跳条件は
ΔE ≃ q²/2m）。束縛エネルギーを差し引いた ε を代入すると、深い殻で尾根を大きく誤配置する。

⚠ **有限核は優先度が低い**（codex）。Au でも R_nuc ≈ 1.3e-4 a₀ なので q=30 a₀⁻¹ で
qR ≈ 4e-3。しかも Au L3 は 2p3/2、M5 は 3d5/2 で、有限核に最も敏感な s1/2・p1/2 ではない。

⚠ **「我々のほうが大きい ⇒ 束縛軌道が収縮している」とは読めない**（codex）。
実空間で収縮した軌道は**運動量空間では広がる**ので、尾根中心では逆に低くなりうる。
収縮を主張するには、位置を合わせた後の残差が y の正負**両側**で上がる偶対称な形が要る。

道具: `tools/gos_vs_zhang.py`（**3 つの規約がコードに固定してある** —
`q_au = q_Ang × a₀` / 殻の規格化（**先方の `occupancy_ratio` と毎回検算**）/
**先方の `ionization_energy` を読んだ `--align omega`**。`--epsmin` / `--epsmax` で ΔE 窓、
ρ 細分と ΔE 層別（ρ 中央値つき）を出す）/ `tools/gos_self_compare.py`（**我々 vs 我々**。
処方や求積を変えたとき「その違いが帯ごとにどれだけ効くか」を測る）。

### P4. `s_cert` と `s_kin` の契約を分離

消費側は現在この 2 領域を同じ「0 + ε」で扱っている:

- **`s_cert < s ≤ s_kin`** — 物理的には可能だが**未収録**。ε で上界を宣言するのが正しい
- **`s > s_kin`** — **運動学的に不可能**（Ewald 球上にそのビーム対が存在しない）。
  「0 ± ε」ではなく「**その要求は成立しない**」と返すべき
