## 1. 何と何を比べているのか

| | 我々 | 先方 (Zhang et al. 2023、CC-BY) |
|---|---|---|
| 面 | `gos_surface` (κ 分解 Dirac 連続状態、Dirac SCF 原子場、Xα) | `refs/data/database/*.hdf5` (FAC ベース) |
| 閾値 | Bote–Salvat の端 | 先方の計算値 |
| 規格化 | nlj 副殻 (2j+1 電子) | nl 殻まるごと (2(2l+1) 電子) |
| 横断項 | **off** | 無し (縦成分のみ) |

```
GOS      = 2·ΔE·S(Q)/Q²                        (l5_exit_gos.jl の定義)
d²σ/dΩdε = 4γ²a₀² (k_f/k_i) S(Q)/Q⁴            (横断項 off)
⇒ σ = 4γ²a₀²·4π ∫dε (k_f/k_i)/(2ΔE) ∫₀^{t_β} dt GOS(Q,ΔE)/Q²
   Q² = (k_i−k_f)² + 4 k_i k_f t,   t = sin²(θ/2)
```

**手順は 2 段**で、⚠ **(1) が通らないうちは (2) の数字に意味が無い**:

   相方の `tools/dump_for_zhang_sigma.jl` が「面」と「直接求積した σ」を同じ行に書く
2. 先方の面を**同じコード・同じ求積・同じ規約**で積分して比を出す

## 2. ★ 見つけた欠陥 (1) — 角度求積が高 `a·t_β` で崩れていた

### 2.1 何が起きていたか

`sigma_from_gos` は角度積分を **t 上の単一 Gauss–Legendre 64 点**でやっていた。
被積分関数は `GOS(Q(t))/Q²` で、`Q² = dq² + kk·t` (`dq = k_i−k_f`, `kk = 4k_i k_f`)。
**小 t で 1/Q² が急**で、その急峻さは

```
a·t_β = kk·t_β / dq²
```

一つで決まる。等間隔に近い節点では、幅 `1/a` の峰を解像できない。

### 2.2 なぜ気づかなかったか — Fe/Au では実際に問題が無かった

`dq ∝ ΔE/v` なので、**閾値が高いほど dq が大きく、a が小さい**。
実測 (200 keV):

| チャネル | 閾値 | `a·t_β` の最大 | 旧実装の検算(1) |
|---|---:|---:|---:|
| Fe K | 7083 eV | 1.7e+03 | 5.6e-05 |
| Au L3 | 11747 eV | ~1e+03 | 3.3e-05 |
| Au M5 | 2151 eV | ~1e+04 | 4.4e-04 |
| **C K** | **291 eV** | **~1e+06** | **6.3e-02** |

C は Fe に対して閾値が 24 倍小さく、`a` は **(7083/291)² ≒ 590 倍**になる。
⇒ **4 チャネルだけで見ていた限り、この欠陥は見えない**。108 元素へ広げた瞬間に出た。

⚠ これは [[reference-generation-matters]] や [[fixed-threshold-assumes-sn]] と同型の罠である —
**標本が狭いと、検査が「効いている」ように見えてしまう**。

### 2.3 直し方 — 1/Q² を解析的に消す

```
x = ln(1 + a t),  a = kk/dq²   ⇒   dt = (e^x/a) dx
GOS/Q² dt = GOS/(dq² e^x) · (e^x/a) dx = GOS/(a dq²) dx = GOS/kk dx
```

**1/Q² が丸ごと落ちて、被積分関数は GOS そのもの**になる。積分域は
`0 ≤ x ≤ log1p(a·sin²(β/2))`。これは出荷経路 (`l4_angular.jl`) が使っている変数と同じ。

### 2.4 ★★ 正しさの証明 — **求積ではないもの**に当てる

⚠⚠ **「検算(1) が下がったから正しい」は言えない**。Julia 側の出荷経路も log-x を使うので、
**同じ変数・同じ族へ寄せただけで差が消えた**可能性が残る。このリポには
「自己収束テストが誤差を 26 倍過小評価した」前例がある ([[self-convergence-underestimates]])。

そこで **閉じた式**に当てた。`GOS = A·Q^m` の合成面は log-log 双 1 次内挿が**厳密に**再現し
(log g が log Q の 1 次式)、角度積分は

```
∫₀^{t_β} A Q^m/Q² dt = (A/kk)(2/m)[(dq²+kk t_β)^{m/2} − (dq²)^{m/2}]   (m ≠ 0)
                     = (A/kk) ln(1 + kk t_β/dq²)                        (m = 0)
```

と閉じる。`python tools/sigma_vs_zhang.py --selftest` の実測 (m = 0,−2,−4,−6 ×
`a·t_β` = 1e0…1e8 の 20 条件):

| 求積 | 解析解との最悪相対差 |
|---|---:|
| **log-x GL 64 点 (採用)** | **5.45e-15** |
| tanh-sinh (独立な族、t 上で直接) | 7.90e-09 |
| **旧: t 上の単一 GL 64 点** | **1.00e+00** |

⇒ **採用した求積は機械精度で解析解に一致し、独立な族もそれを裏づけ、旧実装は同じ検査で落ちる**。
⚠ **負のテストが自己検査に組み込んである** — 「新実装が合格し、かつ旧実装が落ちる」ことを
両方確かめてから合格を印字する ([[prove-the-check-can-fail]])。

旧実装の崩れ方 (m = −4):

| `a·t_β` | 1e0 | 1e2 | 1e4 | 1e6 | 1e8 |
|---|---:|---:|---:|---:|---:|
| 相対誤差 | 7.6e-16 | 6.9e-09 | **7.9e-01** | **1.00** | **1.00** |

## 3. ★ 見つけた欠陥 (2) — 面の外挿を回数で見ていた

両方の面が**低 ε 端で範囲外**になり、clamp (端の値で一定) されていた。
clamp は GOS を落とさず保つので**過大評価**になる。

⚠ **回数で判断してはいけない** ([[count-vs-weight]])。実測 (Fe K):

| | clamp した回数 | **σ に持つ重み** |
|---|---:|---:|
| 我々 (旧: 下端 0.2 eV) | ε下 3648 回 | **4.8e-03** ([0,50] eV 窓) |
| 先方 (下端 0.01 eV) | ε下 1536 回 | 1.2e-04 |

⇒ 我々の ε 格子を **0.2 eV → 1e-5 eV**、点数を **96 → 192** (対数範囲が 3.3 → 7.6 桁に
広がる分の解像度を保つため) にして、**我々側の clamp 重みを 0** にした。
先方の 1.2e-04 は**先方の格子の下端 (0.01 eV) 由来で、こちらでは動かせない**。

### 3.1 ⚠⚠ 訂正 — 「重み」を「バイアス」と書いたのは誤り (2026-08-18 の監査で発覚)

当初この節には「片側だけに乗るので**比に約 0.5 % のバイアス**になる」と書いた。**これは誤りである**。

- **4.8e-03 は「外挿点が積分に持つ重み」であって誤差ではない**。誤差はそのうち
  「平坦に延長したことが外した分」だけで、はるかに小さい
- **実測が否定している**: 格子を伸ばす前 (`eps_lo` = 0.2 eV、clamp 重み 4.8e-03) と
  伸ばした後 (clamp 重み 0) で、σ 比は **4 桁一致**する

  | 条件 (Fe K, β=10 mrad) | 伸ばす前 | 伸ばした後 |
  |---|---|---|
  | 窓 [0,100] eV | 1.1083 | 1.1083 |
  | 窓 [0,200] eV | 1.1100 | 1.1100 |
  | 窓 [0,50] eV | 1.1075 | 1.1075 |

  ⇒ **0.5 % どころか、4 桁目まで動いていない**

- 「clamp は GOS を一定に留めるので**過大評価**」も、符号を一般には言えない
  (閾値直上で df/dE が減る端では過小評価になる)

**では、なぜ格子を伸ばしたのか**。比への影響が測れるほど大きかったからではなく、
**外挿点をゼロにして `CLAMP_MAX` 門を自明に通し、「外挿していないか」という論点を
議論から外すため**である。これは正しい判断だが、**根拠の書き方が誤っていた**。

⚠⚠ **この 0.5 % を契約に書いてはいけない** — 実測の 50 倍以上の系統を凍結することになる。

## 4. ゲートの門 (どの条件を比の集計に入れるか)

⚠ **「数値が出た」と「比較できる」は別**である (codex の指摘、2026-08-18)。

| 門 | 値 | 意味 |
|---|---:|---|
| 検算(1) | ≤ 3e-03 | 我々の面から我々の σ を再構成できているか |
| clamp 重み | ≤ 1e-03 | 面の外を外挿した点が σ に持つ割合 |

門を通らなかった条件は**比の集計から外し、外した数と内訳を印字する**。
⚠ 混ぜると、求積の失敗を「物理の食い違い」として読んでしまう。
