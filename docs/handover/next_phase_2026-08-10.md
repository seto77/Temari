### 1.1 なぜ 80 kV 下限が 16 Å⁻¹ を可能にしたか

s の上限は表の都合ではなく**運動学**で決まる。`l4_angular.jl:631` の
`kz = sqrt(k_i² − K²/4)` が実数である条件 `K < 2k_i` から **s_kin = 1/λ**。

⚠ **これは近似の限界ではない。**「Ewald 球上に差ベクトル K を持つビーム対が
存在しない」という幾何的不可能性で、契約をどう書いても越えられない。

| E0 | s_kin [Å⁻¹] | 16 に対する余裕 |
|---:|---:|---:|
| 30 kV（表の下限） | **14.33** | **届かない** |
| 37.15 kV | 16.00 | 1.00 |
| **80 kV（ALCHEMI 下限）** | **23.95** | **1.50×** |
| 200 kV | 39.87 | 2.49× |

⚠ **表の E0 下限 30 kV は据え置く**。80 kV は ALCHEMI の下限であって、
通常の STEM-EDX 像は 30 kV でも使える。**像は s ≤ 5.6 Å⁻¹ しか要求しない**
(`IonizationChannel.cs:527`、正典 SrTiO₃ 条件の実測) ので低圧行が 16 に
届かないことは像側に影響しない。

### 1.2 なぜ 16 なのか（Bloch 数ではなく結晶と電圧で決まる）

⚠ **「1000 Bloch だから s いくつ」という立て方は誤り**（作者指摘）。帯軸では
基底が Laue zone ごとに階段状に太り、要求は zone 半径で決まる:

    R_n = sqrt(2 n k H),   k = 1/λ,  H = 1/d  (d = 帯軸方向の実空間繰り返し)

⇒ **R ∝ sqrt(1/d) · sqrt(1/λ)**。**小さい格子・高加速電圧ほど大きい。**

実測 3 点（β-AlCo [001] 250 keV, a = 2.861 Å）から較正した scaling は **±5 % で合う**:

    R ≈ 1.41 · k^(1/4) · a^(-3/4) · N^(1/4)      (N = MaxNumOfBloch)

| N | 実測 s | 予測 |
|---:|---:|---:|
| 165 | 6.20 | 5.95 |
| 800 | 8.43 | 8.83 |
| 1600 | 10.54 | 10.50 |

**s は N の 1/4 乗でしか伸びない**。1600 → 6400 Bloch でも 1.41 倍。

1600 Bloch を各条件で使ったときの要求 s [Å⁻¹]:

| a [Å] | 例 | 80 kV | 200 kV | 300 kV | 400 kV |
|---:|---|---:|---:|---:|---:|
| **2.86** | **β-AlCo [001]** | 8.95 | 10.16 | 10.80 | **11.30** |
| 3.52 | Ni [001] | 7.66 | 8.70 | 9.24 | 9.67 |
| 3.90 | SrTiO₃ [001] | 7.09 | 8.06 | 8.56 | 8.95 |
| 5.43 | Si [001] | 5.53 | 6.28 | 6.68 | 6.98 |

**最悪 11.30 に対し 16 は 1.42×**。N^(1/4) 則から **16 が埋まるのは
β-AlCo 400 kV で N ≈ 6,400 Bloch** — 速度制約が 4 倍緩むまで持つ。

⚠ この scaling は **β-AlCo [001] の 3 点だけで較正**しており、`a^(-3/4)` と
`k^(1/4)` の指数は導出値で他系では未検証。**16 の判断を覆すほどの不確かさではない**
（最悪でも 1.42×）が、他系の実測が取れたら確度が上がる。

## 3. 実装計画（S_req = 16 Å⁻¹）

**正本 = `docs/notes/tail_contract_2026-08-09.md`**。以下は要点のみ。

### 3.1 設計の核

1. **s グリッド 0..16、0.05 刻み、321 点**（現行 161 点 / 0..8）
2. **指数 tail (`a·exp(−b·s)`) を出荷形式から撤去**。理由は §4.1
3. **行ごとに保証上限 `s_cert` を持たせる**
4. **s > s_cert には実測した上界 ε を宣言**（`kind` + `eps`）
5. **`GridAt` は s ノード j で `s_cert ≥ s_j` の行だけを補間基底に使う**

### 3.2 なぜ 5 が要るか（低圧行の扱い）

E0 < 37.15 kV の **1,491 行 (10.1 %)** は 16 Å⁻¹ に届かない。素朴に 0 で埋めると
**`GridAt(E0)` が s ノードごとに全 E0 行を PCHIP する**ため、**200 kV の問い合わせが
30 kV 行の埋め草に引きずられる**。

⚠ **この除外は限定的**。発生するのは **321 ノード中の上位 34 点
(s > 14.33、グリッドの 10.6 %)** だけ:

| s [Å⁻¹] | 運動学的に不可な行 |
|---:|---:|
| 14.35 | 525 (3.5 %) |
| 15.00 | 727 (4.9 %) |
| 16.00 | 1,491 (10.1 %) |

**ALCHEMI (E0 ≥ 80 kV) は全 321 ノードで基底に入る**ので throw は起きない。
**通常の像 (s ≤ 5.6) は全行有効**なので現行と同一の挙動。
基底が問い合わせ E0 を含まない場合は **throw**（物理的に不可能な要求。黙って値を返さない）。

### 3.3 コスト

行重み付き scaling 係数 **f = 0.277（実測**）から 161 → 321 点は **×1.28**。
5h16 に対して **約 6h45**、ε 実測を足して **7h 前後**。
.bin は 2.64 MB → **約 3.4 MB**。

⚠ **s は行コストの安い部分**。s 非依存の床（RlTable + Dirac 連続状態）が **62–72 %**
を占めるので、ノード数 2 倍でもコストは 1.28 倍にしかならない。

## 4. ⚠⚠ 触る前に知っておくこと

### 4.1 出荷中の tail は間違っている（実測確認済）

**43 % が hard fail するのは既知。問題は残り 57 %**。Au L3 (Z=79) @300 kV、s = 12:

| | 値 |
|---|---|
| 出荷 tail が返す値 | **+4.151e-05** |
| 実際に計算した値 | **−1.615e-03** |

**符号が逆で 39 倍違う**。F は s = 9〜10 でゼロを横切っている
（s=9: +9.198e-4 → s=10: −1.065e-3）。s=8 は表の値と一致したので計算経路は健全。

同様の符号誤りが **L2 23 % / L3 32 % / M3 24 %**。`tail_fit` 自身の規則で
s ≤ 7 に当て直して (7,8] で検査すると、**上界になっているのは K 1409 行中 665 行 (47 %)**。

⇒ **出荷 tail は上界でも近似でもない**。hard fail はこの静かな誤りから守っていた側。

### 4.2 tail が張れない原因は「減衰しない」ではなく「F が負になる」

null 行 6,359 件の **91.6 % (5,826) が s ≤ 8 内でゼロ交差**。棄却理由は
**符号 86.3 % / 非単調 13.7 %**。文書化されていた第 3 の理由 `b ≤ 0` は
**実データで一度も発火していない** (0/6,359)。

⚠ ただし「`b <= 0` は到達不能な dead code だから消してよい」と読まないこと。
**浮動小数点では窓がほぼ平坦なとき到達する**（1 ulp 差の 6 点で b = 0.0 を返す）。

### 4.3 s グリッド延長は**ビット同一にならない**

- **物理入力は 14,724 行 (99.5 %) で不変** — `l5_channel.jl:169` の
  `q_hi = min(k_i + kf, κ + 15z + 2·max(K_nodes))` は L/M 全行と Z≥20 の K 行で
  **第 1 項が縛る**ので `max(K_nodes)` が落ちる
- **例外は 72 行**（K, Z=6..19, E0≥120 kV）。実際に動く: max|dF| = 1.6e-7 / 1.9e-7。
  HIGH の打ち切り誤差と同オーダー。**MANIFEST に列挙すること**
- **出力は 1 ULP 動く** — `l5_channel.jl:311` の BLAS gemv は s ノード数で
  reduction 形が変わる。|dF| ≤ 1e-18、1e-6 量子化コードの変化 0
- ⇒ **合否は `===` ではなく**「72 行を除き s≤8 で |ΔF| ≤ 1e-15 相対、
  かつ量子化コード変化 0」と MANIFEST に明文化する

### 4.4 主張してはならないこと

- ❌ 「s > s_max で F は指数減衰する」（局所レートは 0.595 → 0.175 と落ちる）
- ❌ 「包絡はべき則 s^-3〜s^-5」（実測指数は **1.05〜18.2** に散る）
- ❌ 「|F(s_max)| が上界」（**1,884 行 (12.7 %) が s=8 で上昇中**）
- ❌ 「ε は E0 で内挿してよい」（内挿した上界は上界ではない。**max × 2.0**）
- ❌ 「符号は最後の点から引き継げる」
- ❌ 「既存の 8,437 本の tail は 12 Å⁻¹ まで信用できる」（§4.1）

### 4.5 ε の取り方（実測で決めた規則）

出荷データで out-of-sample 検証した結果:

| 窓幅 w | 1 Å⁻¹ 外挿で上界になる割合 |
|---:|---:|
| 0.25（6 点） | 77.4 %（最悪 17.2 倍の過小） |
| 1.0 | 88.9 % |
| 2.0 | 99.1 % |
| 3.0 | 100.0 % |

⇒ **ε = max&#124;F(s)&#124; over s ∈ [s_max − 2, s_max] × 安全係数 2.0**、絶対床 1e-6。
**6 点窓から取ってはいけない**。減衰包絡を 6 点に当てるのは論外（63.7 %、最悪 6e8 倍）。
