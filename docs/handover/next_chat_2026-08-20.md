### 1.1 ★ 原因 (究明済み。`window_quadrature_2026-08-19.md` が正本)

**最悪 8 行は全部 Z=54 (Xe) M4、しかも E₀ を 170→400 keV と振っても 1.9 % しか動かない**
⇒ 入射条件ではなく**標的の構造**で決まっている。

1. **d 始状態は双極子の終状態が f 波**で、遠心障壁が閾値直上を抑える
   ⇒ 断面積の最大が**窓の内側**に来る (delayed maximum。Xe M4 は ε ≈ 10 eV、Au M5 は 75 eV)
2. **GL n 点の誤差は Chebyshev 係数 c_{2n} で決まる**。山があると c_32 が大きい
3. **全係数からの誤差再構成が実測と 3 桁一致した** (Xe M4 で 9.78e-03 vs 9.78e-03)
4. ⇒ **対処は次数を上げるだけ**。GL64 で 8e-07、GL128 で 2e-09。
   ⚠⚠ **分割・複合・等比パネルは効かない** (等比 4×6 = 9.00e-03、複合 48 点 < 単一 32 点)

⚠ **Wigner の閾値則は原因ではない** (ε = x² と置けば任意の整数 l′ で解析的)。
⚠ **「l=2 だけ難しい」と一般化しない** — l=0 でも最悪 1.09e-03。
★ **床「~1e-08、原因未特定」の正体も判明** — 連続状態 ODE の格子が ε ごとに組み直されることに
よる**相対 ~2e-09 の決定論的 roughness** (同じ ε ならビット同一だが、刻みを 6 桁掃いても
4 階差が下げ止まる)。⚠ **出荷の F(s) も同じ `eps_setup` を通る**ので、F 側でも測ること。

★ **`worst_window` が角度設定に依らない**という §1.2 の予想は**実測で確認できた** —
角度を継ぎ目分割 npt=12 にしても GL16 9.78e-03 / GL32 4.87e-04 / GL64 7.96e-07 と変わらない。

## 3. ★★★ 作者判断待ち — 角度求積の設計変更

正本 = `docs/notes/nq_nx_2026-08-19.md`。作者指示「n_q を振れ」から始まった調査だが、
**答えは「どちらの次数でもない」だった**。

### 3.1 何が分かったか

被積分関数は `RlTable` の **PCHIP (区分 3 次)** から来るので**継ぎ目を持つ**。
⇒ 全域 GL の前提 (解析性) が崩れており、**誤差が n_x にも n_q にも非単調**。

K=0 では `Q = dq·exp(x/2)` なので継ぎ目は `x_k = 2(ln q_k − ln dq)` と**厳密に写る**。
そこで割ると各パネルの中は解析的 ⇒ GL が指数収束する。

**契約域の最悪条件 (C K @400 keV, β=200 mrad)、横断 on:**

| 規則 | n_q=240 | n_q=540 | n_q=1216 |
|---|---:|---:|---:|
| log-x GL n_x=192 | 8.43e-06 | 4.53e-07 | 1.01e-06 |
| log-x GL n_x=512 | 4.67e-07 | 2.25e-07 | 1.15e-08 |
| **継ぎ目分割 npt=6** | **4.58e-15** | **0.00e+00** | 3.52e-16 |

### 3.2 提案 (⚠ 未承認)

> **σ(β,Δ) の角度求積を継ぎ目分割 GL (npt = 6) にする。n_q = 1216。**

- 角度求積 (a): **~1e-15** — 調整パラメータが消える
- テーブル内挿 (b): **5.6e-08** — 契約域の observed_max。**これが全部になる**
- ⇒ **予算から n_q を逆算できる** (240 → 3.6e-05、540 → 1.5e-06、810 → 2.9e-07、1216 → 5.6e-08)

⚠ 作者は一度 **(1216, 192)** を承認したが、その後 codex の指摘で E₀ を広げたら
**19 倍悪化**し、規則そのものを変える案が出た。**承認は保留中**。

### 3.3 本番実装で守ること (codex のレビュー)

1. **`Q² = dq²·exp(x)` を使う** — 分割点と評価する Q が構造的に一致する
2. ⚠⚠ **継ぎ目を間引かない** — パネル数の上限で節点を飛ばすと、消した非単調性が復活する
3. `gl01(npt)` をキャッシュ、全パネルを 1 本の配列に詰めて `legendre_sum!` を 1 回、
   同じ ε で複数 β なら**累積和をキャッシュ**
4. ★ **認証用の独立オラクルを別に作る** — 本番が継ぎ目分割になるとオラクルが無くなる。
   K=0 の縦成分は各区間で `∫e^{-x}P₆(x)dx` として**準解析的に**積める (求積ではないオラクル)
5. `dq > 0` / `isfinite(a)` / `q_hi ≥ dq` / `x_crit < 0` を assert

### 3.4 ⚠ 測っていないこと

- **K≠0 分岐** — 出荷 F(s) はこちら。**既存テーブルの設定変更をこの結果で正当化できない**
- 出荷 `sig_thresh` / `l_cap` での再確認 (実験は `sig_thresh=0`、`l_cap`=PROD)
- β を契約域で密に (いまは 10 点)、ε をもっと細かく
