## 2. ★★★ 作者判断待ち (1) — 窓の求積規則

### 2.1 何が分かったか

**(a) `Δ₁ > 0` の窓は座標が違う** (`tools/beta_spike.jl:206`):

```julia
if d1_eV == 0.0
    eps = e2 .* x .^ 2          # √ε 正則化
else
    eps = e1 .+ (e2 - e1) .* x  # ★★ 素の GL on ε
end
```

⇒ 契約は Δ₁ に下限を置かないので、素の ε では**どんな固定次数でも一様な保証にならない**
(物理的な分岐点 ε=0 が区間のすぐ外に寄り続ける)。
実測 (Z=54 M4 @400 keV、幅 1000 eV):

| Δ₁ [eV] | ε GL16 | ε GL128 | ε GL512 | √ε GL128 |
|---|---|---|---|---|
| 1000 | 2.78e-08 | 5.10e-09 | 2.89e-09 | 4.14e-09 |
| 10 | **2.89e-03** | 1.57e-08 | 1.46e-08 | 1.43e-08 |
| 0.01 | **5.43e-02** | 2.27e-07 | 1.69e-08 | **1.51e-08** |

**(b) 幅を契約の上限まで広げると GL128 が壊れる** (Δ₁ = 0、基準 = 等比 32×24):

| 規則 | 点数 | 幅 1e3 eV | 幅 1e5 eV | 幅 0.99·ε_max |
|---|---|---|---|---|
| √ε 単一 GL16 (現行) | 16 | 9.78e-03 | 1.59e-01 | 3.68e-01 |
| √ε 単一 GL128 | 128 | 1.54e-08 | **1.47e-04** | **2.35e-03** |
| √ε 単一 GL512 | 512 | 1.63e-08 | 7.60e-09 | 1.36e-08 |
| **★ √ε 等比 16×16** | **256** | 9.83e-09 | **5.06e-09** | **5.20e-09** |

★ 難しさを決めるのは**幅ではなく「窓が山を跨ぐか」** — 同じ幅でも Δ₁ = 10 eV
(窓が山から始まる) なら √ε GL128 が 1.69e-08 で完璧。

### 2.2 提案 (⚠ 未承認)

### 3.1 ⚠ 主張の範囲 (これを外すと誤読される)

> 固定された Float64 の `RlTable` が定める**区分 PCHIP 被積分関数**について、

含まれない: **Q 表の内挿誤差** (n_q) / **連続状態の離散化** (`ppw`) / モデル誤差。
⚠ **K=0 限定。出荷 F(s) の K≠0 には一般化できない** (§7)。

### 3.2 本番実装で守ること

1. **`Q² = dq²·exp(x)` を使う** (分割点と評価する Q が構造的に一致する)
2. ⚠⚠ **継ぎ目を間引かない**
3. `gl01(npt)` をキャッシュ、全パネルを 1 本の配列に詰めて `legendre_sum!` を 1 回
4. **認証用の独立オラクルを別に保持する** (`tools/angular_split_v2.jl` の
   `analytic_longitudinal` と `transverse_tanhsinh`)。⚠ **本番を継ぎ目分割にすると
   認証が自己参照になる**ので、オラクルは認証専用コードとして残す
5. `assert_no_qlo_clamp` / `assert_den_positive` を入れる。
   ⚠ **`bt2 = 0` の根が区間内なら自動的に分割する防御も残す** (出荷格子では起きないが、

## 7. ⚠⚠ K≠0 (出荷 F(s)) — **今回の変更を広げてはいけない**

- `Q₊² = dq²·e^x` は K≠0 でも成り立つが、**`Q₋²(x,φ) = P(x) + C(x)·cosφ`** なので
  PCHIP 節点が **(x,φ) 平面の曲線**になる。⇒ **テンソル積のパネル集合が節点に揃わない**
- 実測で **1 つの x に沿って φ 方向に 60–345 回**節点を跨ぐ ⇒ 素直な一般化は **~400 倍**の費用
- ⚠⚠ **`angular_integral` の K=0 分岐を触ってはいけない** — `S_GRID[1] = 0.0` かつ
  `"F" => N ./ N[1]` (`src/l5_exit_edx.jl:83`) なので、**出荷 F(s) の規格化分母 N(0) が
  そこを通る**。触ると **F(s) の全値と `N0`・`sigma_own_nm2` が動く** = テーブル全再生成
- ⇒ **σ(β,Δ) 用は別関数を新設する**
- ⚠ **`n_phi` を単独で振った実験がリポに 1 つも無い** — F(s) の精度を主張するなら必要
