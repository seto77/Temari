### 2.1 (A) σ(β,Δ) の規則 — v2 を採るか、v3 (パネル数増) へ進むか

  「標本を広げるたびに悪化した」履歴と逆向きにしない)、狭い窓の sentinel を少し残す。deep と同等とは名乗らない
- β = 200 の不合格の広がりを知るだけなら deep は要らない: **β = 200 × 幅 1e5 / to_epsmax × M1–M5 (低 Z) × 最大 E₀ +
