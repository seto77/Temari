### 2.1 ⚠ q の単位は Å⁻¹ (原子単位ではない) — 本書の初稿が誤っていた

HDF5 には単位が書かれていない。**初稿は原子単位と決め打ちして「s で 7.52 Å⁻¹」と
書いたが、これは 1.89 倍の誤り。**物理で決め直した:

H の K 端で、各 ΔE における `data` の最大位置 (= Bethe ridge) を
`(a₀q_r)² = ΔE/R + ΔE²/(2m_ec²R)` の予測と比べると、比が **1.888** に収束する。
これは **1/a₀ = 1.8897 Å⁻¹/a.u.** ⇒ **ファイルの q は Å⁻¹**。

| free_E [eV] | ΔE [eV] | q_argmax (ファイル) | 予測 a₀q_r | 比 |
|---:|---:|---:|---:|---:|
| 103.3 | 116.9 | 5.278 | 2.931 | 1.801 |
| 965.0 | 978.6 | 16.027 | 8.485 | **1.889** |
| 4000.0 | 4013.6 | 32.414 | 17.209 | **1.884** |

裏付け: 最小 q で `∫(df/dE)dE = 0.557`。水素 1s の**連続状態のみ**の f 和 0.5651 と
一致する (4000 eV 打ち切り分だけ小さい) ⇒ `data` は df/dE [1/eV] で物理も正しい。

⇒ **正しくは q_max = 50 Å⁻¹**。我々の規約 (散乱ベクトル [Å⁻¹] = 4π·s) では
**s = 50/4π = 3.98 Å⁻¹ 相当**。⚠ 両者は**別の量** (先方は対角 GOS の q、
我々は MDFF の差ベクトル) なので、範囲の比較は「運動量として何処まで数値が有るか」
の話に限る。

### それでも残る示唆

- **対数格子は実際に出荷されている。**我々の一様 321 点 (Δs = 0.05 固定) は、
  低 s の分解能が足りず高 s に点を捨てている。**次世代は等比格子**
- **q_max = 50 Å⁻¹ は我々の s で 3.98 Å⁻¹ 相当** (§2.1)。⇒ **v4 の 8 Å⁻¹ でも既に
  先方の収録範囲の外**で、**v5 の 8–16 Å⁻¹ には照合相手が存在しない**。
  引き継ぎ書 §3.4 の懸念は裏が取れた (しかも当初思ったより差は大きい)
- 計算規模の目安: 先方は 2143 辺を **10 コアで約 2 日 / 128 コアで約 4 時間**。
  我々は 525 チャネル × 約 28 E0 × 321 s を 16 コアで 6h47。**問題が違う**
  (先方は生の GOS、我々は放出エネルギーと角度を積分した後の量) ので直接比較はできない

## 4. 端エネルギーのずれは我々の欠陥ではない (C9 の設計が裏付けられた)

`CLAUDE.md` は C9 の教訓としてこう書いている —
「E_b が Bote 端と 0.1 % 一致するのは深い準位だけで、浅い準位は 0.5〜1.6 % ずれる。

⇒ **我々の C9a を「絶対値では 0.05 のゲート、割り当ての検査は C9b (分裂比)」に
分けた設計は正しかった。**先方も絶対一致は諦めて線形回帰 (傾き ≈ 1.01) で吸収している。

## 5. 減衰の形 — 指数 tail の撤回は「符号」より深い理由で正しかった

Egerton 3rd ed. §3.11 (Delocalization of Inelastic Scattering) は、非弾性散乱の
object function / PSF を

    PSF(r) ∝ (k₀r)^(−2) · exp(−2r/b_max)      (式 3.176、b_max = v/ω は Bohr 断熱限界)

と書き、さらに「一般には **Lorentzian に指数減衰の裾**が付いた形」(式 3.177) とする。
**実空間が r^−2 の芯を持つ** ⇒ 運動量空間の裾は**代数的**になる。

⇒ v4 が積んでいた `a·exp(−b·s)` は、**符号が反転するから使えなかった**だけでなく、
**そもそも関数形が物理と違っていた**。`tail_contract_2026-08-09.md` の撤回判断は
より強い根拠を得た。実測 (`format_and_sampling_2026-08-12.md` §2) でも、
|F| の減衰は代数的で指数は始状態 l とともに急峻化する。

⚠ **Bethe ridge を我々の s 上限の根拠に使ってはいけない。**Egerton §3.6.1.3 の
Bethe ridge は**運動量移行 q** の話で、我々の K は**2 本のビームの差**である。
K 方向の減衰を決めるのは非局在化 (object function の広がり) であって Bethe ridge ではない。

## 6. 広い動的範囲を運ぶなら、細かい量子化ではなく**構造つきモデル**

Thorkildsen 2023 は X 線原子散乱因子を**逆 Mott–Bethe**構成で表す:

    f_X(s;Z) = Z − 8π²a₀s²·[α + Σᵢ cᵢ exp(−dᵢ s²)]     (MB[nG+α])

**Gauss 6–20 本**で平均絶対誤差 **1.95e-06 (OFFV1 データ) / 5.33e-08 (OFFV2 データ)**。
**我々の量子化 1e-6 より細かい精度を、321 点ではなく 20 個弱の係数で出している。**

効く理由は本数ではなく、**既知の解析構造 (s² の因子) を先に括り出している**こと。
同論文は「パラメータを増やしすぎると逆に破綻する」「有限の s 区間なら MB 型を推奨」とも書く。

⇒ **将来 s の動的範囲を本当に運ぶ必要が出たら、量子化を細かくするのではなく
構造つきモデルにする。**⚠ ただし現時点でその必要は無い
(`format_and_sampling_2026-08-12.md` §1 — 潰れる分の害は 1 行あたり ≤ 1.03e-05)。

参考: 参照データの格子はどれも**非一様**。Olukayode 2023 (OFFV1) は
**IUCr グリッド 62 点** (s = 0–6、精度 1e-5)。**一様格子の参照は 1 つも無い。**
