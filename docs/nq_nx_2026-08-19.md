# 角度求積の分割数 — n_x と n_q のどちらが律速か (2026-08-19)

⚠ 本書は**測定の正本**である。作者指示 (2026-08-18):
「n_q を振れ。n_x とともに変化させれば相関も分かるはず。codex と深く議論したうえで
最良の分割数を提案せよ」。道具 = `tools/nq_nx_probe.jl` + `tools/nq_nx_pareto.py`。

## 0. 結論

| 用途 | 推奨 | 根拠 |
|---|---|---|
| **新製品 `σ(β,Δ)` の既定** | **n_q = 540, n_x = 96** | 全標本の最悪 1.9e-06 / β≤100 mrad で 6.1e-08。費用と精度の折れ点 |
| 広角の高精度オプション | n_q = 540, n_x = 192 | 最悪 9.9e-07。⚠ β≤100 mrad では 96 より**良くない** |
| **既存 F(s,E₀) 出荷テーブル** | **(360, 96) のまま。作り直さない** | ⚠ 本実験は **K=0 分岐しか認証していない** (§6) |

★ 一行で言うと: **n_x = 64 は「十分値」ではなく「n_q が効き始める境目」であり、
そこから先の精度を買う主レバーは n_q である**。

## 1. 何が問題だったか

散乱角の積分は log-x 上の **n_x 点 Gauss–Legendre**:

```
x = ln(1 + a·sin²(θ/2)),  a = 4 k_i k_f/(k_i−k_f)²
σ_ang ∝ ∫₀^{x_β} S(Q(x))·jac(x)/Q⁴ dx
```

契約 §7.5 は、この誤差が **n_x について単調でない**ことを実測していた (96 が 64 より悪い行がある)。
「多ければ良い」が成り立たない理由が分からないまま、出荷次数の議論ができなかった。

`S` は `RlTable` の **PCHIP (区分 3 次エルミート、対数 Q 格子 n_q 点)** から来る。
⇒ **被積分関数は継ぎ目を持つ区分関数**であり、GL の前提 (全域解析性) を満たさない。

## 2. ★ 鍵になった道具 — 継ぎ目分割オラクル

K=0 では `Q = dq·exp(x/2)` なので、PCHIP の継ぎ目 `q_k` は

```
x_k = 2·(ln q_k − ln dq)
```

という**厳密な x 座標**を持つ。同じく `eval_ch` の打ち切りは `x_cut = 2·(ln q_hi − ln dq)`。
そこで**継ぎ目と `x_cut` で区間を割り**、各小区間に GL 12 点を当てる。

**各小区間の中では被積分関数は解析的**なので GL は指数収束する。実測した床:

| 検査 | 値 |
|---|---|
| npt 12 → 20 に上げたときの動き | **1e-16 〜 5e-14** |

⇒ 「**その内挿関数の厳密積分**」が機械精度で得られている。これで初めて

- **(a) 角度求積の誤差** = 既定 GL vs 継ぎ目分割オラクル
- **(b) テーブルの内挿誤差** = オラクル値そのものの n_q 依存

を**分けて**測れるようになった。⚠ この道具が無いと (a) と (b) が混ざる。

### 2.1 交絡の除去 (codex の指摘)

- ⚠ **`sig_thresh` は n_q の交絡である**。有意性フィルタは
  `maximum(abs2, view(rl.R, ic, :))` = **n_q 格子上の標本最大**で決まるので、
  節点が増えると生き残る部分波集合が変わりうる。⇒ **`sig_thresh = 0` で共通マスク**にした
- `q_lo` / `q_hi` / `l_cap` / `lam_max` は n_q に依存しない (コードで確認)
- ⚠ `n_q % 8` は SIMD の端数経路に効く (精度には無関係、時間比較には効く)。1216 を選んだのはそのため

## 3. 結果 (a) — 求積の誤差

標本 = Fe K / Ag L3 / Au M5 × ε/ε_max ∈ {0.001, 0.05, 0.5} × β ∈ {30, 100, 300, 1000 mrad, π rad}。
**全条件を通した最悪の総誤差** = (a) + |(b)|:

| n_q \ n_x | 32 | 64 | 96 | 128 | 192 | 256 | 512 |
|---|---|---|---|---|---|---|---|
| 120 | 3.6e-04 | 2.1e-04 | 1.5e-04 | 2.6e-04 | 1.3e-04 | 5.9e-05 | 5.8e-05 |
| 240 | 9.8e-05 | 2.8e-05 | 1.7e-05 | 1.6e-05 | 1.3e-05 | 1.4e-05 | 4.7e-06 |
| 360 | 1.4e-04 | 8.0e-06 | 1.2e-05 | 4.4e-06 | 4.9e-06 | 5.6e-06 | 3.6e-06 |
| **540** | 1.4e-04 | 2.6e-06 | **1.9e-06** | 2.7e-06 | 9.9e-07 | 1.2e-06 | 8.2e-07 |
| 810 | 1.4e-04 | 1.1e-06 | 1.3e-06 | 9.0e-07 | 8.4e-07 | 1.9e-07 | 5.1e-07 |
| 1216 | 1.4e-04 | 4.0e-07 | 2.4e-07 | 3.3e-07 | 1.0e-07 | 1.2e-07 | 1.5e-07 |

**n_x を固定して n_q を上げる効果 (240 → 1216) は 70 倍**、
**n_q を固定して n_x を上げる効果 (64 → 512) は 6 倍**。⇒ **主レバーは n_q**。

β ≤ 100 mrad (EELS の実用域) だけに絞ると全体に 2 桁良く、n_q=540 / n_x=96 で **6.1e-08**。

### 3.1 ★ n_x = 32 だけ n_q と逆相関する

n_x=32 は n_q=240 で 9.8e-05、n_q=360 以降 **1.4e-04 で平坦**になる。

**codex の説明が正しい** (私の「節点が継ぎ目より少ない」より的確):

> n_x を固定して n_q → ∞ とすると、PCHIP 関数は滑らかな真の関数へ近づく。
> そのとき誤差は 0 ではなく、「**滑らかな極限関数に対する 32 点 GL 固有の誤差**」へ近づく。
> n_q=240 で 9.8e-05 と小さかったのは、継ぎ目由来の誤差が 32 点 GL 固有の誤差と
> **偶然逆符号で相殺**していたためで、n_q を上げるとその「有利な粗さ」が消えた。

⇒ **1.4e-04 が n_q=360 以降で平坦であること**が、この説明を強く支持する
(単なる継ぎ目未解像なら n_q とともに揺れ続けるはず)。

## 4. 結果 (b) — テーブルの内挿誤差は律速ではない

最密 n_q=1216 を基準にした相対差。⚠ **同じ族 (対数格子 PCHIP) の自己収束**なので
下限であって上界ではない ([[self-convergence-underestimates]])。

| n_q | 大きさ |
|---|---|
| 240 | 1e-07 〜 4e-06 |
| 540 | 1e-08 〜 2e-08 |

**推定次数 p は 45 系列で 3.4 〜 4.2 (多くは 4.0 付近)。**
⚠ codex の事前予想は「PCHIP (Fritsch–Carlson) なので p ≈ 3 まで」で、実測はそれより高い。
積分後の局所誤差の相殺・超収束で 4 に近く見えるのは不自然ではない。
⚠⚠ **有限の n_q=1216 を真値としているので p は上向きに偏りうる**。
「内挿誤差の次数を証明した」とは書かないこと。

⇒ **(a) が (b) を 10〜30 倍上回る**。律速は求積であって、テーブルの値ではない。

## 5. 費用と Pareto 前線

実測 (Fe K、2 スレッド、本走と同居):

```
T_table:  120→0.0437 s  240→0.0663  360→0.0772  540→0.0940  810→0.1359  1216→0.1916
T_ang:     32→34.5 µs    64→110      96→230     128→386     192→825     256→1427   512→5320
```

⚠ **費用はほぼ全部テーブル構築側**である。n_q を 240→540 に上げる費用 0.028 s は、
n_x=64 の角度積分 **251 回分**に相当する。逆に言えば **n_x を 64→96 に上げる費用は
角度積分 1 回あたり 0.12 ms しかない**。

`T(n_q, n_x; M) = T_table(n_q) + M·T_ang(n_x)` の Pareto 前線 (M = テーブル 1 個あたりの
角度積分の回数) は、M = 1 / 8 / 64 で**形がほとんど変わらない**。折れ点は一貫して
**(540, 96)** 付近にある。

## 6. ⚠⚠ この実験が認証していないもの

- **K ≠ 0 の経路** — 出荷 F(s,E₀) は `K_nodes = 4π·s_nodes·a₀` (321 点) を使い、
  `angular_integral` の **K≠0 分岐 (φ 積分 `n_phi` と `RaT` を含む)** を通る。
  本実験は **K=0 分岐だけ**を測った。⇒ **既存 F テーブルの設定変更をこの結果で正当化できない**
- **軽元素の `q_hi = κ+15Z` 打ち切り** — 標本 (Fe/Ag/Au) では `q_hi = k_i+k_f` なので
  中途で跨がなかった (跨いだ 1 件は β=π での丸め誤差ぶんの境界事例)。
  ⚠ **C K なら 15Z = 90 に対し k_i+k_f ≈ 262** なので、大 β で**本当に跨ぐ**。別途 §8
- **σ 寄与で重みづけした誤差** — 本書の最悪値は全条件の最大であって、重みではない

## 7. ★ 最悪値で選んでよいのか — [[count-vs-weight]] との緊張

律速条件はすべて **Au M5, ε = 0.5×ε_max (≈99 keV), β = π** という、
**σ をほとんど運ばない隅**である。このリポの規律に従えば、σ 寄与で重みづけすべきに見える。

**codex の反論が決定的だった**:

> `σ(β,Δ)` は**任意のエネルギー窓を受け付ける**。総 σ にほとんど寄与しない 99 keV の尾でも、
> **その周辺だけを窓として要求されたら、それが出力の全量になる**。

⇒ **二重の契約**にする:

| 指標 | 用途 |
|---|---|
| σ 寄与で重みづけした相対誤差 | **設定選択の主指標** |
| 局所の `observed_max` | **契約のゲート** (窓が尾だけを切り出す場合の保証) |
| 微小な尾の窓 | `atol` で評価 (相対では無意味になる) |

⚠ 重みづけ指標はまだ測っていない。凍結前に必要 (§9)。

## 8. 軽元素の `q_hi` 打ち切り — 潰し方 (未実施)

`eval_ch` は `q > rl.q[end]` で**厳密に 0** を返す。積分域が跨ぐと**跳び (0 次の不連続)** が入り、
これは PCHIP の継ぎ目より桁違いに強く、**n_q を上げても消えない**。

**数値的な対処 (モデルを変えない)**: 新製品の K=0 経路では積分上端を
`x_eff = min(x_β, x_cut)` にする。先は厳密に 0 なので、**同じ区分関数を同じ値のまま積分する**
だけであり、GL に内部の跳びを踏ませずに済む。

⚠ **`15Z` の係数を盲目的に上げてはいけない**。q_hi を伸ばすと同じ n_q でも
`h = ln(q_hi/q_lo)/(n_q−1)` が粗くなるので、「尾を伸ばした効果」と「内挿が粗くなった効果」が
混ざる。⚠ **外挿は非推奨** — `R(Q)` は振動と零点を持ち、PCHIP の区間外外挿を二乗して使うのは危険。

## 9. 凍結前に足すべき測定

1. **β = 150, 200 mrad** — 契約域は β ≤ 200 mrad だが、測ったのは 100 と 300。
   ⚠ **100 mrad の値を 200 mrad の契約へ外挿してはいけない**
2. **軽元素 (C K, O K)** — `q_hi` 跨ぎが実際に起きる領域
3. **実際の ε 求積重みを使った重みづけ誤差** (§7 の主指標)
4. **尾側の狭い Δ 窓** — `atol` の根拠
5. K≠0 の認証 (既存 F の設定を将来変えるなら)
