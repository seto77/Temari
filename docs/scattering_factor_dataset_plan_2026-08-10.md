記録ではない。出荷済みの F(s, E₀) については `src/prod_v5_jl/MANIFEST.md` と
`docs/dataset_contract_2026-08-09.md` が正本。*

作者判断: **f_x/f_e は将来公開する**。ただし F dataset で築いた再現性の基準を

## 1. 決定 — 処方は Dirac SCF + KLI

**f_x/f_e データセットの原子場は、完全 Dirac SCF + 厳密交換 (KLI) とする。**

根拠の書き方に注意する。「KLI が正しいから」ではなく:

> f_x について比較可能な最良の外部系列 (OFFV1 = DHF の**計算値**、フィットでは
> ない) に対し、検討した処方のうち Dirac + KLI が最も良好だったので採用する。

**DHF 自体を実験的真値と呼んではいけない**。実測 (2026-08-07) では Dirac+KLI の
f_x は OFFV1 に対して Waasmaier–Kirfel と同水準で、C・Fe・Au では上回った
(Au 相対 0.030 % vs WK 0.079 %)。

⚠ **コードの既定に委ねない**。`parse_fx_exchange` の CLI 既定は既に `:kli` だが
(`compute_fx` の**関数**既定は `:xalpha`)、これは引数解釈の既定であって
科学的判断ではない。**データセットの処方として明示的に宣言する**こと。

### 1.1 F dataset と処方が違うことをどう説明するか

F dataset は **Dirac + Xα** のまま (イオン化では既存参照が全て Xα 系なので、
KLI にすると比較相手を失い 2–5 % 悪化する)。同じリポジトリの 2 製品が違う
交換処方を使うことになるが、これは自己矛盾ではない。**観測量ごとに、外部検証が
可能かどうかを基準に処方を選ぶ**という一貫した方針の帰結である。

ただし README の "the same self-consistent atom" という表現とは緊張するので、
Data ページに以下を明記する:

- Temari エンジンは複数の交換処方を実装する
- dataset は観測量ごとに処方を選ぶ (F = Xα / f_x·f_e = KLI)
- **異なる dataset 間で共通のハミルトニアンを仮定してはいけない**
- ⚠⚠ **KLI の f_e と Xα の F を同一シミュレーションに入れる利用者があり得る。**
  個別には最良でも、**内部整合的な組ではない**。両方を同じ原子場で使う必要が
  ある用途では、同一処方で再計算すること (エンジンは公開されている)

⚠ **Xα 版 f_x を「もう 1 つの正式データセット」として併売しない**。選択肢を
増やすとほとんどの利用者には判断できない。再計算可能であることだけ示す。

### 1.2 外部照合の公開のしかた

OFFV1 の数値そのものはリポジトリに入れない (`refs/` は索引だけ追跡)。しかし
「作者の手元では近かった」では**再監査ができない**。最低限これを公開する:

- 参照系列の厳密な書誌と版
- 比較した元素・s 点数・範囲
- 誤差指標と、合否閾値
- 比較スクリプト本体
- 手元参照ファイルの SHA-256
- 合否・順位・集計結果

## 2. 定義と規約 (ここがずれると全部無駄になる)

$$f_x(K) = \int 4\pi r^2 \rho(r)\, j_0(Kr)\, dr, \qquad K = 4\pi s\, a_0$$

- **s = sinθ/λ [Å⁻¹]** (結晶学の規約)。F(s) 出口と同じ K を使うので変換は不要
- $f_x(0) = N$ (電子数)。中性なら Z
- Mott–Bethe: $f_e(K) = 2(Z_{net} - f_x)/K^2$ [a₀]、Å へは × a₀
- ⚠⚠ **γ を掛けていない**。入射電子の $\gamma = 1 + E/m_0c^2$ は**消費側**が掛ける
  (Peng/Doyle–Turner と同じ規約)。ここで掛けると二重計上になる。
  **note 1 行では足りない** — schema・列名・Data ページ・各ファイルの metadata の
  すべてで目立たせる。事故の被害が大きすぎる

### 2.1 動径モーメントと f_e(0) — **実装済 (2026-08-10)**

$$M_n = 4\pi\int r^{2+n}\rho(r)\,dr$$

⚠ **⟨r²⟩ ではない** (⟨r²⟩ = M₂/N)。記号が曖昧だと消費側が 4π や N の分だけ外す
ので、仕様では `M2 = 4π∫r⁴ρdr` と書ききる。

$j_0$ を展開すると $f_x(K) = N - K^2M_2/6 + K^4M_4/120 - \cdots$ なので、
**中性原子では**

$$f_e(K) = \frac{M_2}{3} - \frac{K^2 M_4}{60} + O(K^4) \quad\Rightarrow\quad
\boxed{f_e(0) = M_2/3 \ [a_0]}$$

⚠ **以前は s=0 の f_e を `nothing` にしていたが、これは誤りだった**。中性原子の
前方散乱値は有限で実用がある。⚠ **イオンでのみ発散する** ($Z_{net}-f_x(0)$ =
正味電荷 ≠ 0 で $f_e \sim 2q/K^2$) ので、そこだけ null にする。**0 を置かない。**

⚠ 直接式 $2(Z-f_x)/K^2$ は K→0 で**桁落ち**する (分子が 0 へ向かう差) ので、
極限は差を取らずモーメントから求める。実装は `density_moment` /
`fe_zero_limit_a0` (`src/l5_exit_fx.jl`)、検査は **selftest T12b**。

**T12b の実測** — 水素 1s ($\rho = e^{-2r}/\pi$) は全部閉形式:

| 量 | 厳密値 | 実測の相対誤差 |
|---|---|---|
| M₀ (電子数) | 1 | 1.11e-16 |
| M₂ | 3 | 2.22e-16 |
| M₄ | 22.5 | 1.11e-16 |
| f_e(0) = M₂/3 | 1 a₀ | 2.22e-16 |

⚠ **大きさの閾値だけでは弱い** — M₄ の係数が間違っていても K を小さくすれば
通ってしまう。そこで**残差が K⁴ で落ちること**を検査する: K を 0.05 → 0.1 に
倍にしたときの比は **16.007** (期待 16)。これが「次の項は O(K⁴)」= M₄ の係数が
正しいことの証拠になる。厳密形の直接展開 $f_e = 1 - 3K^2/8$ と
$-M_4/60 = -22.5/60 = -3/8$ が一致することも同時に確認できる。

### 4.1 ゲートにしてはいけないもの

- ⚠ **f_x の単調減少**。正の球対称密度の Fourier–Bessel 変換が全 K で単調という
  一般保証は無い。殻構造やゼロ交差を異常扱いする危険がある。
  (T12 が水素 1s で `issorted` を要求しているのは、**その解析形が単調だから**
  であって、データセット全体のゲートにはできない)
- ⚠ **大 K 漸近の指数**。Dirac 点核密度の原点特異性・有限核モデル・KLI
  ポテンシャルで指数が変わる。限定的な診断に留める
- ⚠ **f_x(0) = Z**。規格化補正で**強制している**ので物理精度の検査にならない。
  **2 つに分ける** — 補正**前**の電子数誤差を品質ゲート (X3) に、補正**後**の
  等式を配線・出力契約の検査 (X4) に

### 4.2 「格子を細かくして動かない」は収束の証明ではない

⚠⚠ 同じモデル誤差に収束しただけかもしれない。SCF は**反復差ではなく残差**で
測る (X2)。誤差源は 3 つに分離して別々に測る:

- **(a) 動径格子と SCF** — `dt/2`・`r_min` 縮小・`r_max` 拡大・収束閾値厳格化
- **(b) 高 K の求積** — **密度を固定して積分器だけ**比較する (production Simpson
  vs 細密格子上の参照 vs 独立実装)。⚠ 高 K では相対誤差が無意味になるので
  混合ゲート $|\Delta f_x| \le \epsilon_{abs} + \epsilon_{rel}|f_x|$、
  ゼロ交差付近は絶対誤差だけで判定。位相刻み $K r \Delta\ln r$ を監視するが、
  密度が既に無視できる領域まで一律に要求しない (実効的な `r_eff` 内で評価)
- **(c) 表の補間** — ノード精度だけでは不足。各 s 区間の**中点と 1/4 点を直接
  再計算**して、公開 loader の補間結果と比較する

⚠ **閾値は pilot 測定の分布を見てから固定する**。先に公開精度を宣言して後から
閾値を合わせるのは順序が逆。

### 4.3 X2 — SCF の不動点残差 (実装・実測済 2026-08-10)

SCF の収束判定は**反復差**である (`drho = ∫4πr²|ρ_new−ρ|dr < tol_rho` と
`de = max|Δε|/max(1,|ε|) < tol_e`)。⚠⚠ **反復差が小さいことは残差が小さいことを
意味しない** — 混合係数 β を小さくすればいくらでも小さくなる。

そこで `tools/scf_residuals.jl` は**不動点残差**を測る: 出荷される ρ を入力として
場を組み直し (`V_bound_callable`)、軌道を解き直して、**同じ ρ が返るか**を見る。
返らなければその ρ はその処方の自己無撞着解ではない。

⚠ **Dirac 経路では `SCFAtom` が per-κ の G/F を保持していない**
(`orbitals` は占有加重和で「診断用」、実体は SCF ループのローカル変数)。
解き直しは避けられず、結果としてこれは反復差ではなく残差になる。

**実測 (Dirac + KLI、キャッシュ済み SCF):**

| Z | R1 = ‖T(ρ)−ρ‖ | R1/N | R4 = ε 残差 | **Δf_x 相対** | Δf_e(0) 相対 |
|---:|---|---|---|---|---|
| 6 (C) | 6.94e-09 | 1.16e-09 | 6.98e-11 | **1.47e-08** | 2.72e-09 |
| 26 (Fe) | 7.58e-09 | 2.91e-10 | 2.29e-11 | 2.00e-10 | 4.98e-10 |
| 47 (Ag) | 7.15e-09 | 1.52e-10 | 7.48e-12 | 4.25e-11 | 2.62e-10 |
| 79 (Au) | 6.72e-09 | 8.50e-11 | 4.83e-11 | 3.81e-11 | 2.51e-10 |

読み取れること:

- ⚠ **R1 の絶対値は Z によらず ≈ 7e-9 で平ら**。これは SCF の `tol_rho` が
  決めているからで、**R1/N は「精度が Z とともに上がる」ことを意味しない** —
  単に N で割っているだけ。ゲートは絶対値か伝播量で切る
- **効くのは軽元素**。Δf_x の相対誤差は Z=6 が最悪 (1.47e-08) で、Z とともに
  2 桁下がる。f_x 自体が小さいので相対で見ると軽元素が縛る
- **残差が観測量を動かす量は ≤ 1.5e-08**。出荷を考える精度 (~1e-4) の 4 桁下

⚠⚠ **R2 (規格化残差) と R3 (電子数) はゲートに使えない**。どちらも全元素で
きっかり **1.667e-07** (と その N 倍) になるが、これは収束の問題ではなく
**求積規則の差**である — ソルバは台形則で規格化し、こちらは Simpson で測り直して
いるため、`l5_exit_fx.jl` が補正している既知の一様バイアスがそのまま出る。
**収束の指標として読むと誤診する。**

### 4.5 X7 — 求積誤差の掃引 (実測済 2026-08-11)

`tools/factor_convergence.jl --sweep`。**密度を固定して積分器だけを変える**ので、
求積誤差が SCF・格子の誤差から切り離される。⚠ **補間を挟まない** — production
格子を 1 点おきに間引けば刻みがちょうど 2h になるので、Simpson (4 次) の
Richardson 評価 `E(h) ≈ [I(h) − I(2h)]/15` がそのまま使える。細かい格子へ内挿
すると、測りたい求積誤差と内挿誤差が混ざる。

**実測 (Dirac + KLI):**

| | Z=6 (C) | Z=79 (Au) |
|---|---|---|
| s ≤ 6 での相対誤差 | ~1e-16 | ~1e-16 |
| 相対誤差が 1e-8 を超える s | 20.0 | 28.5 |
| 相対誤差が 1e-6 を超える s | 24.5 | 40 以内で起きない |
| 相対誤差が 1e-4 を超える s | 32.0 | 40 以内で起きない |
| **位相刻みが 1 rad を超える s** | **10.0** | **9.0** |
| r_eff (電子の 1−1e-10 を含む) | 15.35 a₀ | 16.78 a₀ |

⚠⚠ **位相刻み K·r_eff·Δln r < 1 rad という経験則は、ここでは過剰に保守的**である。
位相が 1 rad を超えるのは s ≈ 9–10 だが、そこでの実際の求積誤差はまだ ~1e-15 で、
1e-6 に達するのは C で s ≈ 24.5、Au では s = 40 まで行っても達しない。
**位相刻みを certification の基準に使うと、理由なく s を 2.5 倍捨てる。**
理由は r_eff が「電子の 1−1e-10」という深い切り方で決まっているため — 実際の
重みはずっと内側に集中していて、r_eff 付近の粗さは効かない。

- **軽元素が縛る**。C が Au より早く破れる (X2 と同じ向き)
- **現行の既定格子 (s ≤ 6) では求積は律速ではない** — 機械精度で回っている
- ⇒ **s 上限は求積では決まらない**。model validation (X12) の届く範囲か、
  用途上の必要性で決まる。§3 の 2 分割がここで実際に効く

### 4.6 X6 — 格子と SCF の収束 (実測済 2026-08-11)

`tools/factor_convergence.jl`。⚠ **変種は格子が違うので ρ を点ごとに比較できない**
ので、格子非依存な汎関数である f_x(K) で比べる (出荷する量そのものでもある)。
⚠ `get_neutral` は格子のつまみを引数に取らず**ディスクキャッシュのキーにも
入らない**ので、細かい格子の結果で標準キーを汚染しないよう `SCFAtom` を直接呼ぶ。

**実測 (Dirac + KLI、s = 0..6 Å⁻¹):**

| 変種 | Z=6 max\|Δf_x\| | 相対 | Z=26 max\|Δf_x\| | 相対 |
|---|---|---|---|---|
| **dt/2 (動径分解能)** | **5.23e-07** | **4.81e-07** | **2.10e-06** | **2.57e-07** |
| r_min/10 (原点側) | 9.82e-12 | 5.88e-12 | 9.91e-11 | 1.01e-11 |
| r_max×1.5 (遠方側) | 3.42e-11 | 2.65e-11 | 3.55e-15 | 4.25e-16 |
| tol×1e-2 (SCF 厳格化) ⚠ | 6.47e-10 | 1.46e-08 | 7.51e-10 | 1.86e-10 |

⚠⚠ **dt が支配的で、他は 3–4 桁下**である。定義域 (原点側・遠方側) はどちらも
既に十分に取れており、締めても何も動かない。

⚠⚠ **この dt 依存性は求積誤差ではない**。X7 (§4.5) が**同じ密度**に対して求積を
1e-16 で回すことを示しているので、5e-07 は**SCF 解そのものが格子に依存して
いる**分である。誤差源を分離して測った甲斐がここに出た — まとめて測っていたら
「細かくすると動く ⇒ 求積が足りない」と誤診しかねない。

⚠ **最下行は収束していない** — `SCF_TOL_RHO` を 100 倍厳しくすると
`SCF_MAX_ITER` 以内に届かず (drho は 3.1e-10 / 4.4e-10 で頭打ち)、警告つきで
返る。**この数値は「収束した結果の差」ではないので、そのまま収束の証拠に
しないこと**。ただし押し込んでも f_x が 1e-9 しか動かないという事実は残るので、
**SCF 閾値は縛りになっていない**とは言える。

⚠ **2 段だけでは「感度」であって「誤差」ではない**。Δ(h→h/2) を誤差に直すには
収束次数 p が要る (`--order` で dt を 3 段取って測る、§4.7)。

### 4.7 収束次数 — 感度を誤差に直す (実測済 2026-08-11)

`tools/factor_convergence.jl --order`。dt を 3 段 (h, h/2, h/4) 取る:

$$\frac{I(h)-I(h/2)}{I(h/2)-I(h/4)} = 2^p, \qquad
\text{誤差}(h) \approx \frac{I(h)-I(h/2)}{1-2^{-p}}$$

**実測 (Z=6、有効点 24/25):**

| 量 | 値 |
|---|---|
| 比の中央値 | **4.00** |
| 収束次数 p | **2.00** |
| max\|I(h) − I(h/2)\| | 5.226e-07 |
| **production 格子の誤差** | **≈ 6.97e-07** |

⚠⚠ **求積は 4 次 (Simpson) なのに、全体は 2 次である**。次数を仮定せずに測った
甲斐がここに出た — 4 次と仮定していれば誤差を 5.226e-07/(1−1/16) = 5.6e-07 と
見積もり、真の 6.97e-07 を 1.25 倍過小に言うことになる。

鎖のどこかに 2 次の段がある。**候補は `hartree()` が `cumtrapz` (台形則の累積
積分、`l0_numerics.jl:103`) で内側電荷を積むこと** — 台形則は 2 次なので、
Simpson で組んだ最終積分より先に律速しうる。⚠ **これは候補であって証明ではない。**
断定するには高次の累積積分に差し替えて次数が上がることを確かめる必要がある
(未実施)。

**誤差予算のまとめ (Z=6、s ≤ 6):**

| 誤差源 | 相対 | 測った場所 |
|---|---|---|
| 求積 (Simpson) | ~1e-16 | X7 §4.5 |
| 定義域 (r_min・r_max) | ~1e-11 | X6 §4.6 |
| SCF 閾値 | ~1e-9 | X6 §4.6 (⚠ 未収束) |
| SCF の不動点残差 | ~1.5e-08 | X2 §4.3 |
| **動径分解能 dt** | **~7e-07** | **§4.7 (支配的)** |

⇒ 数値側の底は **dt が決める 7e-07** で、公開を考える精度 (~1e-4) の 3 桁下。
**s 上限も dt も、いま縛っているのは数値ではない。**

`tools/probe_interp.jl`。⚠⚠ **節点上の精度だけでは不足**である。利用者が受け取る

**決まったこと — 補間規約は not-a-knot の 3 次スプライン。**
PCHIP に一貫して勝つ (Δs=0.05 で 0.27 対 1.85)。PCHIP は単調性のために精度を

判断の材料: 結晶学では構造因子が f_x の和なので、**絶対誤差が伝播する**。
その立場を取るなら IUCr 格子 (62 点) が半分の点数で勝つ。高 s の**相対**精度を
売りにするなら均一 Δs=0.05 (121 点)。

⚠ 参考: 表 2 行目と 3 行目の 3 次スプラインが 5.36e+01 で 4 桁一致しているのは
**偶然**である (Δs=0.50 は s=0.75、Δs=0.25 は s=0.125 と別の点で最大を取り、
|Δ| も f_x も 3.4 倍違うのに、比が揃った)。バグではない。

⚠ IUCr 格子は**参照ファイルから読んでいる**。分野の慣習であって我々の設計では
ないので、再構成すると転記の誤りが混ざる ([[reference-metadata-is-the-contract]])。

### 4.11 f_e の補間 — **素朴な契約は使えない** (2026-08-11)

codex の指摘: **「f_x で not-a-knot が勝った」は f_e の決着ではない。**

f_x(K) = N − K²M₂/6 + K⁴M₄/120 − … は **K の偶関数**なので
**f_x′(0) = 0 が解析的に厳密**である。ところが not-a-knot スプラインはこれを
保証しない。補間曲線に線形項 a·s が混ざると Z − f̃_x ≈ −a·s となり、
**f_e = 2(Z−f̃_x)/K² が 1/s で偽発散する**。f_x では見えない誤差が f_e では発散になる。

3 経路を測った (ゲート比。1 以下なら帯の内側):

| 格子 | A: f_x補間→MB | B: f_e直接補間 | **C: t=s²で補間→MB** | s=0 の傾き (厳密 0) |
|---|---|---|---|---|
| Z=6 均一 Δs=0.10 | 1.387e+02 | 1.586e+00 | 1.002e+01 | −8.37e-01 |
| Z=6 均一 Δs=0.05 | 1.001e+02 | 2.429e-01 | 2.921e-01 | +4.79e-01 |
| **Z=6 IUCr** | 7.945e+00 | 3.089e-01 | **2.481e-02** | **7.20e-03** |
| Z=79 均一 Δs=0.05 | 7.303e+01 | 1.874e-01 | 3.940e-01 | +1.49e+00 |
| **Z=79 IUCr** | 6.814e+00 | 1.441e+00 | **3.414e-01** | **2.59e-02** |

⚠⚠ **経路 A (f_x を補間して Mott–Bethe で f_e を導く) はどの格子でも不合格**
(1〜3 桁超過)。**これを標準の契約にしてはいけない。**

- **経路 C (t = s² 上で補間) が最良**。偶関数性を座標で担保するので、
  s=0 の傾きの問題が構造的に消える
- **IUCr 格子は s=0 の傾きを 3 桁小さくする** (低 s に点を集めているため)
- ⚠ **ここで格子の順位が f_x のときと逆転する** — f_x の混合ゲートでは IUCr が
  4.16 で不合格、均一 Δs=0.05 が 0.27 で合格だったが、f_e では IUCr + 経路 C が
  最良になる。**単一の指標で格子を決められない**ことの実例

codex の最優先検査。閉殻 1s² は HF 交換が特別に単純で、KLI/OEP の自由度が激減する。

| Z | max \|Δf_x\| (絶対) | 構成 |
|---:|---|---|
| **2 He** | **2.810e-05** | 閉殻 1s² のみ |

**He は C の 250 分の 1。**⚠⚠ もし残差が**核モデル・物理定数・基底切り捨て・
格子・参照規約・実装差**に由来するなら **He にも同じ程度に出るはず**なので、

⚠ **ただし局所性と KLI 近似はまだ分離できていない** — 厳密 OEP を解いても
非局所 DHF と一致する保証は無いので、下記 3 が要る。

**残る検査** (未実施、codex の優先順):

**暫定の決着** (⚠ 凍結しない。下記の未決が残る):

- **共通格子 = 均一 Δs=0.05 (121 点)** — f_x の混合ゲートを通るのはこれだけで、
  f_e も経路 D で 0.04–0.05。IUCr は f_e では優秀だが f_x で 4.16、D でも 1.3–7.1
- **f_x は s 上の not-a-knot 3 次スプライン**
- **f_e は表に直接収録し、t = s² 上で補間する (経路 D)。**
  ⚠⚠ **「補間した f_x から f_e を導く」を標準契約にしない** — 経路 A は
  どの格子でも 1〜3 桁不合格

⚠⚠ **凍結前に必要なこと (codex 指摘):**

- **絶対床 1e-4 の根拠が弱い** (私が決めた恣意的な値)。決め方は 2 つあり、
  **厳しい方**を採る: (a) 補間誤差 ≤ 0.1 × 数値誤差目標 (表にしたことで
  エンジンの数値品質を目に見えて落とさない)、(b) 代表的な構造因子の許容誤差から
  $|\delta F_{hkl}| \le \sum_j o_j |\delta f_j|$ で逆算。
  ⚠ 現行 1e-4 は数値誤差 (7e-7) より **1–2 桁緩い**可能性がある
- 床を決め直してから、均一 0.05・IUCr・**両者の和集合**・均一 0.025 を再比較する。
  ⚠ 表は小さいので 62 対 121 点の最適化に意味は薄い
- ⚠ **格子探索に使った点と最終検証点を分ける** (同じプローブ集合で最適化と検証を
  やると格子に過学習する)
- 経路 D でも **CSV/JSON へ丸めて読み戻した後**の低 s 桁落ちを測る
- スプラインの overshoot で $f_x > Z$ になり **f_e が負**にならないか
- 言語間で not-a-knot の定義が一致するか / 上端外挿を禁止できているか

### 4.14 精度をどう宣言するか (codex の助言、2026-08-11)

⚠⚠ **「DHF に対し 0.32 % の精度」と書いてはいけない** — DHF を真値とみなし、
かつ差を誤差上界と読ませることになる。**分けて書く**:

- **numerical uncertainty** — 同じ Dirac+KLI 処方の計算誤差、~1e-06 級 (§4.7)
- **benchmark discrepancy** — OFFV1/DHF との差、最大 ~3.2e-03 (§4.8・§4.10)
- **model prescription** — 球対称 Dirac SCF + 局所厳密交換 (KLI)
- **interpretation** — DHF を近似再現するための**フィットではない**

⚠ **「Z≤18 は ≤3.2e-3 / Z≥26 は ≤1.6e-3」という層別はまだ書けない** —
**Z = 19–25 が未測定**で、境界 18/26 も結果を見てから引いている。
「tested elements」に限定するか、**全 Z を走査してから包絡線にする**。

## 5. 収録範囲

- **v1 は中性原子のみ**。⚠ 「任意価数」は一意な入力ではない — 同じ Z と電荷でも
  電子配置・準安定状態・占有の取り方が複数ある。現在の `compute_fx` も
  `get_neutral` を呼ぶ中性経路しか無い。イオンは、charge / 電子数 /
  occupation・configuration / 状態選択則 / SCF 処方まで明示した **curated set**
  として後から出す。「よくある酸化数だから」で量産しない
- 元素範囲は宣伝上の切りの良さ (Z=1–92 等) ではなく、**全元素が同じ QC を通る
  最大連続範囲**で決める。穴があれば隠さず exclusion と理由を出す
- ⚠⚠ **s 格子を先に決めない**。既定の `0:0.1:6` を標準にする根拠は弱い。
  上限・刻み・補間規約は**収束試験と補間試験の結果として**決まる。
  格子は入力仕様ではない

## 7. 出す形

(例: `dataset-factors-vX.Y.Z`)。理由は物理量も利用者も違い、E0 軸が存在せず、
版を上げる理由が独立していて、引用単位を分けられるから。F dataset の semantic
version を不必要に連動させない。

(`tables/` の運用は `tables/README.md`)。
