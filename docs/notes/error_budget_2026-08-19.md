# F(s, E₀) の誤差予算 (2026-08-19)

**★ この表の要点は数値ではなく KIND 列**。行によって「予算」「測定値」「標本上の観測最大」
「外部との差」「未測定」が混ざっており、**KIND が違う行は足せない**。数値は全部リポの
どこかにあるが、6 本以上の作業文書に散っていて、複数が本文で「これを上界と読むな」と
書いている。外部の人間がこれを正しく組み立てるのは不可能だった。

⚠ 出所は全部 `file:line` で書いた。**引く前に必ず現物を見ること**。

## 0. KIND の定義 (これを混ぜると嘘になる)

| KIND | 意味 | 足し算 |
|---|---|---|
| `acceptance-budget` | **リリース時に選んだ閾値**。誤差ではない。「これを超えたら出荷しない」 | ✗ 予算行にしない |
| `direct-measurement` | その条件で実際に測った値 | 条件が同じときのみ |
| `observed-max-over-sample` | **標本上の最大**。母集団の上界ではない | ✗ |

| `convention-or-setting` | 契約・幾何・設定。誤差項ではない | ✗ |
| `not-available` | 測っていない | — |

## 8. 結局どれが効くのか

観測量 (ALCHEMI のサイト比) の側から見ると、この表のほとんどの行は効かない。

1. **s < 2 Å⁻¹ の F の誤差**だけが効く。そこでの E₀ 補間誤差は **8.472e-05**、伝達係数
   1.42 を掛けて **サイト比への影響 ≤ 1.2e-04** — ただしこれは `scenario-sensitivity` で
   あって上界ではなく、1 結晶 1 方位の測定である
2. **絶対スケール**が要る用途では、支配的なのは Bote–Salvat の **10–24 %** であって
   この表の他のどの行でもない
3. **未解明の尾根差**は、それを全部我々のものと仮定しても F(s) で 2.2–4.8e-02。
   ⚠ ただし**未比較の ρ 0.3–0.8 帯のほうが重い** (σ の最大 39 % 対 尾根帯 5.79 %) ので、
   「尾根だけが未解明の残り」という読み方は成り立たない
4. **第三者検証は存在しない**。この表のすべては著者自身の測定である
