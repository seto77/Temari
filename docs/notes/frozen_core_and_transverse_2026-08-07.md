## 1. 厳密 frozen core — 実装

`prepare_channel(...; final_state = :relaxed | :frozen | :frozen_static)`。

| 処方 | 束縛が見る場 | 連続が見る場 | z_asym | model_id |
|---|---|---|---|---|
| `:relaxed` (**出荷**) | 中性の KS ポテンシャル (Latter 補正込み) | 緩和 core-hole イオン + KS(2/3) 交換 | 1 | 無印 |
| `:frozen` | 同上 | **同上と同一物** | 1 | `-FZ` |
| `:frozen_static` | 尾を 0 に落とした静的場 | **同上と同一物** | 0 | `-FZS` |

`:frozen` は束縛軌道を `:relaxed` と**同じ場**で解くので、始状態は**ビット同一**。
変わるのは連続状態が見る場だけ。だから束縛のキャッシュ鍵も共有してよい
(共有していること自体が「同じ場である」ことの担保になる)。`:frozen_static` だけ
別の場なので鍵に `"fzs"` を足す。

`:frozen` では空孔イオンの SCF が要らないので、元素あたり SCF 1 回分安い。

### 1.1 引き継ぎ書との違い — 尾は 0 ではなく −1/r

指示書 §2 は「連続状態は中性原子の場で解かれ、Z∞ = −lim r·V → 0」と書いていたが、
**Zhang らの一次情報を読むとそうではない**。彼らは FAC を使い (2024 論文 p.25):

> The solution is computed through a self-consistent Dirac–Fock–Slater method
> within a **modified local density approximation for the correct asymptotic
> behaviour of the exchange energy**. … To ensure orthogonality, we take the
> frozen core approximation that assumes **the potential remains unchanged for
> the initial and final states**.

「交換エネルギーの漸近を直した局所密度近似」= 自己相互作用補正 (Latter 型) なので、
**中性原子でも KS ポテンシャルの尾は −(Z−N+1)/r = −1/r**。frozen core の要点は
「同一ハミルトニアン」であって尾を 0 にすることではない。

物理的にもそちらが筋が通る: 放出されるのは**その原子自身の電子**なので、
自己相互作用を除いた KS ポテンシャル (尾 −1/r) を感じる。尾が 0 の静的場は
「外から飛来する余分な電子」が感じる場で、`phase` 出口 (弾性 δ_l) の担当。

両方実装したので測って選べる (§2)。

### 1.2 実装が正しいことの証明 — 直交性 (selftest T21)

同一ポテンシャルの束縛/連続固有関数は厳密に直交するので、`orthogonalize_l0!` が
除く重なり c が丸め誤差まで落ちる。

| | `:relaxed` | `:frozen_static` | 改善 |
|---|---|---|---|
| C K (ε=5 Ha) | −3.78e-3 | −8.04e-7 | 4700 倍 |
| Fe K (ε=5 Ha) | −4.03e-4 | +1.30e-10 | 3.1e6 倍 |
| Fe L3 (ε=5 Ha) | −8.09e-5 | −9.89e-8 | 818 倍 |
| **Au L3 (ε=5 Ha)** | −7.96e-5 | **+3.8e-14** | **2e9 倍 = 丸め誤差** |

⚠ **この測定は束縛も非相対論 Numerov で解いている**。本番経路の始状態は
Dirac の大成分、連続はスカラー相対論/Schrödinger で、**演算子が違う**。
ポテンシャルを揃えても (Zα)² 級の重なりが残るので、**本番の `max_ortho_c` は
frozen にしても下がらない** (Fe K で 2.1e-2 のまま)。これは frozen core の
欠陥ではなく処方の別次元 — 直せるのは κ 分解 Dirac 連続状態 (指示書 §5.2)。
この切り分けを飛ばすと「frozen core が効いていない」と誤読する。

## 2. 厳密 frozen core — Zhang らの Dirac GOS DB との比較

### 2.1 ⚠ 先に確定させた占有数の規約

先方の DB は **L2 と L3 に同じ値**を入れている (Fe で 1.296e-2 と 1.333e-2)。
我々/先方の比を測ると **L2 が 0.300 ≈ 2/6、L3 が 0.598 ≈ 4/6** と、
きれいに我々の副殻占有数を 6 で割った値になる。つまり

> **先方の L2/L3 は (n,l) 殻まるごと (2p = 6 電子) で規格化されている。**
> K と L1 は殻 = 副殻なので補正 1。補正係数 = 2(2l+1)/(2j+1)。

これを入れないと L 殻の比が 2/3 倍・1/3 倍ずれる。Fe の L2 と L3 が補正後に
0.998 と 0.993 と一致することが、規約が正しいことの傍証になっている。

### 2.2 結果

比 = (我々) / (先方)。**実用 EELS 窓 (ε ≥ 10 eV, q ≤ 8 Å⁻¹)** の平均。

| | `:relaxed` (出荷) | `:frozen` | `:frozen_static` |
|---|---|---|---|
| Fe K | 0.9425 | **0.9664** | 0.9684 |
| Fe L1 | 0.9940 | **1.0037** | 1.0053 |
| Fe L2 | 1.0067 | 0.9979 | 0.9960 |
| Fe L3 | 1.0016 | 0.9933 | 0.9913 |
| Au L2 | 0.9869 | 0.9721 | 0.9706 |
| Au L3 | 0.8951 | 0.8835 | 0.8822 |

読み方:

- **Fe K のギャップは 4 割ほど閉じる** (−5.8 % → −3.4 %)。指示書が予備実験から
  期待した「ほぼ閉じる」までは行かない
- Fe L1 も改善 (−0.6 % → +0.4 %)。Fe L2/L3 は元々 1 % 以内で、僅かに悪化
- **Au L3 は全処方で 0.88–0.90** — 処方ではなくチャネル固有の問題。frozen かどうかで
  1 % しか動かない。frac_small = 1.85 % で、小成分の行列要素 (指示書 §2) と
  κ 分解 Dirac 連続状態 (§5.2) が候補
- `:frozen` と `:frozen_static` の差は 0.2 % 以下。**尾の 0 か −1/r かは、
  実用窓では効かない**。効くのは閾値直上 (ε ≈ 2 eV) で、そこでは静的場の方が
  30 % 以上低く出る (引力が無いので閾値近傍の振幅が落ちる)

⚠ **全格子平均 (ε 2–580 eV、q 0.2–30 Å⁻¹) を取ると別の数字が出る**
(Fe K で 0.961 → 1.003)。閾値直上と q ≥ 16 Å⁻¹ の隅は両処方の差が最も大きく、
かつ我々の近似が最も弱い領域なので、平均に入れると結論が変わってしまう。
**実用窓の数字を正本とする。**

### 2.3 端エネルギーの定義差は「隠していた」側

GOS は ΔE を陽に含むので、端の定義差はそのまま前因子に乗る。
我々 = Bote 表 (Fe K 7083.5 eV)、先方 = 計算値 (6960.5 eV) で **+1.8 %**。
我々の GOS は元々低いので、**この差は不一致を隠している**。補正すると
Fe K `:frozen` は 0.9664 → 約 0.950 と、むしろ悪くなる。

つまり「数 % の GOS 差」の内訳は、frozen core が約 2.4 ポイント、
端の定義が約 −1.7 ポイント (逆符号)、残りが小成分と κ 分解。

## 3. 横断的 (Møller) 相互作用

`--transverse` (edge 出口のみ)。`compute_NK(...; transverse=true)`。
相互作用核だけが変わり、行列要素側は一切変わらない。

### 3.1 ⚠ 指示書に写された式 38 は横断項の分母に q² が落ちている

指示書 §3 の式をそのまま組むと、**Fe K @200 keV の σ が 21 倍**になって破綻した。
原因は次元:

    1/q⁴                                   [長さ⁴]
    β_t²(ΔE/ħc)²/(q²−(ΔE/ħc)²)²           [長さ²]   ← 揃わない

正しい核は

    W(q) = 1/q⁴ + β_t² (ΔE/ħc)² / [ q² (q² − (ΔE/ħc)²)² ]
    β_t² = β² − ΔE²/(cq)² · (1 + ((cq)² − ΔE²)/(2ΔE(E₀ + m_ec²)))

これは次元が合う上に、**同じ論文の式 42 と双極子極限で厳密に一致する** (§3.2)。
式 42 は別出典 [60,65,66] からの引用なので、独立な外部照合になっている。

### 3.2 式 42 との照合 (selftest T22b)

小角では q² = k_i²(θ² + θ_E²)、θ_E = ΔE/(γm v₀²)、(ΔE/ħc)² = β²k_i²θ_E² なので
q² − (ΔE/ħc)² = k_i²(θ² + θ_E²(1−β²))。双極子 S ∝ q² を核に当てて θ₀ まで積分すると

    σ_rel/σ_conv = [ln((x + 1 − β²)/(1 − β²)) − β²x/(1 − β² + x)] / ln(1 + x),
    x = θ₀²/θ_E²

に**厳密に**なる。18 ケース (x = 0.03 … 9.6e3、E0 = 100–300 keV、
ΔE = 100–1000 eV) で最大差 **2.8e-4**。

⚠ **論文の印字は第 1 項が ln((1+x)/(1−β²))** で、これは x ≫ β² の近似
(θ₀ → 0 で比が 1 に落ちない)。厳密な原始関数に直して初めて全域で比べられる。
印字どおりの式 42 と印字どおりの式 38 を突き合わせても、両方の近似・誤りが
別方向に効くので判定できない。

q² を落とした版だと、この照合で 1.0736 に対して **1.0003** が出る。桁で外れるので
検査として十分に鋭い。

### 3.3 σ への効き

σ_own(横断あり)/σ_own(なし) − 1、および σ_own/σ_Bote の変化:

| チャネル | E0 [keV] | β² | 横断寄与 | σ_own/σ_Bote (縦のみ) | (横断込み) |
|---|---|---|---|---|---|
| C K | 60 | 0.199 | +0.3 % | 0.889 | 0.892 |
| C K | 200 | 0.484 | +2.2 % | 0.863 | 0.882 |
| C K | 400 | 0.685 | +5.5 % | 0.833 | 0.879 |
| **Fe K** | 60 | 0.199 | +0.6 % | 1.063 | 1.069 |
| **Fe K** | 200 | 0.484 | +3.9 % | 0.968 | **1.007** |
| **Fe K** | 300 | 0.603 | +6.7 % | 0.933 | **0.996** |
| **Fe K** | 400 | 0.685 | +9.4 % | 0.904 | 0.990 |
| **Au L3** | 60 | 0.199 | +0.7 % | 1.044 | 1.051 |
| **Au L3** | 200 | 0.484 | +4.3 % | 0.984 | **1.026** |
| **Au L3** | 300 | 0.603 | +7.1 % | 0.950 | **1.017** |

指示書 §3 の検査:

1. **c → ∞ で消える** — 0 ulp (T22)
2. **低 E0 で小さく高 E0 で増える** — β² に沿って単調 (T22)
3. **σ_own/σ_Bote が 1 に寄るか** — **寄る。しかも効き方が正しい。**
   縦のみだと σ_own/σ_Bote は E0 とともに単調に落ちる (Fe K で 1.063 → 0.904、
   15 % のドリフト)。横断項を入れるとこの**ドリフトそのものがほぼ消える**
   (1.069 → 0.990)。単に定数倍で近づいたのではなく、**E0 依存性の形が合った**ので、
   「Bote–Salvat が持っていて我々が持っていなかった項」の一つを特定したと言える
4. 検証先を Llovet 2014 (NSRDS 164) の実験集成へ移す — **未実施** (§7)

⚠ 循環比較であることは変わらない (σ_Bote は出荷値)。ただし 3 の「形が合う」は
循環比較でも意味を持つ — Bote–Salvat は DWBA で横断項を含むので、
我々に足りない項が入って E0 依存性が揃うのは予想と一致する。

### 3.4 適用範囲

**K = 0 の分岐 (σ・EELS) 専用。** F(s) の MDFF は Q₊ ≠ Q₋ の混合形式で、
横断項の混合形をどう取るか (Q₊·Q₋ か、Q± それぞれか) に別の処方判断が要る。
`compute_NK` は K ≠ 0 と併用されると停止する。

## 4. F(s) はどれだけ動くか

出荷 s グリッド全域での max|ΔF| (F(0)=1 規格化後)。σ は横断項なし。

| ケース | σ/σ_Bote (`:relaxed`) | (`:frozen`) | max&#124;ΔF&#124; | その s |
|---|---|---|---|---|
| C K 200 kV | 0.865 | **0.981** | 2.28e-2 | 0.25 |
| Fe K 200 kV | 0.968 | 0.990 | 3.62e-3 | 2.00 |
| Sr L3 40 kV | 1.071 | 1.078 | 8.06e-4 | 1.25 |
| Cd K 300 kV | 0.975 | 0.985 | 1.77e-3 | 4.00 |
| Au L3 300 kV | 0.950 | 0.953 | 2.02e-4 | 3.00 |

- **F(s) はほとんど動かない**。軽元素の C K で 2.3 %、他は 0.4 % 以下、
  Au L3 では 2e-4。指示書 §2 の⚠「Oxley–Allen / µSTEM との外部検証と衝突しうる」は、
  **少なくとも重元素では杞憂**。C K だけは要確認
- 一方 **σ_own/σ_Bote は frozen で明確に良くなる** (C K 0.865 → 0.981)。
  σ は N(0) = Q → 0 の極限に効く量で、そこは直交性が最も効く領域だから筋が通る
- `:frozen` と `:frozen_static` の差は F(s) では 3 桁目以下

⚠ **Oxley–Allen / µSTEM そのものとの比較は本リポでは行わない** (公開リポの方針)。
ReciPro 側ローカルで、上の max|ΔF| を「動いた量」として当てること。

## 6. 作者判断待ち

1. **出荷の終状態処方を `:frozen` に替えるか。** 材料は §2 と §4。
   替えるならテーブル全再生成とセット。**替えない理由もある** — `:relaxed` は
   Oxley–Allen / µSTEM との A/B で選ばれた処方で、GOS の改善は Fe K の 2.4 ポイントに
   留まる (Au は改善しない)
2. **出荷 σ を自前値にするか。** まだ早い。横断項で E0 依存性は合ったが、
   絶対値の検証先が Bote–Salvat のままで循環している (§7)
3. **`--transverse` を既定 on にするか。** F(s) に効かない (K=0 専用) ので
   出荷テーブルには影響しないが、EELS 出口の既定処方が変わる
