## 1. 返却フィールド (「出すのは 5 つ」ではなく列挙で決める)

| フィールド | 量 | 単位 | 定義 |
|---|---|---|---|
| `d2sigma_dOmega_dE` | 二重微分断面積 | nm²/sr/eV | 散乱角 θ・損失 ΔE についての微分 |
| `dsigma_dE` | 開口積分後の微分断面積 | nm²/eV | `∫_{Ω(β)} d²σ/dΩdE dΩ` |
| `sigma_partial_own` | 部分断面積 (自前規格化) | nm² | `∫_{Δ₁}^{Δ₂} dΔE ∫_{Ω(β)} d²σ/dΩdE dΩ` |
| `sigma_partial_bote` | 同 (Bote 規格化) | nm² | ★ §1.1 の式で構成する |
| `sigma_total_own` | 総断面積 (自前) | nm² | β=π・全 ε |
| `sigma_total_bote` | 総断面積 (Bote–Salvat) | nm² | 出荷 F テーブルと同じ出所 |
| `k_factor` | k-factor | 無次元 | ★ §1.2 |
| `model_id`, `units`, `quadrature`, `numerical` | provenance | — | §4、§5 |

### 1.1 ★ Bote 規格化の定義 (codex の blocker 4)

**規格化はチャネルごとの定数倍**であり、その式を契約に**直接書く**:

    σ_bote(β, Δ) = σ_own(β, Δ) · [ σ_Bote,total / σ_own,total ]

⇒ **微分量・角度積分・窓積分のどの段階で掛けても同じ** (可換。§6.1 のゲートで検査する)。
⚠ **「全域で Bote の σ に一致する」と言えるのは総積分についてだけ**で、
部分角・部分窓の**形**の検証にはならない (構成上の恒等式)。**そう書くこと。**

### 1.2 ★ k-factor の定義と、ゼロ分母の規則 (codex の blocker 2)

    k_{A/B} = σ_B / σ_A          C_A/C_B = (I_A/I_B) · k_{A/B}

- **A と B は同じ `e0_keV`・同じ開口 (β、および環状なら β_in)・同じ端相対窓**を要求する。
  違うものを混ぜたい場合は**明示的に別モード**にする (既定では拒否)
- **どちらの σ から作るかを `k_factor_normalization` に書く** (`own` / `bote`)。
  ⚠ **A と B で規格化係数が違う**ので、k-factor は規格化の選択で変わる
- ⚠⚠ **ゼロ・微小分母**: `σ_A = 0` (β=0、ゼロ幅窓、運動学的に空、切り詰め後に空) では
  k-factor は**返さず構造化エラー**。`Inf` / `NaN` を通常の結果として返さない
- ★ **分母の床は相対値**: `σ_A < 1e-10 × σ_total_own` ならエラー (作者決定 §9.1)。
  ⚠ 絶対値 (nm²) で置かない理由 = 元素と端で σ の桁が 4 つ違うため
- ⇒ **§6.1 の `k_AA = 1` は `σ_A > k_factor_min_sigma` の条件つき**

## 2. 範囲 (v1)

### 2.1 含むもの

- **孤立原子・平均場・第 1 Born の内殻 1 チャネル**、**平行照明 (α = 0)**
- **軸対称の円形開口** `θ ≤ β`、**同心環状開口** `β_in < θ ≤ β_out`
  (★ **直接区間積分で出す**。`σ(β_out) − σ(β_in)` では出さない — §9.1)
- **横断的 (Møller) 相互作用**: 既定 on (`edge` 出口の 2026-08-08 からの既定)。`model_id` に出す
- **端相対のエネルギー窓** `[E_th + Δ₁, E_th + Δ₂]`

### 2.2 含まないもの (**明記する**)

ELNES・白線の高さ・化学シフト・多重散乱・検出器応答・プラズモン背景・固体の DOS・
非軸対称/偏心開口・**経験的なバックグラウンドモデル**。

⚠ 対応する実験量は「**同じ窓で背景を差し引いた計数**」と書くに留める。

### 2.3 ⚠ 有限 α (収束照明)

作者判断 (2026-08-18) で**実装を限定しない**が、**契約に何を書くかは別問題**:

- **非干渉な角度平均**なら、θ 分解された `d²σ/dΩdE` から後で積める
- **干渉するプローブ**なら**対角 `S(Q,Q)` では足りず、非対角 MDFF `S(Q₊,Q₋)` が要る**

⇒ **v1 では `alpha` をパラメータとして受け付けない** (codex の推奨。私も同意)。
**黙って無視するくらいなら拒否する。**

## 3. パラメータと入力検証

⚠ 規則は**実測 (§7.2、§7.3) で見つかった穴**に対応する。**方針の選択は作者判断**。

| パラメータ | 検証 |
|---|---|
| `z`, `channel` | `available_channels` に無ければ拒否 |
| `e0_keV` | 閾値以下は拒否。**NaN / Inf は拒否** |
| `beta_mrad` | ★ 下記 |
| `beta_in_mrad` | 省略可。`0 ≤ β_in < β_out` を要求 |
| `delta1_eV`, `delta2_eV` | ★ 下記 |
| `transverse` | 既定 on。`model_id` に出す |
| `normalization` | `own` / `bote`。★ **既定は `bote`** (作者決定)。両方常に返す |
| `alpha_mrad` | **受け付けない** (§2.3) |

⚠ **NaN / Inf の拒否はすべての数値パラメータに掛ける** (草案 v1 は β しか書いていなかった)。

**β の規則**:

- `β < 0` → **拒否** (⚠ 素朴な実装は `sin²` のせいで**正の開口として通る**: §7.3)
- `β` が NaN / Inf → **拒否** (⚠ NaN はそのまま伝播する)
- `β = 0` → **0 を返す** (数学的に正しい。契約に明記)
- `β > π` → **拒否** (codex 推奨で確定してよい。π は幾何学的上限。**黙って飽和しない**)

**エネルギー窓の規則**:

- `Δ₂ < Δ₁` → **拒否** (⚠ 素朴な実装は**黙って負の σ を返す**: §7.2)
- `Δ₁ < 0` → **拒否**、`Δ₂ = Δ₁` → **0 を返す** (明記)
- `Δ₁ > ε_max` → **拒否** (切り詰めても空)
- `Δ₂ > ε_max = T₀ − E_th` → ★ **既定は拒否**。`clip=true` を明示したときだけ切り詰め、
  **`requested_window_eV` と `effective_window_eV` の両方を返す**。
  ⚠ **黙って通すと NaN** (§7.2)

**環状開口の規則**: ★ **直接区間積分で出す** (作者決定 §9.1)。`0 ≤ β_in < β_out ≤ π` を要求。
⚠ 「外−内」では出さない — §7.6 A1 で相対 3 桁の劣化を実測した。
⇒ **環状は円形と同じ精度帯に入るので、§5B のゲートを別に緩める必要が無くなった。**

## 4. 規約 (曖昧にしたら契約として無意味になる箇所)

- **閾値の出所**: `E_th` は **Bote–Salvat の吸収端**。自前の Dirac 固有値は `E_bound_eV` として
  **別に**出す。⚠ 両者は 0.4–1.8 % 違う
- **占有数**: 副殻の `occupancy` をそのまま出す。⚠ 2(2l+1)/(2j+1) を**内部で勝手に掛けない**
- **角度**: β は**散乱角の半角** [mrad]。立体角は `Ω(β) = 2π(1 − cos β)`
- **エネルギー**: 窓は**端相対**。絶対損失も併記。区間は**閉区間**として扱う (積分値には
  効かないが、API の再現性のために決めておく)
- **単位**: nm² / eV / mrad。**JSON に単位フィールドを持つ**
- **`model_id`**: 横断項の有無だけでなく、**閾値データの版・動径応答の版・求積処方・
  規格化処方**を含める (codex)
- **`dσ/dE(β=π)` が一致する相手**は **`own` 規格化の既存 `edge` 出口**であると明記する

| l | l′ | 行数 | 中央値 | 最悪 |

**d 始状態は双極子の終状態が f 波で、遠心障壁が閾値直上を抑えるため、断面積の最大が

⚠ **「l=2 だけが難しい」と一般化してはいけない** — l=0 でも最悪 1.09e-03 が出る。
⚠ **Wigner の閾値則は原因ではない** (ε = x² と置けば任意の整数 l′ で解析的になる)。

⚠⚠ **現行 JSONL は行最悪とその位置しか持たない**ので、236,728 窓を計算していても
**幅別・開始位置別の分布は復元できない**。次の認証では層別に保存すること。
実測の最悪は 14,795/14,796 行で **幅 1000 eV の窓**が作った。

#### 5A.3 ★ 「2 経路が互いに頭打ちになる床」の正体

旧記述「~1e-08、原因未特定」を差し替える。実測 (`window_quadrature_2026-08-19.md` §2.7):

- 同じ ε を 5 回評価すると**全部ビット同一** ⇒ 確率的ノイズではない
- ε を ±1 ULP 動かすと f は 6.6e-16 しか動かない ⇒ f は ε に対して素直
- ところが**刻み幅を 1e-04 から 1e-10 まで 6 桁掃いても、4 階差 RMS が ~2e-09 で平ら**

⇒ 被積分関数は**相対振幅 ~2e-09 の決定論的な roughness** を持つ。
容疑者は**連続状態 ODE の積分格子が ε ごとに組み直される**こと (`CONT_PPW` /
`CONT_DT_LOG` から格子点の数と位置が決まるので、離散化誤差が ε の擬似ランダム関数になる)。

★ 辻褄が合う: Chebyshev 係数の床は 2e-09/√256 ≈ 1.3e-10 (実測 ~1e-10、積分値比)。

⚠⚠ **これは窓だけの話ではない** — 出荷の F(s) も同じ `eps_setup` を通る。
⚠ ただし F は ε 積分で平均されるので √n だけ薄まる。**F 側で実測してから書くこと**。
現時点で言えるのは「**窓経路の関数評価に 2e-09 級の高周波床を観測した**」まで。

### 5B. リリースゲート (経路ごとに分ける。⚠ 値は作者判断)

`partial` (β ≤ 100 mrad) / `large_beta` (100 mrad < β < π) / `full_angle` (β = π の互換経路) /
`annular` / `k_factor` の 5 経路に分け、**それぞれに rtol と atol の両方**を持つ。

⚠ **大 β を一律に緩めるのではなく経路別にする** — §7.4 の「難しさは β/θ_E で順序づくが

### 5C. 互換性負債 (**隠さずに書く**)

> `β = π` は既存 `edge` 数値経路との互換性を優先する。この経路の求積を改善すると
> **出荷テーブルの数値基準が変わる**ので、テーブルの全再生成・認証・`model_id` と
> 数値版の更新を伴う。**v1 では既存経路を維持し、その観測精度を別枠で表示する。**

⚠ **収束ゲートに「次数を倍にして動かない」を使わないこと** — スパイク §2 で **26 倍
過小評価**した実績があり、§7.5 では **n_x=96 が n_x=64 より悪い**ケースが複数出た。
**変数を変えた独立オラクル**か**係数つきの漸近**を使う。

## 6. ゲート

### 6.1 外部参照が無くても効く内部ゲート

- 非負・有限
- `d²σ/dΩdE` を立体角で積分すると `dσ/dE` に戻る / それを ε で積分すると `sigma_total_own`
- **β → 0 と窓幅 → 0 で 0**、かつ **β→0 の係数つき漸近** `σ(β) → 4π sin²(β/2)·S(Q_min)·W(Q_min²)`
- β を広げる・窓を広げると**単調増加**
- **互いに素な 2 窓の加法性**。⚠ **恒等式ではない** (別々の求積)
- `k_{AA} = 1`、`k_{A/B}·k_{B/A} = 1` — ⚠ **`σ_A > k_factor_min_sigma` の条件つき** (§1.2)
- 既存の **T11b** (水素 GOS 面) と **T22b** (横断カーネル)

### 6.2 ★ codex のレビューで足したゲート

- **累積量と微分量の関係**: `dσ(β)/dβ = 2π sin β · d²σ/dΩdE|_β`
- **β=π の分岐の連続性**: `π−δ` と `π` の差を、**欠けた立体角の直接積分**と照合する
- **薄い環状開口を直接区間積分と比べる** — ⚠⚠ **「環状 = 外 − 内」は同じ実装どうしの
  恒等式であって精度検証ではない**。`β_out−β_in` を桁で掃引し、β_in≈β_out、β_out≈π、
  信号が数値床に近い環を測る
- **運動学上端の連続性と漸近** — ⚠ 「有限だった」は精度の認証ではない。`k_f→0` の
  独立な漸近か、変数変換オラクルが要る
- **Bote スケールの可換性** — 微分・角度積分・窓積分のどの段階で掛けても同じ (§1.1)
- **解析的な人工被積分関数** (定数・低次多項式) で、**立体角のヤコビアンと単位変換を
  GOS/R_λ から独立に**検査する
- **`rtol + atol` の併用判定** (β→0・ゼロ幅・運動学端)

⚠⚠ **今の「独立オラクル」も同じ `R_λ(Q)` を使う** — 独立なのは**角度求積の変数だけ**で、
動径応答・補間・物理モデルまで独立に検証してはいない (codex)。

⚠⚠ **これは「決定論である」の証明ではない** — 測ったのは同一機・同一プロセスでの
2 回と、スレッド数 2 通りだけ。フリート負荷下で稀に 1–2 ULP が飛ぶ現象 (E8) は
**この測定では排除されていない**。

## 8. 主張してはならないこと

- ❌ **「実験検証済みの k-factor」**
- ❌ **「Bote 規格化版が Bote と一致するので検証された」** — **構成上の恒等式**。
  しかも**総積分についてのみ**の話で、部分量の形の検証にはならない
- ❌ **「数値予算 = 全体の誤差」** — §5 は**求積の誤差だけ**。物理の処方の誤差は別
- ❌ **「≤ X が保証値」** — §5A は**観測標本上の最大値**であって領域全体の上界ではない
- ❌ **「収束を確認した」を、次数倍増の自己一致だけで言う** (§7.5 が反例)
- ❌ **「独立オラクルで検証済み」** — 独立なのは**角度求積の変数だけ**。
  動径応答・補間・物理モデルは共通
- ❌ **「環状開口は外−内で検証した」** — **同じ実装どうしの恒等式**
- ❌ **「尾根の食い違いは影響しない」** — 小さいと**測った**が、**ρ 0.3–0.8 (σ の
  25–39 % を運ぶ) は未比較**
- ❌ **「α を受け付けるが平行照明として扱う」** — **黙って無視するくらいなら拒否**
