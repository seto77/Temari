## 0. 三行で

1. **v3 = v2 + 窓の等比パネル数 24** (θ = atan(√ε, √(ε_max−ε)) 上の等比 24 パネル × GL16 = 384 点。θ₁ = 0 の最下
   パネル規則・ε_c 境界・角度 (継ぎ目分割 GL12)・n_q 1216・HIGH 連続状態・l_max = min(128, ⌈κ·r_core⌉+12)・
   規格化は v2 と同一)。費用は v2 の ≈ 1.5 倍
2. **理由**: pilot v2 の残る不合格 (β = 200 mrad × 広がった軌道 × 高 ε の窓、格子内 3.2e-07 / 格子外 3.9e-06) は
   2×2 で**純粋な窓求積の不足** (margin・ppw・cap に不変、32 vs 48 パネル 2e-09) と帰属され、パネル数掃引で
   24 が足りた。`large_beta` の閾値を緩めて合格させる道は取らない (codex 2026-08-20)
3. **オラクル・合否・標本・β・保存項目は v2 と同一** (rtol 1e-7 + atol 1e-9·σ_ref、sentinel 11 行、deep = 525ch × E₀ 3 点)。
   ⚠ オラクルは √ε 上の等比 **24** パネル × GL16 — v3 の本番と**パネル数が同じ**になる (座標は違う)。
   座標の差だけでは独立性が弱いので、**オラクルのパネル数を 32 に上げる** (`V2_ORACLE_NPAN` 24 → 32、v3 のときだけ)
   ⇒ 認証域の指紋 (`domain`) も変わる。v3 の P−O は「θ 等比 24×16 vs √ε 等比 32×16」
