## 測定した処方

出荷 (SRC + 緩和 core-hole + Xα) を基準に、5 つの変種を同じ物差しで測った:
`+KLI` / `+frozen` / `kdirac` / `kdirac+KLI` / `kdirac+frozen`。
対象は K 殻 7 ケース (Z = 6, 8, 14, 26×2, 29, 47) と L3 殻 4 ケース
(Z = 26, 38, 47, 79)、参照は OA2000 と µSTEM の両方 (L3 は µSTEM 2p のみ)。

## 結論 (順位のみ)

### K 殻 — **κ 分解 Dirac が明確に勝つ**

- `kdirac` が **Z = 6 から 29 の全ケースで、OA2000 と µSTEM の両方に対して
  乖離を減らす**。改善幅は軽元素で小さく、中重元素で大きい (Fe では乖離が
  1/4 以下になる)。唯一 Z = 47 だけ僅かに悪化する
- `+frozen` は**明確に悪化させる**。軽元素ほどひどく、C では乖離が 3 倍に育つ。
  引き継ぎ書 §2 の⚠「緩和 core-hole は Oxley–Allen / µSTEM との A/B で
  選ばれた処方で、F(s) を最も動かした要素」という警告が**実測で裏付けられた**
- `+KLI` はほぼ中立 (Z ≥ 8 で僅かに改善、Z = 6 で僅かに悪化)

### L3 殻 — **KLI が勝つ。κ 分解 Dirac は決め手にならない**

- `+KLI` が**最良**。Fe・Sr・Ag で大幅に改善し (Ag ではほぼ参照に張り付く)、
  Au は変わらない。K 殻でほぼ中立だったのと対照的
- `kdirac` は **2 勝 2 敗** — Fe で改善、Au で同等、Sr と Ag で悪化。
  K 殻での一貫した改善とは対照的で、L3 では決め手にならない
- `+frozen` は混在 (Fe で改善、Sr で悪化、Ag・Au は同等)。K 殻での明確な
  悪化とは違い、L3 では判定できない

⚠ **K と L で最良の単独処方が違う**。K は連続状態の相対論 (κ 分解) が効き、
L は束縛側の交換 (KLI) が効く — 波動関数の広がりが違うので筋は通る。

### `kdirac + KLI` — **2 つは直交するつまみとして合成される**

- **L3 では 4 ケース全部で `kdirac` 単独より良くなる**。Fe では `KLI` 単独
  (連続側そのまま) よりもさらに良い。つまり KLI の効きは連続側の処方に
  ほとんど依存せず、**素直に足し合わさる**
- K 殻でも `kdirac` 単独とほぼ同じ (Z=8・14・26 で僅かに改善、Z=6・29 で僅かに悪化)
- **全 11 ケースの平均乖離では `kdirac+KLI` が最良**。出荷処方から約 1/3 減る

⚠ ただし**一様に最良ではない**:

- `kdirac` が L3 の Sr・Ag を悪化させる分は、KLI を足しても取り戻しきれない
  (この 2 つは `KLI` 単独が最良のまま)
- Z=6 の K 殻は KLI が僅かに悪化させるので、`kdirac` 単独が最良
- Z=47 の K 殻は**出荷処方が最良** (`kdirac` が唯一負ける K のケース)

## なぜ κ 分解は K で効いて L で効かないのか

**理由がある。対症療法ではない。**

κ 分解が非相対論の扱いと違うのは、**終状態のスピン軌道分裂**
δ_{κ=+l′} − δ_{κ=−(l′+1)} を通してだけである。それを実測すると:

| | l′=0 (s) | l′=1 (p) | l′=2 (d) | l′=3 (f) |
|---|---|---|---|---|
| Fe ε=500 eV | **恒等的に 0** | 2.69e-2 | 6.11e-3 | 1.76e-3 |
| Ag ε=500 eV | **恒等的に 0** | 9.32e-2 | 2.36e-2 | 5.95e-3 |

- **l′=0 には κ = −1 しか存在しない**ので、s 波の分裂は**恒等的にゼロ**
- p 波で最大。d で 4 分の 1、f でさらに 4 分の 1 と急速に落ちる
  (遠心障壁が波動関数を核近傍から押し出すので、スピン軌道が届かなくなる)

ここに双極子選択則を重ねる:

- **K 殻 (l = 0)**: λ = 1 の終状態は **l′ = 1 (p)** — **分裂が最大の波そのもの**
- **L 殻 (l = 1)**: λ = 1 の終状態は **l′ = 0 (分裂ゼロ)** と **l′ = 2 (4 分の 1)**

つまり **K 殻の主要チャネルは分裂最大の波に正面から乗り、L 殻の主要チャネルは
分裂ゼロの波と減衰した波に乗る**。κ 分解の効きが K ≫ L になるのは構造的な帰結で、
元素や参照の癖ではない。

**その結果、L 殻の残差は別の要因で支配される**。実測はそれが**束縛側の交換**だと
言っている — KLI が L で決定的、K でほぼ中立という向きは、1s が深く valence との
交換がほとんど効かないのと整合する。

⇒ **2 つのつまみは別々の物理的欠損に対応しており、その欠損がたまたま殻依存**。
両方入れるのは継ぎ接ぎではなく、両方の欠損を埋めることに相当する。

### ⚠ 棄却した仮説 (記録として)

「µSTEM の 2p は j 平均、我々の L3 は j 分解 (2p3/2) なので、違う物を比べている」
という説明を先に立てたが、**測って棄却した**。L2 と L3 を足した **2p 殻まるごとの
形状**で比べ直しても、`kdirac` は Sr と Ag を悪化させる (順位は変わらない)。

ただしこの測定自体には価値があった。**µSTEM が実際に計算しているのは殻合算**
(ラベルが `1s`/`2s`/`2p` の nl 表記) なので、そちらが正しい物差しであり、
そこで見ると **`kdirac+KLI` は 4 ケース (Fe・Sr・Ag・Au) すべてで出荷処方と
同等以上**になる (L3 単独で見えていた「Sr・Ag の後退」は消える)。
改善が最も大きいのは Fe で、Ag だけが実質同等にとどまる。

## ★ Z=47 と Z=6 の「後退」の根 — 外部参照が物差しとして効かない

深掘りした結果、**2 つの後退は同じ構造を持つ**ことが分かった。どちらも
「改良が悪化を招いた」のではなく、**µSTEM / OA2000 がその判定に使えない**。

### 発見: `kdirac` は相対論を足しているのではなく、SRC のアーティファクトを外している

連続状態の処方だけを 3 通り (非相対論 / SRC / kdirac) 変えて F(s) を比べた。
もし kdirac が「相対論を足す」ものなら 非相対論 < SRC < kdirac の順に並ぶはず。
実際は違った (K 殻、E0=200 keV、基準 = SRC 出荷、単位 %):

| Z | 非相対論 − SRC (s=1.25) | **kdirac − 非相対論** (s=1.25) | 同 (s=2.5) |
|---|---|---|---|
| 6 | +1.48 | **−0.31** | −0.65 |
| 14 | +1.57 | **−0.24** | −0.63 |
| 26 | +1.65 | **−0.11** | −0.23 |
| 36 | +0.92 | **−0.01** | +0.03 |
| 47 | +0.34 | **+0.05** | +0.19 |
| 79 | −0.01 | **+0.05** | +0.20 |

- **真の相対論補正 (kdirac − 非相対論) は最大 0.65 %、検証域 s ≤ 1.25 では
  0.3 % 以下**。しかも Z ≈ 36 で符号が変わる
- **SRC は非相対論から 1.5〜6 % ずれる** — 真の効果の 5〜20 倍
- **`kdirac` は非相対論のすぐ隣に着地する** (Z ≥ 26、s ≤ 1.25 で 0.11 % 以内)

⇒ **`kdirac` の改善の実体は「スカラー相対論近似の誤差の除去**」であって、
相対論の追加ではない。SRC は κ 依存部を落としつつ質量速度・Darwin 項と
一成分規格化を残した半端な近似で、その半端さが 1.5〜6 % の誤差を生んでいる。

⚠ 規約 (`norm2c`) のせいではない。SRC を 2 成分規格化に替えても Fe で
−0.27 % しか動かず、しかも**逆方向**。誤差はスカラー相対論の方程式そのものにある。

### これで Z=47 が説明できる

SRC のアーティファクトは Z とともに縮む (Fe +1.65 % → Ag +0.34 % → Au −0.01 %)。
一方 Ag には**連続状態の処方と無関係な +0.5〜0.7 % の超過**が最初からある
(全 s でほぼ一定のオフセット)。SRC のアーティファクト (負方向) がその超過を
**部分的に打ち消していた**ので、kdirac で外すと超過が露出する。

⇒ **`kdirac` は Ag で負けたのではない。隠していた不一致を露わにした。**
GOS で端エネルギーの定義差が不一致を隠していたのと同じ構造 (§2.3 相当)。
Ag の +0.5 % の出所は**未解明**だが、連続状態の処方ではないことは確定した。
(⚠ 2026-08-19 追記: → **解決済 (`docs/notes/src_defect_2026-08-07.md` §8、2026-08-07)**。
出所は**参照側** — µSTEM の Ag は有効 4 桁で小 s の挙動が桁で潰れ、OA2000 でも
(1−F)/s² が s→0 で一定にならない。我々の (1−F) は求積収束・s² 則を満たす)

### Z=6 の KLI も同じ構造

KLI は 1s を浅くして広げる (実測 ΔE_b/E_b と Δ⟨r²⟩/⟨r²⟩):

| Z | 6 | 8 | 14 | 26 | 47 |
|---|---|---|---|---|---|
| ΔE_b/E_b | −2.84 % | −2.48 % | −2.08 % | −1.21 % | −0.74 % |
| Δ⟨r²⟩/⟨r²⟩ | **+2.77 %** | +2.13 % | +1.31 % | +0.75 % | +0.45 % |

r 方向に広がれば運動量方向は狭まるので、F(s) は速く落ちる。C では
s=1.25 で **−1.86 % 動き** (これは自分の処方どうしの差なので載せられる)、
**その量が観測された乖離の増分とぴったり一致する**。
効果は Z とともに単調に縮み、Ag では 0.00 %。

**ここで効いているのは参照の世代である**。µSTEM も OA2000 も
Hartree–Slater 系 (局所 Xα 交換) の計算で、**我々の Xα 基準は参照と同じ近似を
共有している**。KLI はその近似を置き換えるのだから、参照から離れるのは当然。
軽元素ほど 1s の形に交換が効くので、離れ方も最大になる。

⇒ **µSTEM / OA2000 は KLI の可否を判定できない**。判定できるのは独立で
より高精度な参照 — **OFFV1 (DHF の計算値)** で、そちらは KLI を決定的に支持する
(C で相対 RMS 2.450 % → 0.153 %)。

### 結論: 物差しの選び方

| 判定したいもの | 使える物差し | 使えない物差し |
|---|---|---|
| 連続状態の処方 (SRC vs kdirac) | **自分の非相対論極限** (SRC の誤差が見える) | µSTEM / OA (Ag では別の系統に埋もれる) |
| 交換の処方 (Xα vs KLI) | **OFFV1 (DHF)** | µSTEM / OA (同じ Xα 系近似を共有) |

**Z=47 と Z=6 の「後退」は、どちらも物差しの選択の問題であって、処方の欠陥ではない。**

### ⚠⚠ 出荷データへの含意 — **作者の目が要る**

SRC が非相対論から 1.5〜6 % ずれ、真の相対論効果が 0.3 % 以下という測定は、
**出荷中の v3 データ (SRC 処方) が F(s) に 1〜2 % 級の近似誤差を持つ**ことを
意味する (検証域 s ≤ 1.25、Z = 14〜36 で最大)。

**求積のせいではない**。本番求積 (PROD) で測り直しても小数第 3 位まで同値:

| Z | 求積 | 非相対論 − SRC (s=1.25) | kdirac − 非相対論 (s=1.25) |
|---|---|---|---|
| 14 | QUICK / PROD | +1.567 / +1.569 | −0.241 / −0.243 |
| 26 | QUICK / PROD | +1.647 / +1.647 | −0.110 / −0.110 |
| 47 | QUICK / PROD | +0.343 / +0.343 | +0.047 / +0.047 |

さらに、外部参照との一致でも **Z ≤ 26 では非相対論 (v2) の方が SRC (v3) より
良い** (Fe では乖離が 4 分の 1 以下)。SRC が勝つのは Z ≥ 36 だけで、しかも Ag では
「自分のアーティファクトで別の超過を打ち消している」という勝ち方をしている。

⇒ **v2 → v3 で SRC を採ったのは、少なくとも軽・中元素では改良でなかった
可能性がある**。kdirac は非相対論のすぐ隣に着地するので、v4 で kdirac を採れば
この問題は自動的に解消する。

⚠ 反証の可能性も書いておく: 「SRC が誤り」ではなく「kdirac が何かを落として
いる」という読みもありうる。ただし kdirac は (a) 自由粒子で 3e-7、(b) c→∞ の
GOS 退化が物理効果の 1/94、(c) Zhang GOS DB との幅が 11.2→4.0 %、
(d) σ_own/σ_Bote が 5 例すべて 1 へ、と独立な 4 方向から支持されている。
**要追試は「SRC のどの項が 1.5-6 % を出しているか」の特定** (質量速度 / Darwin /
非整数次数 / 一成分規格化のどれか)。規格化でないことは測定済み (Fe で −0.27 %、逆方向)。

## 判断への含意

| | f_x (OFFV1) | GOS (Zhang) | σ_own/σ_Bote | **F(s) (OA/µSTEM)** |
|---|---|---|---|---|
| ① Dirac+KLI | **決定的に改善** | — | 僅かに悪化 | K 中立 / **L3 は明確に改善** |
| ② frozen core | — | Fe 改善・Au 悪化 | 全例改善 | **明確に悪化 (軽元素で顕著)** |
| ③ 横断項 | — | — | **改善** (E0 依存性の形も合う) | 影響なし (K=0 専用) |
| ④ κ分解 Dirac | — | **幅 11.2→4.0 %** | 5 例すべて 1 へ | **K は明確に改善 / L3 は 2 勝 2 敗** |
| **①+④ 併用** | ① と同じ | (未測定) | (未測定) | **全 11 ケース平均が最良** |

- **② frozen core を出荷既定にするのは支持されない**。GOS は Fe で改善するが、
  F(s) は外部参照から離れる。緩和 core-hole が A/B で選ばれた理由がそのまま生きている
- **③ は無条件で入れてよい** — F(s) を動かさないのでテーブル再生成も要らない
- **①+④ の併用が単一処方としては最良**。ただし一様ではない (上記⚠)。
  採るなら「平均で 1/3 改善する代わりに、L3 の Sr・Ag と K の Z=6・47 では
  現状より僅かに悪くなる」という取引を受け入れることになる

## ①+④ 併用での GOS と σ (2026-08-07 実施) — **KLI は GOS を悪化させる**

F(s) は測ったが GOS と σ が未測定だったので埋めた。

**σ_own/σ_Bote** (1 に近いほど良い):

| ケース | 出荷 SRC | SRC+KLI | kdirac | kdirac+KLI |
|---|---|---|---|---|
| Fe K 200 kV | 0.9683 | 0.9653 | **1.0041** | 1.0014 |
| Ag K 200 kV | 1.0228 | 1.0231 | 1.0743 | 1.0744 |
| Au L3 300 kV | 0.9498 | 0.9426 | **0.9907** | 0.9842 |

**Zhang GOS DB との比** (実用窓、1 に近いほど良い):

| key | 出荷 SRC | SRC+KLI | kdirac | kdirac+KLI |
|---|---|---|---|---|
| Fe K | 0.9425 | 0.9374 | 0.9408 | 0.9360 |
| Fe L3 | **1.0016** | 0.9492 | 0.9771 | 0.9280 |
| Au L2 | 0.9869 | 0.9661 | 0.9796 | 0.9602 |
| Au L3 | 0.8951 | 0.8692 | **0.9661** | 0.9410 |

⚠ **KLI は GOS を 4 ケース全部で悪化させる** (2〜5 %)。KLI は軌道を外へ広げるので
GOS の絶対値が落ちる。F(s) (形) では L で改善したのと逆向き。

**しかしこれは KLI の否定材料にならない**。Zhang らの FAC も
「交換エネルギーの漸近を直した局所密度近似」= **Xα 系の局所交換**を使う。
µSTEM・OA2000 と同じで、**3 つの外部参照はすべて Xα 系の近似を共有している**。
KLI はその近似を置き換えるのだから、3 つすべてから離れるのは当然。
**独立に判定できるのは OFFV1 (DHF) だけ**で、そちらは KLI を決定的に支持する。

⇒ **KLI の可否は「どの参照を信じるか」に帰着する**。DHF (第一原理計算) を採るなら
KLI、Xα 系の既存文献との整合を採るなら Xα。**作者判断。**

- **2p の混在は本書が事前に予測・説明したとおり**になった (上の「⭐ Z=47 と Z=6 の
  『後退』の根」)。SRC のアーティファクトが Sr・Ag の別の超過を打ち消していて、
  kdirac で外すと超過が露出する。**その超過の出所は依然として未解明**
  (⚠ 2026-08-19 追記: Ag K の +0.5 % については → **解決済
  (`docs/notes/src_defect_2026-08-07.md` §8)** — 参照側の小 s の振る舞い
  (µSTEM 有効 4 桁 / OA2000 の (1−F)/s² が s→0 で一定にならない)。
  ⚠ L3 の Sr・Ag の 2p 超過は同書 §8 の対象外で、そちらは本当に未解明のまま)
- ⇒ **参照が曖昧でない 2 つの系統 (K = 1s、L1 = 2s) では v4 が決定的に良い。**
  混在するのは、参照側と我々で「同じ物」を比べられていない、あるいは
  別の未解明の系統がある場合だけ

### 外部参照に依らない裏取り (これは数値も載せられる)

**K 殻の高 s 符号反転が消えた**。v3 は Z = 18–50 の K 殻が s > 4 で 1–2 回
符号反転し、`check_tables` の「K は正値・単調」判定を s ≤ 4 の窓に限定する
必要があった。**v4 では K 45 本すべてで符号反転ゼロ**、tail 成立率も
74.4 % → **100 %**。L1 の窓内ゼロ交差 (s グリッドを 8 Å⁻¹ へ延ばした理由そのもの)
も 67 本中 8 本まで減った。

**符号反転は「SRC が高 s の F を押し下げていた」ことの直接の帰結**だったので、
これは欠陥の除去が効いていることの、参照を一切使わない証拠になる。
