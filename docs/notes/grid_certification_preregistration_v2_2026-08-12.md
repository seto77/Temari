## 1. 認証する命題

> 処方 = 完全 Dirac SCF + 厳密交換 (KLI)、数値 backend = `dirac_true_midpoint_v1`、
> **固定区間 [r₀, r_max] = [1e-7, 60] a₀** の対数メッシュ・

- ⚠⚠ **これは「収縮仮定付き数値認証」である** (codex 訂正)。§3.1 の幾何級数の
  尾は**未観測の将来すべての段**について収縮率 ≤ q* を仮定する。観測した 2 比は
  その仮定の**経験的支持**であって、数学的保証ではない。
- ⚠ **「刻み幅極限」であって「真値」ではない**。モデル誤差 (KLI vs DHF、

- ⚠ **区間外 (r < 1e-7, r > 60 a₀) の切断誤差は本認証の対象外** — 全水準が同じ
  r₀/r_max を共有するので、刻み幅の細分では**原理的に検出できない** (codex 構造
  指摘 2)。別試験 = `tools/certify_endpoints.jl` (未実施)。
- ★ v1 (点ごと) と違い、L¹ 界は **s に一様**なので主張は離散節点に限られない。
  ただし補間・loader・丸めは別契約 (B_repr) のまま。

## 3. 凍結する判定式

### 3.1 上限

|j₀(sr)| ≤ 1 (任意の s) と Simpson 重みの非負性から、任意の s で

    |δf_x(s)| ≤ 4π Q_c[r²|Δρ|] ≡ ‖Δρ‖₁ + (求積第 1 項)

刻み幅極限への望遠鏡和に q* = 0.5 の幾何級数尾部を当て:

    E(dt/16) ≤ Σ_{k≥3} ‖Δρ_k‖₁ ≤ S_MARGIN · ‖Δρ₃‖₁ · q*/(1 − q*) + Q1_MARGIN
             = 1.1 · ‖Δρ₃‖₁ + 1e-13

★ **基底は ‖Δρ₃‖₁ である** (‖Δρ₄‖₁ ではない)。P2 の実測 (§6.2) で、‖Δρ₄‖₁ は
停止条件の変種に対して +17.8 % / +121 % 動く (真値が停止スケール以下) 一方、
‖Δρ₃‖₁ は ±3.4 % で安定だったため。**‖Δρ₄‖₁ は bound に使わず、q₃₄ の診断に使う**。

| 記号 | 値 | 意味 |
|---|---|---|
| q* | **0.5** | 尾の収縮仮定 (⚠ **q₃₄, q₄₅, … の未観測の全段に及ぶ**。観測する q₂₃ はその間接的支持にすぎない — codex) |
| `Q1_MARGIN` | **1e-13** | 求積第 1 項 (同一関数の 2 格子求積差) の明示加算。実測: 符号付き積分 (= s=0 での第 1 項) が 2〜3e-15、s>0 は計画書 §4.5 (s ≤ 24 で相対 1e-16) を援用。2 桁の余裕 |
| `S_MARGIN` | **1.1** | 停止・mixing 由来の L¹ 変動の乗算余裕。根拠 = ‖Δρ₃‖₁ の τ 締め差 (C で −3.4 %、§6.2) の 3 倍。⚠ **数学的上界ではなく「代表パネルで検証した普遍性仮定」** (codex 3 巡目)。**設計妥当性条件 = 代表パネル (C/Ar/Fe/Xe/Au) の β ストレス試験で D₃ 変動 ≤ 10 %** (§6.4)。破れたら S_MARGIN を後から拡大せず、**設計を開発へ戻す** |

### 3.2 q₂₃ の三領域 (v1 の欠陥「隙間を不合格にした」の再発防止)

**ゲート (適用条件) は q₂₃ = ‖Δρ₃‖₁/‖Δρ₂‖₁ のみ**:

| 領域 | 分類 | 意味 |
|---|---|---|
| q₂₃ ≤ 0.35 | `pass` | 主解析の合格候補 |
| q₂₃ ∈ (0.35, 0.5] | `uncertifiable` | **「不合格」ではない**。登録規則では認証不能 |
| q₂₃ > 0.5 | `model_violated` | 収縮モデル不適合 |

⚠ **q₂₃ はモデル検証ではなく適用条件である** (codex) — 認証対象の最初の
未観測比は q₃₄ であり、q₂₃ ≤ 0.35 を満たしても将来段の保証にはならない。

**q₃₄ = ‖Δρ₄‖₁/‖Δρ₃‖₁ は診断** (合否に使わない):
‖Δρ₄‖₁ > `Q34_SIGNAL` = 1e-9 の元素のみ `supports` (q₃₄ ≤ 0.5) /
`exceeds_tail` (> 0.5) を記録し、以下は `unresolvable`。
⚠ v2 起草時は q₃₄ もゲートだったが、**P2 実測 (β 0.2→0.15 で q₃₄ が
0.249→0.560) が「健全な元素が停止ノイズ次第で model_violated と誤判定される」
ことを示した**ため、走らせる前に降格した。観測支持が 2 比 → 1 比 + 条件付き
診断に弱まることは §7 に明記する。

## 7. この測定が答えていないこと (「認証した」と書くときに必ず併記)

| 範囲外 | なぜ |
|---|---|
| **未観測段の収縮** | 幾何級数の尾 (q₃₄, q₄₅, …) は仮定。**観測支持は q₂₃ の 1 比 + 信号のある元素の q₃₄ 診断に縮退した** (§3.2)。「厳密上界」「数学的保証」とは呼ばない |
| **区間外 (r₀/r_max) の切断誤差** | 全水準が同一区間を共有。刻み幅細分では原理的に見えない。別試験 (未実施) |
| **4 水準に共通する誤差** | 差分法の原理的な死角 (v1 の負のテスト D2 で実演済) |
| s の連続性のうち補間・loader・丸め | 別契約 B_repr = 9.09e-09 (未測定)。L¹ 界自体は s に一様 |
| SCF 停止 (production 側) | v1 の走の U (全 Z、B_scf の 0.036〜0.252) をそのまま使う。本走では測り直さない |
| 停止誤差の L¹ への混入 | S_MARGIN (工学的余裕) で覆う。⚠ **数学的上界ではない**。根拠 = β ストレス (C/Ar/Fe/Xe/Au の 5 元素、§6.4) + τ 締め差 (**C 1 元素のみ** — Ar の τ/100 変種は PC 再起動で中断・再開せず) |
| **低信号元素 (H/He 級)** | ‖Δρ₃‖₁ が停止スケール以下の元素は本規則では認証しない (uncertifiable_low_signal)。v1 の点ごと実測 (格子誤差 ~0×B_grid) を探索的証拠として別掲するに留める |
| Z > 86・イオン・励起状態 | 収録範囲の外 |
| モデル誤差 (KLI vs DHF) | 数値誤差の 4 桁上。X12 (OFFV1 照合) の仕事 |
| SCF 解の一意性 | `converged=true` でも別の不動点の可能性は残る |
| **L¹ 界の緩さ** | sup の 2.5〜2.8 倍 (層 A 実測)、かつ基底変更で v2 起草時よりさらに ~2 倍緩い。きつさが必要なら点ごとの評価に戻るが、それは本規則の外 |

## 8. 結果をどう書くか — 言い換えの規約

使う表現 (codex の性格づけに従う):

> Z = 1…86 の全元素について、密度差の L¹ ノルムに基づく
> **事前登録した多段収束試験** (4 水準、収縮モデル + 10 % 安定性余裕に基づく) を
> 実施した。観測した第 1 収縮比が適用条件 (q₂₃ ≤ 0.35) を満たす元素について、
> 将来段の収縮率を q* = 0.5 とする**保守的な幾何級数の尾の評価のもとで**、
> 採用格子 dt/16 の f_x への推定残差 (求積・停止余裕込み) が任意の s で
> B_grid = 6×10⁻⁸ 電子以下であることを確認した。

⚠ 使わない表現: 「証明した」「厳密上界」「数学的保証」「格子誤差が○○以下で
**ある**」(→「推定残差が○○以下であることを**確認した**」)。
短く呼ぶなら **「全 Z の事前登録済み・収縮モデル + 安定性余裕に基づく L¹ 数値認証」**。
