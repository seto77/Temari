## 0. 何を突き合わせているのか

| | 既定 (契約が約束する側) | オラクル |
|---|---|---|
| **窓** (ε 積分) | √ε 上の単一 Gauss–Legendre 16 点 | √ε 上の**複合** GL 4 パネル × 12 点 |
| **角度** (θ 積分) | **log-x** 上の GL (n_x = PROD = 64) | **t = sin²(θ/2)** 上の複合 GL |

規模 = **525 チャネル × 全 E₀ = 14,796 行** × 窓 16 種 × β 8 本。
⚠ `Δ₂ > ε_max = T₀ − E_th` の窓は**契約の規則どおり拒否**して `out_of_domain` に数える
(= 認証行列そのものが入力検証の負のテストになる)。

## 1. ★ オラクルは本当に独立か — 窓側だけ変数が同じだった

⚠⚠ 角度のオラクルは **log-x → t** と変数を変えているが、**窓のオラクルは √ε のままで、
単一 GL → 複合 GL と刻み方だけを変えている**。このリポには
「自己収束テストが誤差を 26 倍過小評価した」前例があり ([[self-convergence-underestimates]])、
**同じ変数・同じ族の一致を収束の証拠にしない**という規律がある。

⇒ **第 3 の方法**を当てて測った (`tools/window_oracle_probe.jl`)。

**第 3 の方法 = tanh-sinh (二重指数型) を ε 上で直接** — √ε 置換を挟まない。
節点は `u_k = tanh((π/2)sinh(kh))` で端点へ二重指数的に寄り、閾値端の `√ε`
立ち上がり (代数的特異性) を変換無しで吸収する。GL 族とは節点も重みも生成則も無関係。

### 1.1 結果 — ⚠ **床の上でだけ判定する**

標本 = 7 チャネル (Z=6 K の閾値直上と高過電圧 / Fe K ×2 / Ag L3 / Au M5 / Au L3) ×
窓 5 種 × β 4 本 = **140 組**。

| 集計の範囲 | 比 (第 3 の方法が見る誤差 / 複合 GL が見る誤差) |
|---|---|
| **全 140 組** | 最大 **91.07** |
| **床 1e-07 の上にある 25 組** | 中央値 **1.10** / 最大 **2.10** |

⚠⚠ **全体の 91 倍は雑音である**。この engine は両経路が互いに **1e-08 で頭打ち**になることが
分かっており (原因未特定、`docs/handover/next_chat_2026-08-19.md` §3)、1e-08 どうしの比は比ではない
([[signal-below-tolerance]])。**信号が床の上にある対だけで判定する。**

⇒ **複合 GL の窓オラクルは正直**である。第 3 の方法で測っても**係数 2.1 以内**。
26 倍の過小評価は起きていない。

⚠ ただし **これは 7 チャネルの標本での話**であって、全 14,796 行について
「オラクルが係数 2.1 以内」を示したわけではない。契約に書くときは標本を明記すること。

### 1.2 副産物 — 認証値との一致

同じ probe が出す `|既定 − 複合|` は、認証ハーネスの `worst_window` と一致する。
例: Z=6 K @30 keV、窓 [0,1000] eV、β=200 mrad で **9.48e-07** (認証の
`worst_window` = 9.479274360948259e-07 と同値)。⇒ probe と本体は同じものを測っている。

### 5.4 ★ 原因は究明済み

`docs/notes/window_quadrature_2026-08-19.md` が正本。要点だけ:

- **d 始状態は終状態が f 波で、遠心障壁が閾値直上を抑える** ⇒ 断面積の最大が**窓の内側**へ
  (Xe M4 は ε ≈ 10 eV)。高次 Chebyshev 成分が増え、GL16 の最初の未積分モード c_32 が大きい
- **全係数からの誤差再構成が実測と 3 桁一致**する (9.78e-03 vs 9.78e-03)
- ⇒ 対処は**次数を上げるだけ**。GL64 で 8e-07、GL128 で 2e-09。
  ⚠ **分割・複合・等比パネルは効かない**
- 「2 経路が互いに頭打ちになる床 ~1e-08」の正体は **連続状態 ODE の格子が ε ごとに
  組み直されることによる相対 ~2e-09 の決定論的 roughness**

⚠⚠ **2026-08-19 訂正 (同日夜の多エージェント監査。正本 =
`docs/notes/window_quadrature_2026-08-19.md` §2.7a / §7)** — 上の 3 点目・4 点目は**取り下げる**:

- 「**分割・複合・等比パネルは効かない**」は **Δ₁ = 0 かつ幅 ≤ 1000 eV** でしか成り立たない
  (山が区間の ~1 % を占める幅では分割の利得が出なかっただけ)。契約は幅を ε_max ≈ 4e5 eV
  まで許し、そこでは **√ε 単一 GL128 が 2.35e-03 まで悪化**する一方、**√ε 上の等比 16×16
  パネル (256 点) が 5.2e-09** で最良 (同書 §7.2 / §7.4a)。⚠ 認証が測った Δ₁ > 0 の窓は
  √ε ではなく**素の ε 上の GL** だった (`tools/beta_spike.jl:206`、同書 §7.1)。
  ⇒ **現在の推奨 = 全窓を √ε (または `ε = ε_max sin²θ`) に統一 + 等比 16×16 パネル**
  (同書 §7.6。⚠ 作者判断待ち、契約の窓は凍結しない)
- 「**床の正体 = ODE 格子の組み直し、振幅 ~2e-09**」は**帰属も振幅も誤り**。振幅は
  4 階差 RMS の値で、局所 3 次フィットの残差で測り直すと **~1.5e-10**。`eps_setup` の
  ε 依存の離散判断は最速でも 3 eV に 1 回しか切り替わらず、**切替密度が 7 桁足りない**。
  **機構は未特定** (有力候補 = 球ベッセル Miller 規格化のガード窓、`src/l0_numerics.jl:319-332`)。
  「床の正体を特定した」という主張は撤回する (同書 §2.7a)
