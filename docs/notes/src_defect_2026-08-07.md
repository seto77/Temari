# スカラー相対論連続状態 (SRC) の欠陥 — 追試の記録 (2026-08-07)

*出荷中の v3 データが使っている連続状態の処方 (第 3.5 章 SRC) に、
真の相対論効果の 5〜20 倍の誤差があることの測定と機構の特定。
きっかけは `docs/notes/fs_external_validation_2026-08-07.md` の外部照合。
**コードは変更していない** — 事実の記録と、作者判断のための材料。*

---

## 0. 結論

1. **真の相対論効果は小さい。**κ 分解 Dirac 連続状態と非相対論連続状態の
   F(s) の差は、検証域 s ≤ 1.25 で **0.3 % 以下**
2. **SRC はそこから 1.5〜6 % 外れる** — 真の効果の 5〜20 倍
3. **主犯は Darwin 項** (ずれの ~95 %)。切ると SRC は Dirac のすぐ隣に戻る
4. **機構も特定した**: 厳密な reduction では第 1 項が**小成分に比例**する。
   SRC はその中の 1 項だけを落とすが、**κ<0 では 2 項がほぼ相殺している**ので、
   残した方は物理的な項の 20〜500 倍の大きさになる
5. **⇒ v3 の F(s) は s ≤ 1.25 で 1.5 % 級の近似誤差を持つ。**
   非相対論 (v2) の方が真値に近い。κ 分解 Dirac (v4 候補) は真値そのもの

## 2. Attribution — Darwin 項が 95 %

SRC の診断スイッチを個別に切り、非相対論からのずれがどれだけ残るかを測った
(Z=26 K @200 keV、s=1.25、基準 = 非相対論):

| 処方 | 非相対論からのずれ |
|---|---|
| **SRC 既定 (出荷)** | **−1.620 %** |
| − Darwin 項 | **−0.066 %** |
| − 有限核 (点核) | −0.145 % |
| 2 成分規格化 (`norm2c=true`) | −1.883 % |
| − Darwin − 有限核 | −0.067 % |
| ★ κ 分解 Dirac (真の効果) | −0.110 % |

- **Darwin 項を切るだけでずれの 96 % が消え、真の効果のすぐ隣 (−0.066 vs −0.110) に戻る**
- Z=14 でも同じ (−1.543 → −0.076、真の効果 −0.241)、Z=47 でも同じ (−0.341 → −0.024)
- **規格化規約ではない** — `norm2c=true` はむしろずれを増やす (逆方向)
- 有限核単独の寄与は小さいが、**Darwin 項が入っているときだけ大きく効く**
  (点核だと Z=14 で −5.06 %)。Darwin 項が V″ と V′² を含み、
  核の特異性を拾うため

## 3. 機構 — 「片方だけ落とす」が破綻している

厳密な動径 Dirac から小成分を消去すると

    G″ = (M′/M)[G′ + (κ/r)G] + [κ(κ+1)/r² − k²loc] G,   M = 1 + (ε−V)/2c²

ここで**角括弧は正確に 2cM·F**、すなわち**小成分そのもの**である
(第 1 式 G′ = −(κ/r)G + 2cM·F の移項)。つまり第 1 項は −(V′/c)·F と書ける。

SRC はこの角括弧から **(κ/r)G だけを落とし、G′ を残す**。ところが原点近傍では
G ~ r^γ (γ ≈ |κ|) なので、**κ < 0 では G′ ≈ −(κ/r)G となり 2 項がほぼ相殺する**。
片方だけ残すと、物理的な項より桁違いに大きい偽の項が残る。

実測 |2cM·F| / |G′| (ε = 50 eV、核近傍 r = 1e-6 … 9e-4 a₀):

| | κ=−1 (l=0) | κ=−2 (l=1) | κ=−3 (l=2) | κ=−4 (l=3) | κ=+1 | κ=+2 |
|---|---|---|---|---|---|---|
| Z=14 | 5.3e-3 | 1.3e-3 | 5.8e-4 | 3.3e-4 | 2.0 | 2.0 |
| Z=26 | 1.9e-2 | 4.5e-3 | 2.0e-3 | 1.1e-3 | 2.0 | 2.0 |
| Z=47 | 6.5e-2 | 1.5e-2 | 6.6e-3 | 3.7e-3 | 2.1 | 2.0 |

- **κ < 0 (j = l+½) では相殺が 1/20 〜 1/3000。**SRC が残す G′ は物理的な項の
  20〜3000 倍。しかも比は 1/(l+1)² で落ちるので、**高い部分波ほど悪い**
- κ > 0 (j = l−½) では G′ ≈ +(κ/r)G なので相殺せず、比は 2。ここは問題ない
- 強度の大半は κ < 0 が担うので、全体としては大きく歪む

この偽の項が √M 置換で "Darwin 項" V_D に化ける。だから V_D を切ると
ずれが消える (§2)。

### ⚠ コード中の理由付けが誤っている

`src/l2_continuum.jl` 第 3.5 章の冒頭に

> κ(κ+1) = l(l+1) が κ = +l と −(l+1) の両方で成り立つので、これは j 平均
> (スカラー相対論) に相当し

とあるが、**これは正しくない**。落としているのは κ(κ+1) ではなく **(M′/M)(κ/r)G**
の方で、κ の (2j+1) 重み平均は

    ⟨κ⟩ = [(l+1)·(−(l+1)) + l·(l)] / (2l+1) = −1

であって **0 ではない**。したがって「丸ごと落とす = j 平均」ではない。

⚠ ただし **⟨κ⟩ = −1 を入れても直らない**。κ → −1 とすると角括弧は G′ − G/r に
なるが、l = 1 では G′ ≈ 2G/r なので括弧は ≈ G/r となり、真の値
(≈ 4.5e-3 · G′ ≈ 9e-3 · G/r) の 100 倍のまま。**この reduction 自体が、
核近傍を見る連続状態には使えない。**正しい対処は reduction をやめること
(= κ 分解 Dirac)。

## 4. 独立な量での裏取り — σ_own/σ_Bote

F(s) は N(K)/N(0) の比なので規格化が落ちる。**σ_own は N(0) の絶対値**で
別の情報を持つ。同じ並びが出るかを見た:

| ケース | 非相対論 | **SRC (出荷)** | kdirac |
|---|---|---|---|
| C K 200 kV | 0.8647 | 0.8628 | 0.8635 |
| Si K 200 kV | 0.9575 | 0.9456 | 0.9520 |
| Fe K 200 kV | 1.0221 | **0.9683** | 1.0041 |
| Cu K 200 kV | 1.0382 | **0.9726** | 1.0170 |
| Ag K 200 kV | 1.1061 | **1.0228** | 1.0743 |
| Au L3 300 kV | 1.0220 | **0.9498** | 0.9907 |

**SRC は全ケースで [非相対論, kdirac] の区間の外側**、一貫して低い側に外れる。
F(s) の測定と独立に同じ結論になる。

⚠ ただし σ では **kdirac が非相対論と SRC の中間**に来る (F(s) では kdirac ≈
非相対論)。矛盾ではない — σ は絶対値なので**振幅**の相対論効果を拾い、
F(s) は比なのでそれが落ちて**形**だけが残る。SRC の欠陥は形の側にあり、
それは偽の r 依存ポテンシャルが波動関数の動径形を歪めるという §3 の機構と整合する。
**σ では kdirac が最も 1 に近い** (Fe 1.004 / Cu 1.017 / Au L3 0.991)。

## 5. 出荷データへの含意

- **v3 (SRC 処方) の F(s) は、検証域 s ≤ 1.25 で 1.5 % 級・s = 2.5 で 6 % 級の
  近似誤差を持つ** (Z = 14〜36 が最大。Z ≥ 47 では 0.3 % 以下に落ちる)
- 真の相対論効果は 0.3 % 以下なので、**v2 (非相対論) の方が真値に近い**
- 外部参照 (Oxley–Allen / µSTEM) との一致でも Z ≤ 26 では v2 が v3 に勝つ
  (Fe で 0.19 % vs 0.86 %。`docs/notes/fs_external_validation_2026-08-07.md`)
- **κ 分解 Dirac (v4 候補) はこの問題を持たない。**真の相対論効果を正しく持ち、
  かつ SRC の偽項を持たない

## 6. 反証の可能性と、それを潰した根拠

「SRC が誤り」ではなく「kdirac が何かを落としている」という読みもありうる。
kdirac 側は独立な 5 方向から支持されている:

| | 検査 | 結果 |
|---|---|---|
| 1 | 自由粒子で Riccati–Bessel と一致 | 3.1e-7 (selftest T23c) |
| 2 | c→∞ で GOS が非相対論経路へ退化 | 2.2e-5 vs 物理効果 2.1e-3 = 1/94 (T23d) |
| 3 | 角度因子が非相対論へ厳密退化 | 2.2e-16 (T23b) |
| 4 | Zhang GOS DB との幅 | 11.2 % → 4.0 %、L2/L3 の内部整合も 9.7 → 1.4 % |
| 5 | 同じソルバの δ_κ から組んだ σ_el が NIST SRD 64 と一致 | 1 keV 以上で 0.90–0.94 |

対して SRC 側は、**自分の中の非相対論極限からも、Dirac からも、外部参照からも
同じ向きに外れる**。5 と 4 は完全に独立な外部参照なので、kdirac 側の系統誤差で
説明するのは難しい。

## 7. 全殻・全 E0 での確認 (2026-08-07 追加)

s = 1.25 での「SRC の偽差」(= 非相対論 − SRC) と「真の相対論効果」
(= kdirac − 非相対論)。単位は F(s) の相対差 [%]。

| チャネル | E0 | **SRC の偽差** | 真の相対論効果 | 倍率 |
|---|---|---|---|---|
| Fe K | 60 keV | 1.350 % | 0.039 % | 35 |
| Fe K | 200 keV | 1.647 % | −0.110 % | 15 |
| Fe K | 400 keV | 1.784 % | −0.199 % | 9 |
| **Fe L1** | 60 keV | **49.23 %** | −2.253 % | 22 |
| **Fe L1** | 200 keV | **48.50 %** | −2.519 % | 19 |
| **Fe L1** | 400 keV | **48.76 %** | −2.731 % | 18 |

| Ag K | 200 keV | 0.343 % | 0.047 % | 7 |
| Au L3 | 300 keV | −0.367 % | −0.226 % | 1.6 |

**わかったこと**:

1. **E0 にほとんど依存しない** (Fe K で 60→400 keV が 1.35→1.78 %)。機構が
   「偽の r 依存ポテンシャル」であることと整合する — 原子構造側の効果で、
   運動学ではない
2. **L1 (2s) が桁違いに悪い。**s = 1.25 で相対 49 %。⚠ **節の artefact ではない** —

   (M′/M)G′ ∝ V′G′ で、節を持ち外側に振幅がある 2s を最も歪める。機構と整合
4. **重元素ほど小さい** (Ag K 0.34 %、Au L3 −0.37 %)。Au L3 では真の効果と
   同程度まで落ちるので、そこだけは SRC が実害を出していない

⇒ **出荷 v3 の L1 チャネルは s ≳ 1 で数十 % の近似誤差を持つ。**
K・L2・L3 は 1.6〜7 % 級。**軽・中元素の L1 が最も深刻。**

## 8. Ag K の +0.5 % 超過 — **参照側だった** (2026-08-07 解決)

SRC のアーティファクトを外すと露出する +0.45〜0.51 % (s にほぼ平坦)。
連続状態の処方でないことは §1 で確定。さらに:

| 候補 | 検査 | 結果 |
|---|---|---|
| 端エネルギーの定義差 | E_th を ±3 % 動かす | **却下**。感度が s とともに育つ (Ag で 0.002→0.175 %) が、超過は s に平坦。形が合わない |
| 始状態 1s の相対論的収縮 | 非相対論 1s に差し替え | **却下**。⟨r²⟩ は 7.5 % 違うのに F(s) は 0.002〜0.18 % しか動かない (K/Z が小さいため) |
| 過電圧 (運動学) | E0 = 100→400 keV | **一部**。乖離は 100 keV の +1.6 % から 400 keV の +0.36 % へ減るが、消えない |

⚠ **参照 2 つは独立ではない。**Oxley–Allen 2000 と µSTEM は**どちらも Allen
グループ (Melbourne) の系譜**で、µSTEM のイオン化形状因子は OA の定式化の実装。
両者が一致することは独立な確認にならない。

### 解決 — 参照側だった

**絶対値で見ると「平坦な 0.45 % のオフセット」ではなかった。**Ag K @200 keV で
(1−F) を比で見ると、s が小さいほど食い違いが開く:

| | s=0.125 | s=0.375 | s=0.625 | s=1.25 |
|---|---|---|---|---|
| **(1−F) の比 我々/参照** | **0.136** | 0.584 | 0.785 | 0.919 |

小 s で **(1−F) が 7 倍違う**。決め手は 3 つ:

1. **我々の (1−F) は求積で完全収束**している。QUICK / PROD / HIGH /
   HIGH の角度求積 4 倍が **6 桁一致**。しかも **s² 則を厳密に満たす**
   (s = 0.0625 / 0.125 / 0.25 で 0.000185 / 0.000740 / 0.002952、比 4.00, 3.99)
2. **µSTEM の Ag は有効 4 桁**しかない。s = 0.025 と 0.05 で f が同値になり、
   小 s の挙動が桁で潰れている
3. **OA2000 (6 桁) でも (1−F)/s² が s→0 で跳ね上がる** — Ag で平坦域の **7 倍**。
   **F(0)=1 に規格化された形状因子なら (1−F)/s² は s→0 で一定になるはず**で、
   なっていない。Fe でも同傾向

物理的にも我々の方が筋が通る: 我々の非局在長 √(6(1−F)/K²) = 0.080 a₀ は
運動学の下限 1/q_min = v/ΔE = 0.101 a₀ と整合する。参照から出る値は**その 2 倍**。

⚠ **この節からは参照側の値そのものを落としてある** (2026-08-09)。
`CONTRIBUTING.md`「制限付き出所の参照データを入れない」に従い、**先方の表を
書き写した行 (1−F の絶対値・生の f 値・(1−F)/s² の絶対値) を削除**した。
残してあるのは**我々の値と、比較の比**で、論証と結論は変わっていない。
参照の実データは `ReciPro/tools/IonizationGen/` にあり、比較は scratchpad で行う。

⚠⚠ **公開に先立って履歴も書き換えた** (2026-08-09)。この節は `88f916b` で
追加されてから一度も変更されておらず、値は 6 コミットに同じ blob として
残っていた。public 化は HEAD だけでなく全履歴を公開するので、`git filter-repo`
で当該 blob を本版に差し替えてある。**`88f916b` 以降のコミットハッシュは
すべて変わっている** — v4 の生成器ハッシュは `src/prod_v4_jl/MANIFEST.md` の
記載が正本。

⇒ **Ag の「超過」は参照側の小 s の振る舞い (規格化の規約か表の精度) による。
我々の値の方が物理的に妥当。**⚠ 逆に言えば、**µSTEM / OA2000 は s ≲ 0.2 の
重元素 K 殻では 0.1 % 水準の物差しにならない**。
