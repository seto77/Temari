## 3. 機構 (b) — src の部分波打ち切りは広がった軌道の高 ε で収束していない (★★★ 出荷に関わる)

`eps_setup_lmax` (tools の写し、`l_max` を外から与える) で 1 ノードの角度積分 (β=π、縦成分、HIGH 設定
ppw 30 / dt 1e-3 / n_q 360 / sig 1e-13) を l_max について振った。基準 = src の l_max + 40:

|---|---|---|---|---|---|
| **Xe M4 @400** (2.64, 0.111, 0.111) | 100 eV | 12 | −1.2e-07 | −1.2e-07 | −1.2e-07 |
| | 1 keV | 13 | −9.7e-09 | −2.7e-14 | 4e-16 |
| | 5 keV | 15 | **−2.7e-04** | −7.4e-07 | −1.1e-10 |
| | 30 keV | 18 | **−7.3e-02** | −9.1e-03 | −3.0e-04 |
| Fe K @200 (0.80, 0.231, 0.231) | 30 keV | 23 | −2.5e-09 | −1.5e-12 | −7e-15 |
| Au L3 @200 (0.66, 0.076, 0.076) | 30 keV | 16 | −2.3e-07 | −2.0e-11 | −8e-16 |
| C K @200 (3.84, 1.0, 1.0) | 30 keV | 60 | −4.2e-05 | −9.0e-06 | −8.7e-07 |

Xe M4 @400、ε=30 keV の収束の様子 (β=π): l_max 18: 1.2555e-10 → 22: 1.3187 → 30: 1.3504 → 40: 1.35426
→ 60: 1.354487 → 80: 1.354488 (単調、飽和)。β=200 mrad では 18 → 80 で +1.5 %。

**読み**: src の `l_kin = ⌈κ·min(r_core, 6/Z)⌉ + 12` は、**m = 6/Z が軌道の広がりより小さい** (Xe 3d は
r_core 2.64 に対し 6/Z = 0.11) と、高 ε (κ 大) で部分波が足りない。K 殻・Au L3 では 6/Z と軌道の大きさが
合っているので収束している。⇒ これは**求積ではなく src の処方 (部分波の打ち切り) の問題**で、
P−O 比較 (同じ l_max を共有) では見えない。

**出荷への影響の見積り (⚠ 測る前の見積り)**: Xe M4 @400 keV の全域 σ (β=π) は、窓を [0,1000] /
[1e3,1e4] / [1e4,1e5] / [1e5,ε_max] に分けて l_max を各帯の上端値にすると 1.6e-08 / 8.2e-05 / **2.8e-02** /
**3.2e-01** 動く (帯の重みは 84 % / 16 % / 1 % / 0.05 %)。⇒ **σ_own (= N(0)) で ~1e-03**、F(s) = N(K)/N(0)
では**高 s (N(K) が高 ε・大 Q に支配される領域) の M4/M5 で百分率級の可能性**。s ≤ 2 Å⁻¹ (観測量が感じる
帯) は ε ≲ 2 keV が支配するので ≤ 1e-05 級と見込む。⚠ **F(s) 側で直接測るまで主張しない** (F v6 台帳、
最優先)。⚠ `:window_max` を [0, ε_max] に掛けると Fe K で高 l・低 ε の Coulomb 関数が DomainError
(sqrt の負引数 −3.9e-15) で落ちる = 低 ε に高 l を強いると src の連続状態ソルバが壊れる。
**l_max は κ に比例して増やす (例: ⌈κ·r_core⌉ + 12 か、κ·r_bulk + margin)** のが安全で、費用は
高 ε で最大 7× (Xe M4: 18 → 138 波)。
