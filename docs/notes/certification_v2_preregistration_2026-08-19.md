## 3. 合否規則 (固定)

各窓・各 β について

    |P − O| ≤ rtol·|O| + atol·σ_ref,   rtol = 1e-7,  atol = 1e-9

- σ_ref = **同じ行の最も広い窓 [0, ε_max] のオラクル値 O** (β ごと)。
  尾の窓 (σ ≈ 0) を相対だけで判定しない (codex)。⚠ この atol は物理単位で一定の絶対許容ではなく
  **行スケールの絶対許容** (row-scaled absolute tolerance)。尾の窓 (O/σ_ref = 1e-5) では相対 1e-4 まで
  緩む一方、全断面積に換算した絶対寄与は 1e-9·σ_ref 以下に抑える設計。
- 分母は **|O|** (オラクル)。P でも平均でもない。
- **記録はすべて残す** (P, O, 差, 相対, scaled = |P−O|/max(|O|, (atol/rtol)·σ_ref))。
  集計で使う正式な量は **scaled の最悪・中央値・p99**。
- rtol = 1e-7 の根拠: 規則どうしの差は連続状態 ODE の離散化 (ppw=25) で **~1e-08〜3e-08 で頭打ち**
  になる (`tools/window_floor_probe.jl`、2026-08-19。n_q は無関係)。床の 3〜10 倍上に置く。
  これより小さい差は**測れない** ([[measurement-floor-is-shipping-floor]])。
- ⚠ **不合格が出ても規則を書き換えて合格にしない**。不合格は不合格として記録し、規則の
  改訂は別版 (v2) として**再認証**する。

## 5. 事前に分かっている限界 (測る前に書く)

- **同じ n_q・同じ ppw** なので P−O は窓求積の差であり、n_q の補間バイアス (1216 で最悪 4.7e-07、
  8 条件標本) と ppw の離散化バイアス (~1e-06) は**見えない**。それらは別の測定 (`nq_interp_direct.jl`、
  `window_bias_probe.jl`) の値を契約へ並記する。
- オラクルも同じ `eps_setup` を通るので、両者に共通の誤差 (参照関数の段差そのもの、Miller ガード窓) は
  差から消える。
- `indicator` (Legendre モードの尾) は**診断値**。合否の根拠にしない。認証では
  「scaled が大きいのに indicator が小さい」件数 (偽陰性) を数えて、指標の信頼度を測る。
- 標本は決定論的な層別標本であり、全格子ではない。**全格子の observed_max は主張しない**。
