## 1. 方法 — 内挿を一切挟まない

v3 は s ≤ 8 の 161 点、v5 は s ≤ 16 の 321 点。**v5 の先頭 161 点は v3 の格子と
厳密に一致する** (実測で確認)。⇒ v5 を「落とす」のでも v3 を「伸ばす」のでもなく、
**v5 の厳密な部分集合**を取れる。処方差に内挿誤差が混ざらない。

- **共通 246 チャネル** (v3 に M 殻は無い。母集団に入れない)
- **共通の E₀ 実在行**のみ
- **共通 s 格子点** (0, 0.05, …, 8.0)
- 両方の有効域の内側だけ。⚠ v3 は schema 1 で `s_cert_A_inv` を持たない
  (v5 で導入された概念) ので、v3 側の上限は格子の端 s = 8

走査点 **1,202,026**。

⚠ 禁止したこと: v3 を s>8 へ外挿 / v5 を v3 に無い点へ内挿 / M 殻を母集団に入れる /
E₀ 軸が一致しない点を補間して処方差へ混ぜる。

## ⚠⚠ 動いたつまみは 1 つではない

```
v3: DHFS-KS23-DiracB-SRC-jsplit-fullrange-sym-v3
v5: DHFS-KS23-DiracB-KDIRAC2C-jsplit-fullrange-sym-v4-DSCF
```

**連続状態** (SRC → κ 分解 Dirac) **と 原子場** (非相対論 SCF → 完全 Dirac SCF、
接尾辞 `-DSCF`) の **2 点が同時に変わっている**。
⇒ **この測定を「κ-Dirac だけの効果」と呼んではいけない**。

## 3. 観測量への感度 (⚠ シナリオであって測定ではない)

`observable_propagation_2026-08-13.md` §4 の**帯ごとの**伝達係数を使う。

⚠⚠ **単一の 1.42 / 1.76 を s<2 の帯最大に掛けてはいけない**。あの 2 つは δF を
全帯へ一様に載せたときの総合比であって、帯別の応答ではない。帯別に掛けるのが正しい
(私は最初これを取り違え、20 倍近く大きい値を出しかけた)。

| s 帯 | 伝達係数 (サイト比) |
|---|---:|
| [0.0, 0.5) | 0.9973 |
| [0.5, 1.0) | 0.3757 |
| [1.0, 2.0) | 0.0603 |
| [2.0, 4.0) | 0.0030 |
| [4.0, 6.0) | 4.9e-07 |

### 3.1 監査が使った配置 (Al K / Co K @ 200 keV)

| | Al K | Co K |
|---|---:|---:|
| 寄与の和 (Al/Co サイト比) | **2.81e-03** | **5.67e-03** |

⇒ 既報の 2.8e-3 / 5.7e-3 を**厳密に再現した**。

### 3.2 ⚠⚠ しかしそれは 1 配置であって母集団ではない

同じ構成を **246 チャネル × 全 E₀ 行**へ広げると:

| | サイト比 | 生の収量 |
|---|---:|---:|
| 帯ごとの最悪を積んだ寄与の和 | **4.14e-02** | **5.16e-02** |

**約 15 倍**。s<2 帯最大 \|ΔF\| の分布 (7,466 行) は
min 2.85e-04 / p10 3.11e-03 / **中央 8.57e-03** / p90 2.69e-02 / max 5.72e-02。

⇒ **「v3→v5 の影響は 3e-03 程度」という読み方は、Al/Co という 1 配置に
固有の値を母集団に広げたもの**であって成り立たない。

⚠ 呼び方: これは `scenario-sensitivity`。**上界ではない** — 伝達係数は任意の δF(s)
に対する作用素ノルムとして証明されていないし、符号・s 依存・チャネル間相関を
無視している。**実経路へ通した測定でもない** (それは `AlchemiCheck sens` +
`ChannelDataOverride` が要る = ReciPro 側の作業)。

## 4. v3 を使った過去の結果について

> dataset v3 は、公開後に処方上の欠陥が判明したスカラー相対論的連続状態を
> 使用していました。dataset v5 ではこれを κ 分解 2 成分 Dirac 連続状態へ
> 置き換えており、新しい計算には v5 を推奨します。
>
> ただし、**v3 を用いたすべての結果が自動的に無効になるわけではありません**。
> 影響は元素・副殻・s 領域、および F の差を最終観測量へ伝えるシミュレーション
> 条件に依存します。サイト強度比などの小さな定量差、重元素 L 殻、または今回
> 測定した条件固有の v3–v5 差と同程度の許容差に結論が依存する場合は、v5 で
> 再計算してください。十分に大きな余裕を持つ定性的結論は変わらない可能性が
> ありますが、個別確認が必要です。過去結果を再現できるよう、**v3 は引き続き
> 保存します**。

⚠ **書いてはいけない表現**: 「v3 の結果は間違っている」/「v3 でも十分正確」/
「v5 が v3 の結果をすべて訂正する」/「2.8e-3 は普遍的な上界」/
「X 以下なら再計算不要」。

**明確に再計算を勧める対象**: 新規研究 / サイト占有率・サイト強度比の定量 /
重元素 L 殻 (⚠ L1 が最も動く) / v3–v5 差と同程度のマージンで結論が変わる研究 /
dataset version が記録されていない研究 / 高 s 寄与や tail 処理に感度がある設定。
