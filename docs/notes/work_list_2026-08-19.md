### B6. Mott の cos θ CDF プローブ { #b6 } — ★ 2026-08-19 実施

**実装 = `tools/mott_cdf_probe.jl`**。`--selftest` (負のテスト 5 種 + 偽陽性検査) と
`--demo` (Al/Fe/Au × 10/30 keV) が入っている。⚠ **tools 限定のまま**にした
(codex の条件)。

**測って分かった 2 件** — どちらも先に知らずに出荷したら消費側が踏んでいた:

1. ★★ **節点間 (Δμ=0.001) を GL 1 枚で積むと足りない**。Legendre 級数は前方で
   Δμ ≈ sinθ·π/l_max の周期で振動し、Al の 30 keV (l_max=774) では**先頭パネルに
   約 7.8 振動**入る。⇒ **l_max からサブパネル数を自動決定**する形に変えたところ、
   部分波和 (角度求積を含まない独立オラクル) との相対差が
   **5.82e-06 → 7.86e-15**。全 6 ケースで **≤ 2.9e-14**
   - ⚠ 残った「エンジン GL(400) との差」は `closure_rel` と同値。つまり
     **このケースではエンジン自身の全域 GL のほうが前方を解けていない**。
     ⇒ N5 はエンジンの自己申告より厳しく責めない形にした
2. ★★★ **NIST 配置の Δμ=0.001 は前方ピークを分解しない**。先頭パネル
   [1.000, 0.999] (θ ≤ 2.56°) が σ_el に占める割合の実測 =
   **Al 47.3/67.2 %、Fe 33.2/53.6 %、Au 28.2/47.1 % (10/30 keV)**。
   ⇒ この CDF を逆関数化するモンテカルロでは**弾性事象の約半分が 1 区間に潰れ**、
   **エネルギーが上がるほど悪化する = EBSD の常用域 25/30 kV がいちばん悪い**。
   ⚠ 現行の NIST sampler も同じ配置なので同じ制約を持つ。**出荷形式を決める前に**
   前方の刻み方 (θ か log(1−μ)) を決めること

⚠ 既定 `l_cap=600` は**軽元素の高エネルギーで足りない** (Al 30 keV は l_max=774 が要る)。
プローブは `truncated` を検査 N8 で捕まえて落ちる。

ReciPro P1 で**唯一完全にブロックの無い切片**。新規 `tools/mott_cdf_probe.jl` が
`compute_mott(z, eps)` を呼び、cos θ を +1→−1 の 0.001 刻み 2001 節点、dσ/dΩ の累積と
σ_el・σ_tr を NIST サンプラ配置で出す。⚠ **節点間はパネルごとの Gauss–Legendre で積む**
(全域 1 本の規則にしない。前方ピークが難所そのもの)。⚠ `compute_mott` は
`cont.ok[ic]` が false の位相を 0 にするので、**自前の積分を返り値
`sigma_el_a0_2` と突き合わせる**。

⚠ **codex の条件**: **tools 限定プローブに留め、外部 API・データ製品に昇格させない**。
CDF の規格化・角度規約・tail・単調性の**負のテストが揃ってから** ReciPro へ渡す。
利点は「Z=1–96 のデータセット完成を待たずに**形式を生成前に合意できる**」こと。
