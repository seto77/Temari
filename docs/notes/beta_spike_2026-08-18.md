## 0. 五行で

1. **部分角は求積区間の制限で出せる** — β ごとに `gl01(n_x, x_β)` を張り直すだけ。
   β = π は既存 `angular_integral` と**全 ε ノードでビット同一** (PROD で 72/72、
   3 チャネル × 横断 on/off の 6 通りすべて)
2. **β は事実上ただ** — β 1 本の追加コストは `eps_setup` の **0.005–0.14 %**。
   ⚠ ただし**同じ ε ノード・同じ `RlTable` を使う限り**。新しいエネルギー窓は
   `eps_setup` からやり直すので**ただではない**
3. ★★ **既存の全角度求積が、この一連で最も緩い** — 変数を変えた独立オラクルと
   比べると n_x = 64 で ε ノードあたり **2.5e-06〜1.2e-05**。
   ⚠⚠ **n_x を倍にする自己収束テストはこれを 26 倍過小評価した** (誤差が n_x に
   対して非単調で、64 → 128 で**悪化する**場合すらある)
4. **エネルギー窓は 16 点の GL で 1e-08 級** — 加法性 7.1e-09〜2.8e-08、
   ノード倍増 6.4e-09〜3.6e-08。⚠ **加法性は恒等式ではない** (別々の求積)
5. ★ **Q² の組み方は `dq²·exp(x)` が最良** — 変数変換の定義そのもので、相殺の無い
   形と**機械精度 (1.2e-16〜3.5e-16) で一致**する。既存の naive 式は最悪 3.4e-08

## 2. ★★ 最大の発見 — 自己収束テストが誤差を 26 倍過小評価した

### 2.1 何が起きたか

G3 (n_x を 2 倍にして動かなければ収束とみなす) は、全角度で **6.2e-07** と出た。
ところが変数を変えた独立オラクル (G9) と比べると **1.6e-05** ずれていた。**26 倍。**

n_x を掃いて両者を並べると理由が見える (Fe K、ε = 25.3 keV、PROD の R 表):

| n_x | 64 | 128 | 256 | 512 | 1024 | 2048 |
|---|---:|---:|---:|---:|---:|---:|
| オラクルとの相対差 | 1.20e-05 | 1.90e-06 | 3.59e-06 | 1.89e-07 | 3.01e-08 | 2.57e-08 |

**単調でない** (128 → 256 で悪化)。Au M5 の ε = 13.8 keV では **64 → 128 で悪化する**
(9.27e-06 → 1.24e-05)。Gauss 求積の誤差は次数に対して振動しうるので、
**「n と 2n が近い」は「2n が正しい」を意味しない** (codex の指摘そのもの)。

### 2.2 何に効くのか / 効かないのか

- ⚠ **効くのは σ_own と `edge` 出口** — 比を取らない量なので相殺が期待できない。
  **`σ(β, Δ)` はまさにこの型**なので、契約に数値予算として書く必要がある
- **出荷 F(s) は比** `N(K)/N(0)` なので、K と 0 で共通する分は打ち消える。
  ⚠⚠ **どれだけ打ち消えるかは測っていない。**「F(s) は無事」と書いてはいけない
- ⚠ 出荷テーブルの生成は **HIGH_SETTINGS (n_x=96)** で、上表は PROD (n_x=64)。
  n_x=96 の値は測っていない (64 と 128 の間なら 1e-06 台と推測されるが**推測**)

### 2.3 両求積が頭打ちになる床 (~1e-08) の原因は**未特定**

n_x → 2048 とオラクル (192 パネル × 24 点) は互いに **1e-08 級**で止まる。
被積分関数が R_λ(Q) の PCHIP 補間 (C¹ だが C² でない) を通ることが容疑だったので
**n_q を 180 → 1440 と 8 倍振ったが、床は系統的に下がらなかった**
(1.0e-10〜3.5e-08 でばらつく。720 でたまたま 1.0e-10 まで落ちる)。

⇒ **節点位置に依存する何か**であることは示唆されるが、**特定できていない**。
⚠ 「PCHIP のせい」と書かないこと。

## 3. 契約 (S1) へ持っていく数値

⚠ これは**測定値**であって、契約の許容値そのものではない (許容値は作者判断)。

| 量 | 実測 | 備考 |
|---|---|---|
| 部分角の求積 (β ≤ 1 mrad) | ≤ 1.4e-12 | オラクルとの一致 |
| 部分角の求積 (β = 10 mrad) | ≤ 1.2e-08 | |
| 部分角の求積 (β = 100 mrad) | ≤ 3.2e-06 | Au M5 が最悪 |
| **全角度 (既存経路、n_x=64)** | **≤ 9.3e-05** | ★ ここが一番緩い |
| エネルギー窓 (16 点、幅 100 eV) | ≤ 3.6e-08 | 加法性・ノード倍増とも |
| Q² の式による差 | ≤ 3.4e-08 | 最悪運動学 (ΔE=50 eV, E₀≥200 keV) |

**推奨** (私の意見):

1. **Q² は `dq²·exp(x)` へ替える** — 変数変換の定義そのもので、相殺の無い形と機械精度で
   一致する。⚠ **既存の K=0 分岐は触らない** (ビット同一)。新経路だけ替えると
   G1 の closure がビット同一でなくなる (~1e-12 の差) ので、**closure の判定を
   「ビット同一」から「1e-11 以内」へ緩める**か、**新経路も naive のままにして
   数値予算に 3.4e-08 を計上する**かの二択。**作者判断**
2. **β の求積次数を β に応じて決める** — 小 β は今の n_x で桁違いに余裕があり、
   大 β が足りない。⚠ ただし**全角度は既存経路の話**なので、ここを直すのは
   出荷テーブルの再生成とセット (F v6)
3. **窓は 16 点で足りる** (幅 100 eV、閾値端の √ 正則化つき)。⚠ **狭い窓・上端に
   接する窓・ゼロ幅は未測定**

## 4. 言えないこと (⚠ 主張の線引き)

- ❌ **「G1 がビット同一だから新経路は正しい」** — G1 が検査したのは **β=π の
  dispatch と `x_β = log1p(a)` の一致と既存と同じ式・重み・縮約順序**だけ。
  **β < π の部分区間の求積が正しいことの独立な証明ではない** (codex の指摘)。
  部分区間側を支えているのは **G9 (別変数のオラクル)** と **G10 (係数つき漸近)**
- ❌ **「G2 が通ったから系統誤差は無い」** — 単調性は系統的な過大・過小でも通る
- ❌ **「G3 が通ったから収束している」** — §2 が反例。同じ変数・同じ求積族の
  自己収束は、**同じ誤答へ収束していないことを保証しない**
- ❌ **「オラクルが真値」** — オラクルも有限次数。両者の**相互一致**を測っただけで、
  床 1e-08 の下は見えていない
- ❌ **「床は PCHIP のせい」** — n_q を 8 倍しても系統的に下がらなかった (§2.3)
- ❌ **「安定式が真値」** — G6/G11 が測ったのは**式どうしの差**であって、
  naive の真の誤差ではない (codex の指摘)
- ❌ **「角度分解はただ」** — ただなのは**同じ ε ノード・同じ R 表からの複数 β**
  だけ。**新しいエネルギー窓は `eps_setup` を引き直す**
- ❌ **「出荷 F(s) は影響を受けない」** — 比なので打ち消えるはずだが、**打ち消しの
  量を測っていない**
- ❌ **「σ(β) の値が正しい」** — 外部の物差しとは 1 つも突き合わせていない (S4)

## 5. 次に測るべきこと (codex 2026-08-18 の助言 + 私の追加)

1. **Q² 誤差の観測量への伝播** — Q² の相対差がそのまま σ の相対差になる保証は無い
   (カーネルが 1/Q⁴)。ε ノードの角度積分・窓積分 σ・k-factor の各段で
   naive / stable / exact-x を比べる。特に低損失・高 E₀・小 β
2. **窓端の境界行列** — ゼロ幅、極狭窓、Δ₁ が 0 に極めて近い内部窓、逆順・負の端、
   上側運動学端 (k_f→0) に接する窓、上限をまたぐ窓。⚠ **今の √ 正則化は下端だけ**
3. **β の入力契約** — β=0 / 極小 / π⁻ / π / >π / 負 / NaN / Inf の拒否・飽和規則。
   ⚠ 現状 `beta_x_upper` は β≥π を全角度へ飽和し、**負の β は sin² のせいで
   正の開口として通ってしまう**
4. **標本を β/θ_E で張る** — β の絶対値ではなく θ_E との比で配置すると、
   前方ピークの難しさを均等に踏める
5. **d²σ/dΩdE を θ 分解して返す形** — 有限 α への道を塞がないため (§8-4)。
   `dσ/dβ = 2π sinβ · d²σ/dΩdE|_β` の関係で累積量と被積分関数を相互検査できる

## 6. ★ 看板候補 J — 角度–エネルギー EELS 応答面 (codex 提案、2026-08-18)

作者指示 (2026-08-18) の「**B と並ぶ看板・新しい看板がないか**」に対する codex の答え。
**思いつきではなく、今回の実測が根拠になっている。**

`σ(β, Δ)` という 1 つの数ではなく、**累積角度分布** `C(β, ε) = ∫_{Ω(β)} d²σ/dΩdE dΩ` を
β × ε の面として返す。

**なぜ既存資産で出せるのか** (実測に基づく):

- `eps_setup` が ε ごとの動径応答を作り、`angular_integral` の中に θ 被積分関数が既にある
- **同じ ε ノードから複数 β を出す追加コストが `eps_setup` の 0.005–0.14 %/本** (G5)
- 円形開口は `C(β)`、**同心環状開口 (ADF/HAADF 的な取り方) は `C(β_out) − C(β_in)`**
- 任意の軸対称な検出器重みは θ 分解量から後処理できる
- **B (σ(β,Δ) と k-factor) はこの面の縮約**として得られる

⇒ 位置づけは「B の代替」ではなく「**B を一段上から包含する看板**」。
§8-3 の response API 案にも物理的な中身を与える (API 単体はリファクタだが、
新しい観測量を載せれば飛躍になる、という私の評価と整合する)。

⚠ **今は言えないこと**: 有限 α の干渉プローブまで扱える / 非軸対称・偏心開口を
`C(β)` だけで扱える / 背景・検出器応答・多重散乱込みで実験条件を最適化できる /
応答面データセットの格子・内挿・容量が認証済みである。
