## 2. --prod-all (14/14) — U は格子に依らない

各元素を stage 3/4/5 (dt/4, dt/8, dt/16) の**全水準で** production と tight の
両方解き、U_k = max|f_prod(L_k) − f_tight(L_k)| を比較した:

- **全 42 水準で U ≤ 0.25×B_scf** (v1 の採用段実測と同じ水準)
- **U の格子依存: max/min ≤ 1.65、系統的な増減なし** (軽元素はほぼ 1.00 —
  H 2.295e-09 が 3 水準で 4 桁一致。C の v1 実測 1.256/1.248/1.274e-09 と同型)
- ⇒ 「停止影響を採用段だけで判定する」v1/L¹ の設計は標本で裏づけられた

⚠ 点ごと verdict が NG の 6 元素 (Cu/Xe/Cs/Gd/Au/Rn) は **grid/scf/収束すべて
合格で、v1 の点ごと q ゲート (既知の設計欠陥、37/83 が落ちた) の unresolved のみ**。
格子の正本は L¹ 認証 v2.1 (certified 83) であり、この NG に運用上の含意は無い。

## 3. 運用記録 (v1・L¹ と同じパターンの再現)

| 事象 | 件数 | 対応 |

## 4. この測定が答えていないこと

- Z ≥ 18 の τ/10 十分性は**この方法では検査できない** (τ/100 という物差しが
  届かない)。間接証拠は (i) U′ 参考値が全て ≤ 0.093×B_scf、(ii) L¹ の
  停止安定性実測 (‖Δρ₃‖ が τ 締め ±3.4 %)、(iii) U の格子非依存 (§2)
- τ/1000 級のラダーや固定点残差からの停止不確かさ評価 (codex 提案) は
  次世代の課題のまま (事前登録 v2 §E4)
