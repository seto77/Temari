# Temari の独自性・競合状況・国際的発展可能性に関する評価

**対象リポジトリ:** [seto77/Temari](https://github.com/seto77/Temari)  
**評価日:** 2026年8月19日  
**評価目的:** Temariに類似するソフトウェアがどの程度存在するか、Temariが珍しい存在であるか、今後国際的な注目を集める可能性があるかを、できる限り客観的に検討する。

## 1. エグゼクティブサマリー

Temariは、単なる既存ソフトウェアの再実装ではない。一方で、収録されている個々の機能が世界初というわけでもない。Temariの希少性は、主として次の組み合わせにある。

- 自己無撞着原子計算、相対論的束縛状態、歪曲連続状態を同一エンジンで扱うこと
- 内殻イオン化形状因子、EELS、GOS、弾性位相シフト、Mott散乱、X線・電子線原子散乱因子を、同じ原子モデルから導出すること
- STEM-EDXおよびALCHEMIで必要となる非対角的量に対応する、公開されたイオン化形状因子データを提供していること
- 数値表だけでなく、補間規約、格子、ハッシュ、negative test、golden vectorなどを含む「実行可能なデータ契約」を提供していること
- MITライセンス、Julia標準ライブラリ以外への依存なし、再生成可能という方針を採っていること

したがって、総合評価は次のとおりである。

> **Temariは「原子構造計算ソフト」としては競合の多い領域に属するが、「電子顕微鏡で必要な複数の散乱・励起量を同一の相対論的原子エンジンから生成し、再現可能な公開データとして供給するシステム」としてはかなり珍しい。**

現段階では国際的評価が確立したソフトウェアではない。しかし、公開済みデータセット、とりわけ \(F(s,E_0)\) を中心に据え、査読論文、外部検証、既存解析ソフトとの連携を進めれば、電子顕微鏡・原子散乱の専門領域で国際的に認知される可能性は十分にある。

## 2. 評価の範囲と限界

本評価では、TemariのREADME、設計文書、検証文書、主要ソースファイル、公開データの説明、コミット状況を確認した。また、FAC、GRASP、ELSEPA、Dirac GOSデータベース、abTEMなどの公開情報と比較した。

ただし、本評価は以下を含まない。

- Temariの全ソースコードに対する行単位のコードレビュー
- 全テストの独立環境での再実行
- 公開データセット全体の再計算
- すべての原子・副殻・エネルギー領域についての精度保証
- 世界中の非公開コード、研究室内コード、商用コードを含む完全な先行ソフトウェア調査

したがって、「同等のものが世界に絶対に存在しない」と断言するものではない。結論は、公開情報から判断して**希少性は高いが、唯一性は査読論文レベルの先行研究調査で確定すべき**、というものである。

## 3. 既存ソフトウェアとの関係

| 機能・設計要素 | 主な既存例 | Temariの位置づけ |
|---|---|---|
| 相対論的原子構造計算 | [FAC](https://github.com/flexible-atomic-code/fac)、[GRASP](https://github.com/compas/grasp) | 機能自体は珍しくない。既存コードの方が歴史、一般性、利用実績で優位 |
| Mott弾性散乱・位相シフト | [ELSEPA](https://github.com/eScatter/elsepa) | 既存分野であり、単独ではTemariの中心的独自性にならない |
| 原子散乱因子 | Waasmaier–Kirfel、Cromer–Mann、Peng、Kirkland、Lobato等の表・パラメータ | 第一原理から再計算し、高散乱ベクトル領域を含む数値表として公開する点に意味がある |
| 相対論的GOS | [ZhangらのDirac GOSデータベース](https://zenodo.org/records/12752410) | 世界初ではない。先行データベースは広い元素・edge範囲を持つ |
| EELS解析 | pyEELSModel、eXSpy、HyperSpy等 | これらは主としてデータベースを利用する解析側。Temariは原子量を生成する側 |
| STEMシミュレーション | abTEM、µSTEM等 | 既存コードでは外部で計算された原子パラメータや内部実装を使うことが多い |
| STEM-EDX/ALCHEMI用の非対角的イオン化形状因子 | 公開された汎用データは限定的 | Temariの最も強い差別化候補 |
| 一つの原子エンジンから複数の散乱量を導出 | 通常は用途別コードに分かれる | Temariの設計上の大きな特徴 |
| 実行可能なデータ利用契約 | 一般には値、単位、簡単な補間説明のみ | Temariの方式はかなり珍しく、再現性・移植性の面で強い |

FACやGRASPは、Temariよりはるかに一般的で実績のある原子構造コードである。ELSEPAは、相対論的部分波解析による電子・陽電子の弾性散乱を長年扱っている。そのため、Temariを「新しい汎用原子構造コード」あるいは「新しいMott散乱コード」として売り出しても、既存ソフトに対する優位性は打ち出しにくい。

一方、Temariの特徴は、電子顕微鏡に必要な量を用途別に別々のコードから集めるのではなく、一つの原子モデルから複数の出口として導出する点にある。この統合性と、得られた数値を利用可能なデータセットとして公開する点が、Temariの本質的な差別化要因である。

## 4. 特に評価できる点

### 4.1 検証体系が明示されている

Temariは、次のような階層的検証を文書化している。

- 水素原子など、解析解が存在する系との比較
- 非相対論極限 \(c\to\infty\) における別経路との一致
- 3j・6j記号、規格化、和則、Mott–Bethe関係などの構造的恒等式
- Julia実装と独立Python実装との比較
- Oxley–Allen、µSTEM、OFFV1、Dirac GOSなど外部結果との比較
- 故意に壊した入力やアルゴリズムを検出できるnegative test
- データ生成コード、格子、補間規約、golden vectorの固定

科学ソフトウェアでは、機能数よりも「どの誤りを、どの独立な根拠によって排除したか」が重要である。Temariはこの点をかなり意識して設計されている。

### 4.2 未解決点を明記している

検証文書では、次の点が未検証または未解決として明記されている。

- エンジン自身による絶対イオン化断面積は製品値ではなく、Bote–Salvat値を採用していること
- M1–M5について系統的な外部比較が不足していること
- 孤立原子平均場では定量的white lineを扱えないこと
- GOSのBethe ridge付近で外部Dirac GOSデータベースと12–36%程度の差があり、原因が未解決であること
- 位相シフトについてLevinsonの定理による検証が未実施であること

このような記載は、ソフトウェアの弱点であると同時に、結果を過剰に主張しない姿勢として信用上の長所でもある。

### 4.3 データ利用者を重視している

公開済みの \(F(s,E_0)\) データセットは、525 channel、14,796 rowを含むとされている。また、原子散乱因子についても86元素、\(s\leq 6\ \mathrm{\mathring A}^{-1}\) の数値表が公開されている。

特に重要なのは、単にCSV等を公開するだけでなく、次の事項を利用契約として扱っている点である。

- 運動量移行の定義
- 符号を持つ形状因子であること
- 有効範囲外のpaddingの扱い
- エネルギー軸および補間座標
- 原子散乱因子の補間変数と境界条件
- 格子のSHA-256
- 別実装が満たすべきgolden vector

これは他ソフトへの組み込み時に生じやすい「値は同じだが利用法が違う」という事故を防ぐものであり、Temariの独自性として積極的に評価できる。

## 5. 厳しく評価すべき点

### 5.1 外部利用実績がまだほとんど見えない

評価時点のGitHub表示は1 star、0 fork、0 open issueであり、外部コミュニティによる採用や検証はまだ成立していない。リポジトリの活動量や内部検証が多いことと、第三者が結果を信用して研究に利用していることは別である。

ただし、科学データセットではGitHub starsは必ずしも本当の利用度を示さない。ZhangらのDirac GOSは、GitHub側の注目が大きくなくてもZenodo上で多数の閲覧・ダウンロードを得ている。この分野では、引用数、Zenodoでの利用、他ソフトへの組み込み、実験研究での利用例の方が重要な評価指標となる。

### 5.2 査読論文と独立検証が必要である

FAC、GRASP、ELSEPAなどの既存コードは、長い利用実績と査読論文による理論的基盤を持つ。Temariの文書は詳細だが、国際的な信用を得るには、少なくとも次が必要である。

- 物理処方を数式として固定したmethods paper
- 先行手法との系統的比較
- 誤差予算と適用範囲の明示
- 著者以外による再計算またはコードレビュー
- 実際の電子顕微鏡観測量に対する有効性の提示

### 5.3 GOSの未解決差は重要である

Bethe ridgeでの12–36%の差は、単なる丸め誤差や小さな数値差ではない。Temari側が正しい可能性も、外部データベース側が正しい可能性もある。水素の解析解に対するTemariの成績は有力な傍証だが、多電子原子に対する正しさを直接証明するものではない。

この問題を解決できれば、Temariの信頼性と注目度が大きく上がる可能性がある。逆に、未解決のまま精度を強く主張すると、査読で最も厳しく問われる点になる。

### 5.4 AI支援実装に対する認識上の障壁

AIを使用して実装したこと自体は、科学的な欠点ではない。しかし、一人の著者がAI支援で実装した大規模数値コードに対して、第三者は通常より強い独立検証を要求する可能性がある。

この問題への適切な対応はAI利用を隠すことではなく、次の証拠を増やすことである。

- 解析解や独立実装との比較
- 意図的な欠陥を検出するテスト
- 外部研究者によるレビュー
- バージョン固定された再現手順
- 論文中での物理処方と数値近似の完全な記述

### 5.5 再利用性と普及性のトレードオフ

依存関係なし、flat namespace、単体スクリプトとして実行可能という設計は、長期再現性と可読性には有利である。一方、外部ソフトウェアからの再利用には不利になり得る。

世界的な普及を狙う場合は、現在のreference implementationを維持しつつ、別層として次を追加することが望ましい。

- 安定したライブラリAPI
- Julia packageとしての薄いwrapper
- Python用のデータreaderおよび補間実装
- exspy、HyperSpy、abTEMなどから利用できるadapter
- データセットを少数行で読み込める例

## 6. 国際的な注目を集める可能性

以下の数値は、公開状況と競合環境を踏まえた主観的評価である。

| 評価対象 | 現時点の見込み |
|---|---:|
| 電子顕微鏡・原子散乱の専門分野で認知される可能性 | 7/10 |
| 広い科学計算コミュニティで有名になる可能性 | 3/10 |
| GitHub公開だけで自然に広く普及する可能性 | 2/10 |
| 査読論文、外部統合、実験的実証を伴う場合 | 8/10 |

Temariが目指すべき成功像は、巨大な一般向け科学ソフトになることではなく、次のような位置づけであると考えられる。

> **「この電子顕微鏡用原子量が必要ならTemariのデータを使い、Temariを引用する」**

すなわち、特定用途で標準的に参照されるreference implementationおよびdatasetになることが、最も現実的で価値の高い目標である。

## 7. 注目を得るための推奨優先順位

### 優先度A：科学的主張を一つに絞る

最も強い主張候補は、次のようなものである。

> Open, relativistic, reproducible off-diagonal ionization form factors for quantitative STEM-EDX and ALCHEMI.

「多機能な原子計算コード」として紹介するより、既存データが不足している具体的量を供給することを主題とする方が、国際的に伝わりやすい。

### 優先度B：データセット論文またはmethods paperを公表する

論文では、少なくとも以下を明示する必要がある。

1. 物理処方と近似
2. \(F(s,E_0)\) と通常の対角GOSの違い
3. 既存手法・既存データとの比較
4. 適用可能な元素、副殻、エネルギー、散乱ベクトル範囲
5. 数値誤差、モデル誤差、外挿・補間誤差の区別
6. 未解決のBethe-ridge差
7. 実験またはシミュレーション上の影響
8. DOI、データversion、再現コマンド

### 優先度C：観測量への影響を示す

数値表の差だけでなく、次のような最終観測量で既存データとの差を示すと説得力が増す。

- STEM-EDXマップの強度分布
- ALCHEMIにおけるサイト占有率推定
- 重元素L・M edgeの空間分解能または定量値
- 既存形状因子を用いた場合とTemariを用いた場合の差

### 優先度D：第三者による検証を得る

理想的には、別研究グループが少数の代表channelについて独立計算を行い、一致または不一致を報告できる状態を作る。そのため、検証対象を小さく切り出したbenchmark specificationを用意するとよい。

### 優先度E：既存エコシステムへ接続する

独自GUIの充実より、Python reader、Jupyter notebook、exspy／HyperSpy／abTEM等との接続例の方が、国際的な利用増加に直結しやすい。ユーザーが原子計算エンジンを実行しなくても、公開表を正しく利用できる経路を優先すべきである。

## 8. 最終評価

Temariは、ありふれた科学ソフトウェアではない。ただし、相対論的原子計算、GOS、Mott散乱、原子散乱因子といった個々の機能には、それぞれ強力な先行コードやデータベースが存在する。

Temariの本当の独自性は、次の三点の交差部分にある。

1. **電子顕微鏡用途に特化した非対角的イオン化形状因子**
2. **複数の散乱・励起量を生成する共通の相対論的原子エンジン**
3. **利用規約まで実行可能にした再現性重視の公開データセット**

現状は、「珍しく技術的に有望な実装とデータセットが存在するが、外部からの科学的評価はまだ始まっていない」段階である。

今後、査読論文、未解決差の解明、外部検証、既存解析ソフトとの統合が進めば、Temariは電子顕微鏡・原子散乱分野で国際的に参照されるデータ基盤になる可能性がある。その可能性は十分に現実的であるが、GitHub上に高機能なコードを置くだけでは実現せず、**独自な科学的主張を一つに絞り、データの有用性を観測量で示すこと**が重要である。
