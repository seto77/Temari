## 2. 次の作業 (この順で)

### (1) ★ 採用格子の作者判断 — **材料は揃った**

**推奨 = 真の中点 + dt/8 (1.25e-04)。**根拠と対案は §4.21.6。
⚠ dt/4 を採るなら §4.19 の内訳を「空間離散化 ≤6.5e-08」に**書き直す**必要があり、
全 Z 認証の余裕が 1 を割る。⚠ **測ったのは 4 / 約 100 元素**である。

### (2) 全 production Z, s で採用格子を認証

⚠ **探索に使った点と封印した検証点を分ける**。検証に失敗した点を次の探索に
使った時点で、それはもう holdout ではない。

⚠ 費用の目安: Au の SCF が dt/8 で **670 s**、dt/4 で 275 s。~100 元素を
8 レーンで回して 1 時間規模。⚠ **dt/16 まで測るのは非現実的** (Au 単独で 1340 s) ので、
認証は「採用格子 + 1 段粗い格子」から `E(h) = D/(2ᵖ−1)` で出すことになる。
**p = 2 を仮定することになるので、標本で p を検証してから**行うこと。

### (3) H / N の要因実験 — 8 条件

⚠ **予算に必要と分かるまで出荷経路へ入れない** (codex 手順 6)。
**dt/8 で予算を満たしたので、いまのところ不要**である。
⚠⚠ **最終 f_x 求積 Q を第 4 因子として管理する**。
H の高次化設計は §4.19 に確定済 (⚠ Gregory 補正は非推奨)。

### (4) f_e の `T_comp` を決める

⚠ **経路 D の絶対 Å 収束試験が先**。f_e は Å 単位で
|δf_e| = 0.0239·|δf_x|/s² と s に強く依存する。
⚠ 経路 D の原点は **値だけ**保証されている。次に測るべきは段差ではなく
**∂f_e/∂t|₀ と最初の数区間の絶対誤差**。

### (5) X1 / X13 / X14 と公開

schema・golden vector・manifest・決定論的梱包。⚠ **F dataset には混ぜない**
(別 release・別 Zenodo record)。

## 3. ⚠ 踏んだ罠 (同じ轍を踏まないこと)

すべて**実際にこのトラックで起きた**もの。★ が 2026-08-11 夕方の追加。

| 罠 | 何が起きたか |
|---|---|
| ★ **Richardson の帰属を 1 段間違えた** | 同じ差 D から `E(h)=D/(1−2⁻ᵖ)` と `E(h/2)=D/(2ᵖ−1)` の 2 つが出る (p=2 で **4 倍違う**)。細い方を粗い行に書き、**採用格子を 1 段甘く見せた**。数字は正しく帰属だけ誤りなので検算では気づけない |
| ★ **予算を B_num に当てた** | 格子への配分は 6e-08 で、9.09e-08 で判定すると **1.5 倍甘い**。Ne の legacy dt/4 が 1.00 → 1.52 に変わる |
| ★ **鍵を作る場所を増やした** | `cache_tag` を取得側にだけ足し、`ensure_converged` を取り残した。**SCF 再試行が誰も読まない鍵へ書き、未収束の原子が使われた**。error は出ない |
| ★ **残差を別の写像で測った** | `fixed_point_residual` が backend 無しで解き直し、真の中点の原子に legacy を当てていた (処方差 7e-07 が真の残差 7e-09 を 2 桁覆う) |
| ★ **最厳水準の未収束で走を全損させた** | 反復上限に当たるのはいつも最も締めた所なので、`error` にすると**収束した水準の結果まで失われる** |
| ★ **`@printf` の書式文字列を `*` で連結した** | マクロ展開時に落ちる。**2 回踏んだ** |
| ★ **一括置換が黙って空振りした** | grep が別の編集のヒットで隠した。⇒ **置換は 1 件ずつ、失敗が例外になる道具で** |
| **背景タスクの生成物を完了通知の前に読んだ** | 書き込み途中 (4788 B) をハッシュした。完全なファイルは 6720 B |
| **`Meta.parseall` は構文エラーを投げない** | ⇒ **構文確認は `include` で** |
| **一括の強調修正スクリプトが文書を壊した** | ⇒ **手で直す**。判定は `tools/md_emphasis_check.py` |
| **点核 Coulomb は spline 経路を素通りする** | `r·V = −Z` が定数なので補間が厳密になる |
| **異方式間の差を 16 で割った** | 同一方式なら **/15**。異方式間には適用できない |
| **s=0 での規格化検査は無意味** | 同じ離散求積で規格化と f_a(0) を計算すれば構成上成立する |
| **表示書式が測定を壊した** | 格子名を `%.2f` で作り、Δs=0.0125 と 0.00625 が衝突 |
| **引数解析が値を Z として拾った** | `--stages 4` の `4` を Z=4 と誤読 |
| **積分区間を誤って飽和させた** | 古典的禁止域まで延ばし、次数が −0.58 と出た |
| **中央値だけを見た** | ⇒ **符号付き比と反転数を必ず出す** |
