## 2. 次の作業 (この順で)

### (1) `gen_production.jl` に `numerics=:legacy_v5` を明示する — 軽い

⚠ **将来の既定変更に対する防御**であって、現在の正しさの問題ではない
(既定が `legacy_v5` なので今は正しい)。だから独立した小さな変更として先に片付ける。

配線が要るのは 4 箇所: `compute_channel` (`l5_exit_edx.jl:19`) →
`ensure_converged` / `get_neutral` / `get_ion` (`l5_channel.jl`)。
`PRESC_V3` / `PRESC_V4` に `numerics=:legacy_v5` を足す。

**検証**: ビット同一スナップショット (v3 5ch / v4 7ch) が上のハッシュと一致すること。

### (2) 4 元素 × 4 段の格子測定 — 重い

```bash
julia +1.11 -t auto tools/factor_convergence.jl 6 10 26 79 --quadrant --stages 4
```

⚠ dt/8 は格子 8 倍なので**これまでで最も重い**。背景実行にすること。

真の中点 backend でも同じことを行い、**採用格子を決める**。
⚠ 現状の第一候補は dt/4 だが、**Fe・Au は未測定**なので確定していない。

### (3) SCF tolerance を observable で決める

⚠ **dt から機械的に決めない** (p=2 だから 16 倍厳しく、では不十分)。
採用候補の最細格子で τ, τ/10, τ/100 を回し、**f_x の差**が
`B_num` の 10 % (≈9e-09) 以下になる τ を選ぶ。
⚠ mixing 下の「連続反復間の差」は真の固定点残差ではないので、
**unmixed な SCF residual も記録する**。

### (4) 全 production Z, s で採用格子を認証

⚠ **探索に使った点と封印した検証点を分ける**。検証に失敗した点を次の探索に
使った時点で、それはもう holdout ではない。

### (5) H / N の要因実験 — 8 条件

⚠ **予算に必要と分かるまで出荷経路へ入れない** (codex 手順 6)。
3 因子なら 8 条件全部が要る。⚠⚠ **最終 f_x 求積 Q を第 4 因子として管理する**
— H/N を高次化しても f_x 自身が 2 次求積なら要因差に Q の誤差が混ざる。

H の高次化設計は §4.19 に確定済 (t = ln r 上で各セルを独立に 4 次で積み、
中点は明示的な 4 点補間。⚠ Gregory 補正は非推奨)。

### (6) f_e の `T_comp` を決める

⚠ **経路 D の絶対 Å 収束試験が先**。f_e は Å 単位で
|δf_e| = 0.0239·|δf_x|/s² と s に強く依存するので、いま数字を置けばまた恣意的になる。
配分方針 (B_repr = 0.1·B_num) だけ先に決まっている。

⚠ 経路 D の原点は **値だけ**保証されている。次に測るべきは段差ではなく
**∂f_e/∂t|₀ と最初の数区間の絶対誤差**。

### (7) X1 / X13 / X14 と公開

schema・golden vector・manifest・決定論的梱包。⚠ **F dataset には混ぜない**
(別 release・別 Zenodo record)。

## 3. ⚠ 踏んだ罠 (同じ轍を踏まないこと)

すべて**実際にこのトラックで起きた**もの。

| 罠 | 何が起きたか |
|---|---|
| **背景タスクの生成物を完了通知の前に読んだ** | 書き込み途中 (4788 B) のファイルをハッシュし、誤った値を文書に記録した。完全なファイルは 6720 B |
| **`Meta.parseall` は構文エラーを投げない** | `Expr(:error, …)` を返すだけなので「parse OK」と報告しながら実際は読み込めなかった。⇒ **構文確認は `include` で** |
| **一括の強調修正スクリプトが文書を壊した** | `**` の開き/閉じを対にせず正規表現で判定するため、閉じ側を開き側と誤認して句読点を強調の内側へ移す。⇒ **手で直す** |
| **点核 Coulomb は spline 経路を素通りする** | `r·V = −Z` が定数なので `RvSpline` の補間が厳密になり、中点評価を一切試していなかった |
| **異方式間の差を 16 で割った** | legacy at dt と真の中点 at dt/4 の差は同一方式の Richardson ではない。同一方式なら **/15** |
| **s=0 での規格化検査は無意味** | 同じ離散求積で軌道規格化と f_a(0) を計算すれば f_a(0)=n_a は構成上成立する |
| **表示書式が測定を壊した** | 格子名を `%.2f` で作り、Δs=0.0125 と 0.00625 が同じキーに衝突して集計が壊れた |
| **引数解析が値を Z として拾った** | `--stages 4` の `4` を Z=4 と誤読し、毎回 Be を混ぜていた |
| **積分区間を誤って飽和させた** | M の単体試験を古典的禁止域まで延ばし、Au が全段 ~1.0 に飽和して次数が −0.58 と出た |
| **中央値だけを見た** | 符号反転が 19/24 点あるのに p=2.84 が妥当な測定に見えた。⇒ **符号付き比と反転数を必ず出す** |

f_x の単調減少 / 大 K の漸近指数 / 強制済みの f_x(0)=Z /
