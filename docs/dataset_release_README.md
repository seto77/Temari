# Temari dataset v5.0.0 — inner-shell ionization form factors F(s, E₀)

Generated by [Temari](https://github.com/seto77/Temari). This archive is the
**data only**; the software is released separately and carries its own version.

## Five things that will bite you

These are not stylistic preferences. Each one has been observed to break a
consumer, and each is checked by `temari_contract.py`.

1. **F is signed.** 358 of the 525 channels contain negative values, the
   smallest being −0.3194. Any path that treats F as non-negative — `clip(0)`,
   `abs`, an assumption of monotonicity — corrupts it silently, and the
   corruption survives integration over q. This is why F is *not* published in
   the GOSH format, whose consumers clip.
2. **The momentum convention is q = 4πs [Å⁻¹]**, so K = 4πs·a₀ in atomic units.
   Using s directly as a momentum is wrong by 4π.
3. **Beyond `s_cert` the values are exactly-zero padding, not calculated.**
   Each row declares how far it reaches. Feeding the padding into an
   interpolation basis drags the result toward zero.
4. **The E₀ axis differs from channel to channel** — 459 distinct axes across
   525 channels. There is no dense [channel, E₀, s] cube.
5. **`eps` is an upper bound and must not be interpolated in E₀.** Take the
   maximum of the two bracketing rows; an interpolated bound is not a bound.

And two more that concern how, not what:

6. **E₀ interpolation runs in x = ln(u−1), with y = log F where the column is
   positive.** Interpolating in raw E₀ over raw F gives different answers from
   the shipping consumer — up to 2.9e-03, and with the sign reversed in places.
7. **Beyond `s_cert` there are two distinct regions.** Between `s_cert` and
   `s_kin = 1/λ(E₀)` the value is unrecorded and carries the bound `eps`. Above
   `s_kin` no such beam pair exists on the Ewald sphere at all, so the request
   itself does not stand — attaching a bound there would be guaranteeing
   something about a configuration that cannot occur.

## What this dataset does not claim

- **Beyond s ≈ 4 Å⁻¹ there is no external yardstick.** The most recent
  published database in the field stops at q = 50 Å⁻¹, which is s = 3.98 Å⁻¹ in
  this convention. The range from there to 16 Å⁻¹ is verified against internal
  identities and analytic limits, not against anyone else's numbers.
- **The absolute cross sections are Bote–Salvat**, not this calculation. The
  engine's own σ is reported alongside as a sanity indicator only.
- **F is a shape, normalized to F(0) = 1.** It is not a GOS and must not be
  substituted for one.

## Verifying what you received

```bash
sha256sum -c temari-dataset-v5.0.0.tar.gz.sha256   # the archive
python tools/temari_contract.py .                  # the contents
```

`manifest.json` carries `digest_sha256`, computed over the sorted
`<file>:<sha256>` lines, so it is independent of file order and of the time of
packing. The archive is built deterministically: the same inputs produce the
same bytes, which is what lets the copy on Zenodo and the copy on GitHub be
compared rather than merely trusted.
