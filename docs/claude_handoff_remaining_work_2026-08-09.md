## 1. 次に着手する優先課題

### P1. 閾値直上の求積監査

`src/gen_production.jl` の `audit()` は現在、次の高過電圧3ケースだけを測っている。

- Fe K @ 200 kV
- Au L3 @ 300 kV
- Au M5 @ 200 kV

一方、v5で最も極端だったのは Sn K @ 30 kV（`u ≈ 1.03`）。閾値直上では放出電子が
ほぼ静止し、Fが高sまで減衰せず符号反転も大きい。この領域の求積誤差は未測定。

実施内容:

1. Sn K @ 30 kV、または同等の `u ≈ 1.03–1.05` ケースを `audit()` に追加する。
2. 固定 `0:0.25:16` を渡さず、`s_cert_of(e0)` で監査sグリッドを切る。
3. HIGHと各bumpの `max|ΔF|` を保証域内だけで測る。
4. 高過電圧ケースの既存結果を変えない。
5. 結果と採否を `docs/next_phase_2026-08-12.md` に反映する。

対象: `src/gen_production.jl` の `audit()`（現在およそ758行目）。

### P2. `check_tables` のC2検査窓を再設計

`tools/check_tables.jl` のK殻単調性検査は、81点時代の `s ≤ 4 Å⁻¹` のまま。
ただしK殻でも高sでは物理的に正常な符号反転があるため、単純に16まで広げてはいけない。

実施内容:

1. v5全Kチャネルについて、最初の極値・最初のゼロ交差・E0依存を実測する。
2. 「正値かつ単調減少であるべき領域」をデータから定義する。
3. 物理的符号反転を誤検知しないC2へ変更する。
4. 意図的な異常データでC2が確実に落ちる回帰試験を追加する。
5. C2の説明と実装の窓を一致させる。

対象: `tools/check_tables.jl` の `i_s4` / C2（現在およそ79行目）。

### P3. `s_cert` と `s_kin` の契約を分離

現在の消費側契約は、次の2領域を同じ「0 + ε」相当として扱う。

- `s_cert < s ≤ s_kin`: 物理的には可能だが未収録
- `s > s_kin`: Ewald球上で運動学的に不可能

後者は上界付きゼロではなく、要求自体が成立しないことを返すべき。

この変更は単独ファイルで済まない。以下を一組として扱うこと:

- 生成JSONへの `s_kin` 情報または計算に必要な情報の契約化
- `schema/temari_dataset_v2.schema.json`
- `tools/temari_contract.py`
- `tools/check_tables.jl`
- ReciPro側ローダー／Evaluate
- EdxCheck / AlchemiCheck

既存データとの互換方法とschema/version更新の要否を先に決めること。

## 2. 精度検証の残件

### V1. 小成分の外部照合

`small_component_fraction` は内部恒等式では検査済みだが、外部数値との照合は未実施。
Zhangらの公開値はおおよそ次の桁を示す。

- Si: 0.03 %
- Ag: 0.6 %
- Au: 2 %

実施する場合:

1. Si / Ag / Auについて同じ定義・同等の状態を計算する。
2. 定義が `∫F² / ∫(G²+F²)` で一致することを再確認する。
3. 先方は有効数字1桁程度なので、精密一致ではなく桁・傾向の検査とする。
4. 結果を `docs/literature_findings_2026-08-12.md` §3へ記録する。

### V2. v5の `s=8–16 Å⁻¹` の外部照合

この範囲を直接覆う既存外部データはほぼ無い。比較相手を無理に生成しない。
見つからない場合は、MANIFESTと利用者向け文書に「外部照合の無い範囲」と明記する。
