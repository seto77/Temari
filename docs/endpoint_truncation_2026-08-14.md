未収束解との差は端点効果の測定にならない (検査不能) ので:

- `certify_endpoints.jl` に **L¹ と同じ元素単位ラダー**を追加 (`d91f756`)。
  どれかが未収束なら base + 全変種を β0.08/2400 で解き直す。
  ⚠ **変種ごとに「最初に収束した試行」を混ぜない** — base との差に
  mixing・停止点の手順差が混入する (certify_l1.jl のラダー設計と同じ理由)
