## 2. ✅ 完了 — KLI を SCF へ配線し、Latter を削除した

`SCFAtom` に `exchange::Symbol = :xalpha | :kli` を足し、CLI は `--kli`。
設計は当初案どおり (初回反復を Xα でブートストラップ / 密度と**別に** vx も混合 /
Latter クリップを外して尾は `-(Z−N+1)/r`)。実装で分かったことだけ以下に残す。

### 予定と違ったところ

- **遠方の 0/0 は実在した** (`tail_guard!`)。`solve_bound` は WKB 減衰が 80 e-fold
  を超えた先の軌道を**厳密に 0** にするので、そこで V_x の分子も分母も 0 になり、
  ガード無しでは V_x が 0 に落ちて尾が壊れる。H 様 Z≥2 で実際に踏んだ
  (r·V が −1 ずれた)。ρ̃ < 1e-120 で厳密な漸近 −1/r に落とす
- **散乱 (phase 出口) は KLI の V_eff を使ってはいけない**。中性標的の静的場は
  遠方で 0 に落ちねばならないが、KLI の V_eff は −1/r の尾を持つ。これは KS
  ポテンシャルとして正しく、飛来電子の静的場としては誤り。KLI の改善は**密度**を
  通して受け取り、交換は局所形で当てる (`V_bound_callable(...; local_exchange=true)`)
- **「閉殻は Latter 版と大きく変わらない」は外れ**。Ne でも密度は 4.7% 動く
  (⟨r²⟩ 0.895 → 0.937)。α=1 の局所交換は閉殻でも厳密交換とかなり違う
- **コストは見積もりどおり**: Au (非相対論 14 副殻) で 21 s/原子

### 検査の結果

1. Latter 無しで収束 ✓ / 中性の漸近 r·V → −1.0005〜−1.0008 ✓ /
   core-hole イオン → −2.0004 ✓ (selftest T18b)
2. **最も鋭い検査 = 1 電子系** (T18a): 厳密交換は Hartree を完全に打ち消すので
   V_eff は裸の −Z/r に戻らねばならない。max\|r·V+Z\| = 1.1e-9、ε/(−Z²/2) = 1±2e-9。
   自己相互作用の相殺・u_x の 1/2・Δ の連立解・遠方ガード・SCF 配線が一度に見える
3. 密度は**広がる** = 診断書 §1 の「収縮しすぎ」を直す向き ✓ (T18c)
4. **payoff は当初目標を超えた** — `docs/exchange_diagnosis_2026-08-07.md` §5 が正本。
   f_x/f_e は α=1 に対して 3–15 倍良く、**「最良の α」0.75 よりも良い**。
   σ_own/σ_Bote は 0.083 → 0.086 と僅かに悪化 (トレードオフ自体は残る)
5. 既存ゲート一式 ✓ — selftest ALL PASS / refcheck 9.044e-08 (基準値どおり) /
   SIMD 288 + qlane 75 ビット同一 / **5 チャネル === ビット同一** (既定処方は無傷)

### 出荷既定は Dirac + Xα のまま

KLI は非相対論 SCF にしか配線していない。Au では相対論的収縮が交換の改善を圧倒する
(Dirac+Xα 0.82% vs 非相対論 KLI 2.68%) ので、**重元素の判定は Dirac-KLI 待ち**。

## 2′. ★次の一手 — KLI を Dirac 経路へ広げる

これが済むと「Dirac + 厳密交換 + Latter 無し」という、knob がひとつも無い原子場が
全元素で使えるようになり、**出荷既定を差し替えるかどうかの判断ができる**。

### 決めなければいけないこと (物理)

1. **小成分 F を交換に入れるか。** Dirac–Fock 本来は入る。Au 1s では ∫F² が全体の
   ~9% なので無視できない。入れると Y^k を (G_a G_b + F_a F_b) で作ることになる
2. **角度係数を κ 分解にする**。いまの `threej000_sq(l_a, k, l_b)` は非相対論の
   軌道角運動量の 3j。Dirac では j (= κ) の 3j に置き換わり、
   c^k = [3j(j_a k j_b; ½,0,−½)]² × パリティ条件 になる
3. **整数占有の自己項補正の κ 版**。いまの D_k(l) = 1/(2k+1) に相当する和則を
   j について取り直す (selftest T17 と同じ形の検査を作れるはず)

### 実装上の足場

- `SCFAtom` の Dirac 経路は `orbs[key]` に**占有加重和**を入れている (診断用)。
  KLI には軌道そのものが要るので、(n,l,κ) ごとの G, F を持つ辞書を別に作る
- `dirac_occupancy` が既に (n, l, κ, q) を返すので、副殻の並べ方はそのまま使える
- ガードは共有できる (`tail_guard!` は κ に依らない)

### 検査 (この順に)

1. **c → ∞ で非相対論 KLI に退化すること** (T8/T13 と同じ思想。これが本命の構造検査)
2. 1 電子系 (H 様 Z=1,2,26) で V_eff → −Z/r。相対論でも自己相互作用は完全に消える
3. 漸近 −(Z−N+1)/r が Dirac でも出ること
4. payoff: Au/Ag の f_x を WK と比べ、Dirac+Xα の 0.82% を下回るか
5. 下回ったら **出荷既定の差し替えを検討** (model_id・テーブル全再生成とセット)

## 3. 今セッションで確定した物理 (蒸し返さない)

### 3.1 交換の診断 — 正本は `docs/exchange_diagnosis_2026-08-07.md`

- f_x の残差は**常に正**、絶対値の山は s ≈ 0.2–0.4 → **密度が収縮しすぎ**
- **Latter は主犯ではない** (Fe で有無が 1.55% vs 1.56%)。主因は局所交換の強さ
- **α を動かすのは解決にならない**: 最適 α は全元素 0.70–0.75 (Schwarz の値域) だが、
  f_x は 0.75 を、σ と 1s 固有値は 1 を好む。α=1+Latter は「固有値を束縛エネルギーに
  合わせる」設計、α≈0.7 は「HF の密度を再現する」値で、目標が違う

### 3.2 厳密交換の定式 (実装済み・検証済み)

    E_x = −(1/2) Σ_{ab} Σ_k c^k(l_a,l_b) W^k_{ab} G^k(ab)
    c^k = [3j(l_a k l_b;000)]²,  G^k(ab) = ∫ P_a P_b Y^k(ab;r)/r dr
    W^k_{ab} = q_a q_b/2 + δ_{ab}[(2l_a+1)q_a − q_a²/2]/(2k+1)

第 2 項が**整数占有の自己項補正**。球平均のために m の**選び方**を平均すると
⟨n(m)n(m′)⟩ = f² + δ_{mm′}(f−f²) となり、⟨n²⟩=⟨n⟩ (占有は整数) だから出る項。
角度因子は D_k(l) = Σ_m[3j(l k l;−m,0,m)]² = **1/(2k+1)** (l に依らない、実測確認)。

**この 1 項で 3 つが同時に正しくなる**:
1 電子の完全相殺 (4.4e-16) / 閉殻は補正ゼロ / **開殻の漸近が −1/r**
(C 2p²: −0.335 → −1.002、Au 6s¹: → −1.00001)。**スピン分極は不要**。

⚠ `33c689b` のコミットメッセージに「球平均した開殻では −1/r は原理的に回復
できない」と書いたが**これは誤り**。`e722f3b` で訂正済み。

### 3.3 危険な落とし穴 (実際に踏んだ)

- **u_x の 1/2**: δE/δP_a = 2q_aε_aP_a なので u_x P_a = (1/(2q_a))δE_x/δP_a。
  落とすと Slater ポテンシャルと 2 倍食い違う。恒等式 **Σ_a q_a ū_a = 2E_x** で固定 (T16)
- **u_x 自体を作らない**: P_a の節で 0/0。常に **P_a² u_x** の形で扱う
- **交換係数の二重計上**: `slater_vx` に α を畳み込むと終状態の KS(2/3) が (2/3)α に
  なる。**`slater_vx` は素の Slater 形**、α は SCF 側、2/3 は終状態側で掛ける (T13b)
- **キャッシュキーの取り違え**: 束縛状態の鍵に SCF 種別・α を入れ忘れると、
  `--dscf` 実行が入れた 1s を非 dscf 実行が黙って読む。refcheck が
  `|dE_b/E_b| = 2.2e-3` で検出した (K 殻だけ、L 殻無傷という症状)
