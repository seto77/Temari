## 2. ✅ 完了 — KLI を SCF へ配線し、Latter を削除した

`SCFAtom` に `exchange::Symbol = :xalpha | :kli` を足し、CLI は `--kli`。
設計は当初案どおり (初回反復を Xα でブートストラップ / 密度と**別に** vx も混合 /
Latter クリップを外して尾は `-(Z−N+1)/r`)。実装で分かったことだけ以下に残す。

### 予定と違ったところ

- **遠方の 0/0 は実在した** (`tail_guard!`)。`solve_bound` は WKB 減衰が 80 e-fold
  を超えた先の軌道を**厳密に 0** にするので、そこで V_x の分子も分母も 0 になり、
  ガード無しでは V_x が 0 に落ちて尾が壊れる。H 様 Z≥2 で実際に踏んだ
  (r·V が −1 ずれた)。ρ̃ < 1e-120 で厳密な漸近 −1/r に落とす
- **散乱 (phase 出口) は KLI の V_eff を使ってはいけない**。中性標的の静的場は
  遠方で 0 に落ちねばならないが、KLI の V_eff は −1/r の尾を持つ。これは KS
  ポテンシャルとして正しく、飛来電子の静的場としては誤り。KLI の改善は**密度**を
  通して受け取り、交換は局所形で当てる (`V_bound_callable(...; local_exchange=true)`)
- **「閉殻は Latter 版と大きく変わらない」は外れ**。Ne でも密度は 4.7% 動く
  (⟨r²⟩ 0.895 → 0.937)。α=1 の局所交換は閉殻でも厳密交換とかなり違う
- **コストは見積もりどおり**: Au (非相対論 14 副殻) で 21 s/原子

### 検査の結果

## 2′. ✅ 完了 — KLI を Dirac 経路へ広げた

3 つの決め事は全部片付いた。**小成分は入れる** (重なり密度が G_aG_b + F_aF_b になる。
Dirac–Fock 本来の形)、角度係数は [3j(j_a k j_b;½0−½)]² × π(l_a+k+l_b 偶)、
自己項の縮退度は 2j+1 でスピン和の 1/2 が消える。3 つを並べると

    W^k = s·{ q_a q_b + δ_ab (D_a q_a − q_a²)/(2k+1) }
    s = 1/2, D = 2(2l+1)  (非相対論)  /  s = 1, D = 2j+1  (Dirac)

という同じ形。**jj の係数を κ について足すと LS の係数に厳密に戻る** (3.6e-15) ので、
c→∞ で非相対論 KLI に落ちる — これが本命の構造検査 (T19a)。

### 結果 — 参照のノイズ床に届いた

正本は `docs/exchange_diagnosis_2026-08-07.md` §6。相対指標 (s≤2) で

| Z | Dirac+Xα (現行出荷) | **Dirac+KLI** | 参照間スプレッド (WK vs CM) |
|---|---|---|---|
| 6 | 2.39% | **0.19%** | 0.32% |
| 14 | 2.34% | **0.14%** | 0.19% |
| 26 | 1.42% | **0.19%** | 0.18% |
| 79 | 0.82% | **0.12%** | 0.13% |

**公開パラメータ化どうしの食い違いと同等かそれ以下**に入った。σ_own/σ_Bote は
0.0730 → 0.0770 と僅かに悪化。コストは SCF 1.9 倍 (Au 30 s → 56 s、元素ごとに 1 回)。

### 実装で分かったこと

- **κ 分裂した HOMO の相方が定数オフセットを残す** (2–3e-4 Ha)。Ne 2p½ は格子端まで
  密度の 29% を占め、その Δ ≠ 0 が corr に残る。**取り除いていない** — 束縛問題では
  V の定数は波動関数を変えない (固有値が一様に動くだけ) ので、密度由来の出荷量には
  効かない。ゲージを取り直す規則は軌道ごとに打ち切り半径 45/λ が違うせいで
  場当たりにしかならず、場当たりを入れるより T19c で上から抑える方を選んだ
- **開殻では jj と LS の平均配置が原理的に一致しない** (DF-AOC と HF-AOC の既知の差)。
  c→∞ の退化テストは**閉殻元素で行う** (Ne)。閉殻なら自己項が両方 0 で厳密に一致する

## 2‴. ★GOS の数 % — 原因は特定済み。処方の選択の問題であってバグではない

Zhang ら (2023) の Dirac GOS DB (`refs/data/`) と比べると、水素は **3e-5** で一致するのに
実元素では Fe K −5.5% / Au L3 −7% ずれる。残差が ε・q にわたり**平坦**なのが手がかりで、
波動関数の形ではなく処方の違いを示していた。

**論文に明記されている**: 彼らは **frozen core** — 「the potential remains unchanged for the
initial and final states」。連続状態は**中性原子の場**で解かれ、Z∞ = −lim r·V → 0。
初期状態と終状態が厳密に同じポテンシャルなので**直交性が保証**され、Q→0 の発散が構造的に
消える。我々は**緩和 core-hole イオン** (Z∞ = 1) で、直交性が壊れるので Gram–Schmidt が要る。

**水素で 3e-5 一致したのは 1 電子系では両処方が一致するから** — だから水素は
規約の確定には使えても、この違いの検出には使えない。

実測 (我々/先方の平均比):

| | 緩和イオン (既定) | 中性場を入れた版 |
|---|---|---|
| Fe K | 0.940 | **0.993** |
| Fe L3 | 1.062 | 1.748 |
| Au L3 | 0.929 | 1.074 |

**Fe K はギャップがほぼ閉じる。** L3 で悪化するのは、この試験がまだ彼らの処方に
なっていないため — 中性場を終状態に入れただけで、**束縛側 (Latter 補正 + α=1) と
終状態側 (Latter なし + 2/3 交換) が別ポテンシャルのまま**。frozen core の要点は
「同一ポテンシャル」なので、そこを揃えないと直交性の利得が出ない。

### ⚠ ここは「合わせに行く」判断をする前に測ること

緩和 core-hole は**当て推量ではなく、Oxley–Allen / µSTEM との A/B で選ばれた**処方で、
F(s) を最も動かした要素 (第 5 章のコメント)。Zhang らに合わせると **F(s) の外部検証と
衝突しうる**。やるべきはどちらかに寄せることではなく:

1. **厳密な frozen core を実装する** (束縛と連続を同一ポテンシャルで解く)。直交性が
   厳密になるので Gram–Schmidt が不要になり、**それ自体が実装の検査になる**
2. 両処方で GOS を Zhang らと、F(s) を Oxley–Allen/µSTEM と比べる
3. 出荷処方はその 2 枚の表を見て決める (作者判断)

### 同時に残っている、より小さい寄与

- **端エネルギーの定義差**: 我々は Bote–Salvat (Fe K 7083.5 eV)、先方は計算値 (6960.5 eV)。
  GOS は ΔE を陽に含むので 1.8% の系統差になる
- **遷移行列要素の小成分**: 先方は R = ∫[P_aP_b + Q_aQ_b] j_λ dr (式 40)、我々は大成分のみ
- **連続状態の κ 分解**: 先方は κ 分解 Dirac、我々はスカラー相対論

## 3. 今セッションで確定した物理 (蒸し返さない)

### 3.1 交換の診断 — 正本は `docs/exchange_diagnosis_2026-08-07.md`

- f_x の残差は**常に正**、絶対値の山は s ≈ 0.2–0.4 → **密度が収縮しすぎ**
- **Latter は主犯ではない** (Fe で有無が 1.55% vs 1.56%)。主因は局所交換の強さ
- **α を動かすのは解決にならない**: 最適 α は全元素 0.70–0.75 (Schwarz の値域) だが、
  f_x は 0.75 を、σ と 1s 固有値は 1 を好む。α=1+Latter は「固有値を束縛エネルギーに
  合わせる」設計、α≈0.7 は「HF の密度を再現する」値で、目標が違う

### 3.2 厳密交換の定式 (実装済み・検証済み)

    E_x = −(1/2) Σ_{ab} Σ_k c^k(l_a,l_b) W^k_{ab} G^k(ab)
    c^k = [3j(l_a k l_b;000)]²,  G^k(ab) = ∫ P_a P_b Y^k(ab;r)/r dr
    W^k_{ab} = q_a q_b/2 + δ_{ab}[(2l_a+1)q_a − q_a²/2]/(2k+1)

第 2 項が**整数占有の自己項補正**。球平均のために m の**選び方**を平均すると
⟨n(m)n(m′)⟩ = f² + δ_{mm′}(f−f²) となり、⟨n²⟩=⟨n⟩ (占有は整数) だから出る項。
角度因子は D_k(l) = Σ_m[3j(l k l;−m,0,m)]² = **1/(2k+1)** (l に依らない、実測確認)。

**この 1 項で 3 つが同時に正しくなる**:
1 電子の完全相殺 (4.4e-16) / 閉殻は補正ゼロ / **開殻の漸近が −1/r**
(C 2p²: −0.335 → −1.002、Au 6s¹: → −1.00001)。**スピン分極は不要**。

⚠ `33c689b` のコミットメッセージに「球平均した開殻では −1/r は原理的に回復
できない」と書いたが**これは誤り**。`e722f3b` で訂正済み。

### 3.3 危険な落とし穴 (実際に踏んだ)

- **u_x の 1/2**: δE/δP_a = 2q_aε_aP_a なので u_x P_a = (1/(2q_a))δE_x/δP_a。
  落とすと Slater ポテンシャルと 2 倍食い違う。恒等式 **Σ_a q_a ū_a = 2E_x** で固定 (T16)
- **u_x 自体を作らない**: P_a の節で 0/0。常に **P_a² u_x** の形で扱う
- **交換係数の二重計上**: `slater_vx` に α を畳み込むと終状態の KS(2/3) が (2/3)α に
  なる。**`slater_vx` は素の Slater 形**、α は SCF 側、2/3 は終状態側で掛ける (T13b)
- **キャッシュキーの取り違え**: 束縛状態の鍵に SCF 種別・α を入れ忘れると、
  `--dscf` 実行が入れた 1s を非 dscf 実行が黙って読む。refcheck が

# 処方の切り替え
--nodscf     非相対論 SCF に戻す (既定は完全 Dirac SCF)
--kli        厳密交換 (KLI、Latter 無し)。--nodscf と組めば非相対論版
