## 2. ~~★次の一手 A — 厳密 frozen core を実装する~~ → **実施済 (2026-08-07)**

> **測定の正本は `docs/frozen_core_and_transverse_2026-08-07.md`。**
> `prepare_channel(...; final_state = :relaxed | :frozen | :frozen_static)` として
> 実装。出荷既定は `:relaxed` のままで、5 チャネル === ビット同一。
>
> 本節の記述で**訂正が要る点が 2 つある** (詳細は上記の正本):
> - 「連続状態は中性原子の場で解かれ、Z∞ → 0」は**誤り**。Zhang らは FAC の
>   「交換の漸近を直した局所密度近似」= Latter 型を使うので、中性原子でも
>   KS ポテンシャルの尾は −1/r (z_asym = 1)。frozen core の要点は
>   「同一ハミルトニアン」であって尾を 0 にすることではない。両方実装した
>   (`:frozen` が z_asym=1、`:frozen_static` が 0) が、**実用窓では 0.2 % しか違わない**
> - 予備実験の比 (Fe K 0.940 → 0.993 等) は**先方 DB の占有数規約を入れていない**。
>   先方の L2/L3 は 2p 殻まるごと (6 電子) で規格化されている。補正込みの実測は
>   Fe K 0.9425 → 0.9664、Fe L3 1.0016 → 0.9933、Au L3 0.8951 → 0.8835
>
> 下記の検査 1 (直交性) は**丸め誤差まで落ちた** (Au L3 で 3.8e-14)。ただし
> 演算子を揃えた測定でのみ — 本番の `max_ortho_c` は Dirac/Schrödinger の
> 演算子不一致で落ちない。切り分けは正本 §1.2。

### なぜ

Zhang ら (2023) の Dirac GOS DB と比べると、**水素は 3e-5 で一致するのに実元素で
Fe K −5.5% / Au L3 −7% ずれる**。残差が ε = 2–580 eV、q = 0.2–6 Å⁻¹ にわたり
**平坦**なのが手がかりで、波動関数の形ではなく処方の違いを示していた。

**論文に明記されている**: 彼らは **frozen core** — "the potential remains unchanged
for the initial and final states"。連続状態は**中性原子の場**で解かれ、
Z∞ = −lim r·V → 0。始状態と終状態が厳密に同じポテンシャルなので**直交性が保証**され、
Q→0 の発散が構造的に消える。我々は**緩和 core-hole イオン** (Z∞ = 1) で、直交性が
壊れるため Gram–Schmidt が要る。

**水素で一致したのは 1 電子系では両処方が一致するから** — 水素は規約の確定には
使えても、この違いの検出には使えない。

終状態場だけ中性場に差し替えた予備実験 (我々/先方の平均比):

| | 緩和イオン (既定) | 中性場を入れた版 |
|---|---|---|
| Fe K | 0.940 | **0.993** |
| Fe L3 | 1.062 | 1.748 |
| Au L3 | 0.929 | 1.074 |

**Fe K はギャップがほぼ閉じる。** L3 で悪化するのは、この予備実験がまだ彼らの処方に
なっていないため — 中性場を終状態に入れただけで、**束縛側 (Latter 補正 + α=1) と
終状態側 (Latter なし + 2/3 交換) が別ポテンシャルのまま**。frozen core の要点は
「同一ポテンシャル」なので、そこを揃えないと直交性の利得が出ない。

### やること

`prepare_channel` に `final_state::Symbol = :relaxed | :frozen` を足し、`:frozen` では
**束縛状態も連続状態も同一ポテンシャル**で解く:

```julia
# 尾を 0 に落とした中性場 (Latter クリップ無し)。局所交換で組む
vb = V_bound_callable(neutral; latter_charge=0.0, local_exchange=true)
E_b, r_b, u_b, frac_small = solve_dirac_bound(vb, z; kappa=kap, n_nodes=n_b-l_b-1)
ion_pot = IonPotential(z, 0.0, neutral.r, vb)     # ★同じ場を終状態にも使う
```

`IonPotential` は `(z, z_asym, r, V::RvSpline)` の内部コンストラクタを持つので、
新しい型を作らずそのまま使える。`V_for` / `r_match_for` もそのまま動く
(`r_match_for` は z_asym=0 でも動く — `phase` 出口が既にそうしている)。

## 3. ~~★次の一手 B — 横断的 (Møller) 相互作用~~ → **実施済 (2026-08-07)**

> **測定の正本は `docs/frozen_core_and_transverse_2026-08-07.md`。**
> `--transverse` (edge 出口のみ)。既定 off で、5 チャネル === ビット同一。
>
> **⚠ 下に書き写した式 38 は横断項の分母に q² が落ちている。**そのまま組むと
> 第 1 項が [長さ⁴]・第 2 項が [長さ²] で次元が合わず、Fe K @200 keV の σ が
> **21 倍**になる。正しい核は
>
>     W(q) = 1/q⁴ + β_t² (ΔE/ħc)² / [ q² (q² − (ΔE/ħc)²)² ]
>
> これは同じ論文の式 42 と双極子極限で厳密に一致する (18 ケースで最大差 2.8e-4、
> selftest T22b)。式 42 の方も印字は x ≫ β² の近似なので、厳密な原始関数に
> 直して比べること。
>
> 検査 3 の結果: **σ_own/σ_Bote が 1 に寄る。しかも E0 依存性の形が合う。**
> 縦のみだと Fe K で 1.063 → 0.904 と E0 とともに 15 % ドリフトするのが、
> 横断項で 1.069 → 0.990 とほぼ平らになる。検査 4 (Llovet 2014 の実験集成) は未実施。

### なぜ

σ_own/σ_Bote が C K 0.86 / Fe K 0.97 / Au L3 0.95。**出荷 σ は Bote–Salvat なので、
これは出荷値と自前値を比べる循環比較**で検証になっていない。自前 σ を主張するには
足りない項を入れ、**実験集成と比べる**必要がある。

差の内訳候補は 3 つで、**(a) が最も安く効きが大きい**:

- **(a) 横断的 (Møller) 相互作用**。我々は 1/q⁴ のクーロン項のみ。200–300 keV では
  数 % 効く。**行列要素は既にあるので配管だけ**
- (b) 交換項 −Re(DX*) (v4 の最大の物理項)
- (c) 入射電子の歪曲波 (DWBA 本体、大仕事)

### 式 (Zhang ら 2024、`refs/Zhang_2024_arXiv2405.10151_*.pdf` の式 38–39)

    ∂²σ/∂E∂Ω = (2γ/a₀²)(k_f/k_i) [ 1/q⁴ + β_t²(ΔE/ħc)²/(q² − (ΔE/ħc)²)² ] Σ|⟨f|e^{iqr}|i⟩|²
    β_t² = β² − ΔE²/(cq)² · (1 + ((cq)² − ΔE²)/(2ΔE(E₀ + m_ec²)))

つまり **1/q⁴ を [1/q⁴ + 横断項] に置き換える**だけ。

### やること

- **K=0 の分岐 (σ・EELS) から入れる**。そこでは Q₊ = Q₋ = q なので曖昧さがない
- F(s) の MDFF (Q₊ ≠ Q₋) へ広げるのは**別途検討が要る** — 横断項の混合形式を
  決める必要がある。まず σ 側で効きを測ってから
- **既定では off**。オプション (`--transverse` 等) で入れ、model_id に印を付ける。
  出荷テーブルに影響する変更はビット同一か全再生成とセット (§7)

### 検査

1. **c → ∞ で横断項が消えること** (β → 0。T8/T13 と同じ思想の構造検査)
2. **低 E0 で寄与が小さく、高 E0 で増えること** (β² に比例)
3. **σ_own/σ_Bote が 1 に寄るか**。寄れば「Bote–Salvat が持っていて我々が持って
   いなかった項」の一つを特定したことになる
4. **検証先を Llovet et al. 2014 (`refs/`) の実験集成へ移す**。Bote–Salvat との
   比較は循環なので、そこで止めない

### 6.2 厳密交換の定式 (実装済み・検証済み)

非相対論 (LS) と Dirac (jj) は**同じ形**に書ける:

    E_x  = −(1/2) Σ_{ab} Σ_k c^k W^k_{ab} R^k(ab)
    W^k  = s · { q_a q_b + δ_ab (D_a q_a − q_a²)/(2k+1) }

    非相対論: s = 1/2, D = 2(2l+1), c^k = [3j(l_a k l_b;000)]²,
              R^k = ∫ P_a P_b Y^k/r dr
    Dirac   : s = 1,   D = 2j+1,    c^k = [3j(j_a k j_b;½0−½)]² × π(l_a+k+l_b 偶),
              R^k = ∫ (G_aG_b+F_aF_b) Y^k/r dr

第 2 項が**整数占有の自己項補正** (⟨n²⟩=⟨n⟩)。角度因子 D_k = Σ_m[3j(j k j;−m,0,m)]²
= **1/(2k+1)** は整数・半整数を問わず成立。**この 1 項で 1 電子の完全相殺・閉殻の
補正ゼロ・開殻の漸近 −1/r が同時に正しくなる。スピン分極は不要**。

**jj の係数を κ について足すと LS の係数に厳密に戻る** (3.6e-15、T19a) — これが
c→∞ の退化を保証する。⚠ **開殻では jj と LS の平均配置が原理的に一致しない**
(DF-AOC と HF-AOC の既知の差) ので、c→∞ の退化テストは**閉殻元素で行う**。

⚠ `33c689b` のコミットメッセージに「球平均した開殻では −1/r は原理的に回復できない」
と書いたが**これは誤り**。`e722f3b` で訂正済み。

### 6.3 危険な落とし穴 (実際に踏んだ)

- **u_x の 1/2**: δE/δP_a = 2q_aε_aP_a なので u_x P_a = (1/(2q_a))δE_x/δP_a。
  落とすと Slater ポテンシャルと 2 倍食い違う。恒等式 **Σ_a q_a ū_a = 2E_x** で固定
  (T16 / T19c)
- **u_x 自体を作らない**: P_a の節で 0/0。常に **P_a² u_x** の形で扱う
- **遠方の 0/0**: `solve_bound` / `_dirac_gf` は WKB で減衰しきった先の軌道を**厳密に 0**
  にするので、そこで V_x の分子も分母も 0 になる。`tail_guard!` が ρ̃ < 1e-120 で
  厳密な漸近 −1/r に落とす。**H 様 Z≥2 で実際に踏んだ**
- **散乱に KLI の V_eff を使わない**: 中性標的の静的場は遠方で 0 に落ちねばならないが、
  KLI の V_eff は −1/r の尾を持つ。KS ポテンシャルとして正しく、飛来電子の場としては誤り。
  `V_bound_callable(...; local_exchange=true)` で局所形に組み直す (`phase` 出口)
- **κ 分裂した HOMO の定数オフセット** (Dirac KLI、2–3e-4 Ha)。相方が格子端まで密度の
  29% を占め Δ≠0 が残る。**取り除いていない** — 束縛問題では V の定数は波動関数を
  変えないので密度由来の出荷量に効かない。T19c で上から抑えてある
- **交換係数の二重計上**: `slater_vx` に α を畳み込むと終状態の KS(2/3) が (2/3)α に
  なる。**`slater_vx` は素の Slater 形**、α は SCF 側、2/3 は終状態側で掛ける (T13b)
- **キャッシュキーの取り違え**: §2「忘れずに」参照

### 6.4 参照との比較の測り方 (実際に間違えた)

- **f_x は OFFV1 (DHF の計算値) と比べる。**公開パラメータ化 (WK/CM/Peng/Kirkland) は
  全てフィットで自身の残差を持つ (WK の平均絶対誤差は現代手法の ~50 倍 — Thorkildsen 2023)
- **RMS 相対差を全域で取らない。**高 s では参照の Gauss 展開が尽きて発散する
  (Peng は s=6 で Kirkland と 60% 以上ずれる)。指標は **s≤2 の RMS|Δf| と相対 RMS、
  および全域の max|Δf|**
- 高 s まで見るなら **Kirkland** (3 Lorentzian + 3 Gaussian で 1/q² 裾が正しい)
