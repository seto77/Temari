# F(s) の誤差は観測量へどう伝播するか (2026-08-13)

*Temari で測った F の誤差を、ReciPro の ALCHEMI 経路へ通して観測量の変化を実測した記録。
指示書 `next_phase_2026-08-13.md` が「**この測定の外**、ReciPro 側で測る別の仕事」と
繰り返し書いていた項目 (codex が V1 より優先と判断した (B))。*

---

## 0. 三行で

1. **観測量は s < 2 Å⁻¹ しか感じない**。s > 4 Å⁻¹ の摂動は 1e-09 以下、
   s > 10 Å⁻¹ は数値ゼロ
2. **E0 補間誤差の最悪 3.002e-03 は s = 6.65〜11.6 Å⁻¹ にある** = 感度がほぼ無い帯。
   **感じる帯 (s ≤ 2) に限った実測は 8.472e-05** で、観測量への影響は **≤ 1.2e-04**
3. ⚠ **「サイト比なら共通誤差が打ち消える」はほぼ成り立たない** (打ち消し 1.1–1.2 倍だけ)。
   しかも生の収量では δF を **1.67 倍に増幅**する

## 1. なぜこの測り方が厳密なのか

**F は μ_hg を通してしか入らない**:

    μ_hg = Σ_a Occ_a · e^{−M_a(G)} · σ_a · F_a(|G|/2) · e^{−2πi G·r_a}

そして **Bloch 係数・固有値・幾何は F に依らない**。したがって同じ `AlchemiRequest` で
**形状だけ**差し替えて 2 回走らせると、差は δF の寄与**だけ**になる。近似ではなく、
同じ Bloch 解の上での厳密な差分。

道具 = `ReciPro/tools/AlchemiCheck` の **`sens` サブコマンド** (新規)。
差し替え口は `AlchemiRequest.ChannelDataOverride` (新規、**既定 null**)。

⚠ **既定 null では 1 ビットも挙動が変わらない** — `UseNativeSolver` (backend 一致検証用) と
同じ位置づけの診断専用プロパティ。⚠ **長さが合わなければ例外**にしてある
(片方だけ黙って差し替わる事故を防ぐ)。

⚠ **F(0)=1 は契約なので摂動しない**。s>0 だけを動かす — F(0) を動かすと μ の対角
(= σ) が動き、それは F の誤差ではなく σ の誤差になる。

### 自己検査 (負のテスト)

| | 実測 |
|---|---|
| δF ≡ 0 の差し替えで `Total` が一致するか | **max rel = 0.00e+00** (厳密) |
| δ を 2 倍にすると δY も 2 倍か (線形性) | **max\|比−2\| = 2.90e-09** |

⚠ 線形性の残差 2.9e-09 の**出所は未調査**。δF≡0 が厳密に 0 だったので run 間の
非決定性ではない。ここで論じるどの効果よりも 6 桁小さいので、ゲートは 1e-6 に置いた。

## 2. 配置

**β-AlCo (B2, a = 0.2861 nm)** — 設計 §6.1-4 の v1 主検証系
(Oxley, Allen & Rossouw, Ultramicroscopy 80, 109 (1999))。Al を原点・Co を体心に置くので
**h00 系統反射列の定在波に対して 2 副格子がちょうど腹と節に来る** =
ALCHEMI が最も素直に効く配置。

E0 = 200 keV / x 軸まわり 17.3° 傾斜で h00 系統反射列 / ±2.2 θ_B × 21 点 /
厚み 20, 50, 100 nm / サイト = Al, Co / チャネル = Al-K (u = 129), Co-K (u = 26)。

## 3. 伝達係数

### 3.1 一様な相対摂動 F → F(1+ε)

| ε | max\|ΔY\|/Y | max\|Δ(Al/Co)\|/(Al/Co) | 打ち消し比 |
|---:|---:|---:|---:|
| 1e-03 | 1.672e-03 | 1.343e-03 | 1.2 |
| 1e-02 | 1.672e-02 | 1.364e-02 | 1.2 |
| 5e-02 | 8.359e-02 | 7.317e-02 | 1.1 |

⚠⚠ **「サイト比を取れば共通誤差が消える」は成り立たない。**打ち消しは **1.1–1.2 倍だけ**。
理由は、Al と Co が**異なる s を異なる位相でサンプルし**、Al-K と Co-K の F(s) も違うから。
サイトに共通な**相対**摂動でも、比においては共通モードにならない。

⚠ **生の収量では増幅する** — ΔY/Y ≈ **1.67 ε**。δF が観測量で薄まるという直感は誤り。

### 3.2 一様な絶対摂動 F → F + δ

Temari の実測は**絶対値** (F(0)=1 基準) なので、対応するのはこちら。

| δ | max\|ΔY\|/Y | max\|Δ(Al/Co)\| | 出所 |
|---:|---:|---:|---|
| 3.0e-03 | 5.277e-03 | 4.257e-03 | E0 補間の実測最悪 (全 s) |
| 2.0e-02 | 3.518e-02 | 2.926e-02 | 尾根帯 下限 |
| 5.0e-02 | 8.795e-02 | 7.738e-02 | 尾根帯 上限 |

⇒ **伝達係数は 1.76 (生の収量) / 1.42 (サイト比)**。

⚠ **これは「δ が全 s に一様に乗った場合」の理想化**で、上界としてしか使えない。
実際の δF は s に強く局在する — それが次節。

## 4. ★★ s 帯の分解 — ここが決定的だった

δ = 3.0e-03 を **1 つの s 帯にだけ**載せる:

| s 帯 [Å⁻¹] | max\|ΔY\|/Y | max\|Δ(Al/Co)\| |
|---|---:|---:|
| [0.0, 0.5) | **4.099e-03** | **2.992e-03** |
| [0.5, 1.0) | 1.282e-03 | 1.127e-03 |
| [1.0, 2.0) | 1.741e-04 | 1.809e-04 |
| [2.0, 4.0) | 1.062e-05 | 9.131e-06 |
| [4.0, 6.0) | 1.544e-09 | 1.480e-09 |
| [6.0, 10.0) | 9.979e-16 | 9.992e-16 |
| [10.0, ∞) | **0.000e+00** | **0.000e+00** |

**⇒ 観測量が感じるのは s < 2 Å⁻¹ だけ**。s = 2–4 で既に 3 桁落ち、4–6 で 6 桁、
6 以上は数値ゼロ。

### 基底に依るのではないことの確認

`MaxNumOfBloch` を 120 (基底 263 本) → 400 にしても profile は動かない
(s<0.5 で 4.099e-03 → 4.155e-03、s 2–4 で 1.062e-05 → 9.752e-06 = 1.5 % 以内)。
⚠ 大きい基底では [10, ∞) が 0 ではなく **5.4e-12** になる — 基底が s>10 Å⁻¹ へ届くため。
だが値は無視できる。

⚠ **これはこの結晶・この方位での測定**。要求 s の上限そのものは
`docs/basis_s_requirement_2026-08-10.md` が別に測っており、N=1600 で 10.54 Å⁻¹。
**届く s と、効く s は違う** — ここで測ったのは後者。

## 5. ⇒ 実測 δF を当てる

### 5.1 E0 補間誤差 (P1b) — **観測量にはほぼ効かない**

指示書 §2 P1b の直接測定の最悪 **3.002e-03 は s = 6.65 Å⁻¹** (Po L1)、
危険域の他のチャネルも **s = 10.5〜11.6 Å⁻¹** に集中していた。
⇒ **どれも感度がほぼ無い帯にある。**

そこで probe に「**s ≤ 2 Å⁻¹ に限った最悪**」を足して測り直した (50 チャネル・450 点):

| 層 | 全 s の最大 | **s ≤ 2 の最大** |
|---|---:|---:|
| risk (u_min<2 の全数、n=25) | 3.002e-03 | **3.292e-05** |
| shell (n=9) | 8.472e-05 | 8.472e-05 |
| c6b (n=8) | 1.522e-03 | 1.890e-05 |
| ctrl (n=8) | 8.563e-05 | 3.295e-05 |
| **全体** | **3.002e-03** | **8.472e-05** (35 倍小さい) |

⇒ 伝達係数 1.42 を掛けて **サイト比への影響 ≤ 1.2e-04**、生の収量で ≤ 1.5e-04。

★ **危険域 (閾値直上) の s≤2 誤差はむしろ小さい** (3.29e-05) — 全 s の最悪
3.002e-03 の 1/91。閾値近傍で大きくなるのは**高 s の側**だった。

### 5.2 尾根帯の δF (§2 P3) — **上界しか言えない**

指示書 §2 P3 の「もし全部我々の誤差なら max\|δF\| ≈ 2–5×10⁻²」を当てると、
一様に s<2 Å⁻¹ に乗った最悪の場合で **サイト比 2.9e-02 〜 7.7e-02**。

⚠⚠ **これは上界であって測定ではない** — 理由:

- **δF(s) の s 依存が分解されていない** — `rho_weight_probe.jl` が出したのは
  「s ごとの δF の最大」であって、s 分布ではない
- **尾根帯 (ρ≈1、q ≈ 13–23 a.u.) は内部の求積変数**であって外部の s ではない。
  F(s) は各 s で ρ 分布全体を積分するので、**尾根帯の誤差は全 s に効きうる**
- ⇒ 「尾根帯の誤差は s = 2–3.5 Å⁻¹ に対応する」と**読み替えてはいけない**

**この上界を狭めるには δF(s) を s 分解して測り直す必要がある** (未実施)。

## 6. ⚠ 主張してはならないこと

- ❌ **「F の誤差は観測量では薄まる」** — 生の収量では **1.67 倍に増幅**する
- ❌ **「サイト比を取れば共通誤差は消える」** — 打ち消しは **1.1–1.2 倍だけ**
- ❌ **「E0 補間誤差は 3.0e-03 だから観測量も 3e-03 級」** — その誤差は
  **感度の無い s 帯にある**。感じる帯での実測は 8.47e-05
- ❌ **「尾根帯の δF は観測量に 2.9–7.7 % 効く」** — **上界**であって測定ではない。
  δF(s) の s 依存が分解されていない
- ❌ **「s > 4 Å⁻¹ は観測量に不要」** — 測ったのは **β-AlCo のこの方位**だけ。
  結晶・方位・厚みを変えれば効く s は動く。⚠ **s ≤ 16 の収録をやめる根拠にはならない**
- ❌ **「1e-04 なら無視してよい」** — 何と比べて無視できるかは実験側の話
  (計数統計・試料・検出器)。**ここで測ったのは伝播だけ**
