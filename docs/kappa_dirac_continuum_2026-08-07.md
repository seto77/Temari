## 1. 何を実装したか

Zhang ら 2024 の式 40–41:

    R^λ_{κκ′}(q) = ∫ [G_nκ(r) G_Eκ′(r) + F_nκ(r) F_Eκ′(r)] j_λ(qr) dr
    S = occ Σ_κ′ Σ_λ (2l+1)(2l′+1)(2j′+1)(2λ+1)
                     [3j(l′ λ l;000)]² {6j(j λ j′; l′ ½ l)}² |R^λ|²

変更点は 3 つ:

| | 出荷 (SRC) | KD |
|---|---|---|
| 連続状態 | スカラー相対論 (κ 依存部を落とした 1 成分) | **連立動径 Dirac を κ ごとに** |
| 行列要素 | 大成分のみ | **G_aG_b + F_aF_b** |
| 始状態の規格化 | 大成分のみ ∫G²=1 | **2 成分 ∫(G²+F²)=1** |

部分波は l ごとに κ = −(l+1) (j=l+½) と κ = +l (j=l−½) の 2 本になる。

### 1.1 下流を 1 行も変えない作り

Dirac 版の R テーブルは**通常の `RlTable` を返す**。仕掛けは 2 つ:

* 被積分関数を先に畳む — `gw[ic,i] = w_i (G_bG_c + F_bF_c)` を κ′ ごとに
  作ってしまえば、あとは非相対論版と同じ Σ_i gw·j_λ(Qr_i) の形になる
* チャネルの重み A に Dirac の角度因子を入れる。`channels` の第 1 要素は l′ の
  ままなので、有意性フィルタも `zero_l!` もそのまま効く (同じ l′ を 2 本の κ′ が
  共有し、別チャネルとして並ぶだけ)

おかげで `legendre_sum` 以降 (角度積分・N(K) 縮約・GOS 組み立て・EELS 出口) は
**まったく手を入れていない**。

## 3. 実装中に踏んだ落とし穴 (3 つとも実際に踏んだ)

### 3.1 角度因子の (2l′+1) 落とし

Zhang の [l, l′, j′, λ] は (2l+1)(2l′+1)(2j′+1)(2λ+1)。(2l′+1) を落としても
6j の直交性は 1 を返すので**単体では気付けない** — 非相対論への退化を
突き合わせて初めて 1/(2l′+1) だけずれていることが分かる。

### 3.2 原点の種を「F/G = c(γ+κ)/Z」で固定してはいけない

これは点核 Dirac の指標方程式の解で、**r ≪ Z/(2c²) でしか成り立たない**。
高 l では種の位置がその外に出るので、κ > 0 で F を 2 桁以上過大に置くことになる。
c→∞ でも発散する。正しくは第 1 式そのものから

    F = (s + κ) G / [ r (2c + (ε − V(r))/c) ]

を使う。分母が Z/(cr) に支配される領域では自動的に c(s+κ)/Z に戻り、
外では自由粒子の (s+κ)/(2cr) に落ちる。1 本で両方の領域を跨げる。

### 3.3 RK4 は同じ格子で Numerov より 6–73 倍粗い

Numerov は y″ = Wy 専用で誤差定数が桁違いに小さく、連立 1 階系には使えない。
素の RK4 だと c→∞ の退化残差 (1.1e-3) が物理効果 (2.6e-3) と同程度になり、
**構造検査として成立しない**。

対処は「**格子は変えず、区間内で RK4 を n_sub 分割する**」。r_int も Simpson
重みも非相対論版と同一のまま、誤差だけ 1/n_sub⁴ に落ちる。n_sub = 4 で
自由粒子の誤差が 6.3e-4 → 3.1e-7 (Numerov の 8.6e-6 より 28 倍良い)、
c→∞ 残差は 2.2e-5 になった。

### 3.4 ⚠ c→∞ の検査を作るときの罠 (コードのバグではない)

実チャネルで c→∞ を見るとき、**小成分を 0 に潰すだけでは駄目**で、
大成分を ∫G² = 1 に**再規格化しなければならない**。Gram–Schmidt は
「束縛の 2 成分ノルムが 1」を前提に c·(G_b,F_b) を引くので、ノルムが
1−frac_small のままだと偽の単極子が c·frac_small だけ残り、**小 q で 1/q² の
発散**になる。Au L2 で比が 1.76 まで膨らんで一度これに騙された
(重なり c = 6.1e-3 が 4 チャネル中最大で、破綻の順序と一致する)。

## 4. 残っている系統ずれ

KD 後も全チャネルが 0.94–0.98 に揃って**低い**。共通要因の候補:

- **端エネルギーの定義差** — 我々は Bote 表、先方は計算値。GOS の前因子 2ΔE に
  そのまま乗るので +1.8 % (Fe K)。**我々が低いので、この差は不一致を隠している** —
  補正するとさらに 1.8 % 下がる
- **終状態の処方** — `:frozen` にすると Fe K は上がるが Au は下がる
  (`frozen_core_and_transverse_2026-08-07.md` §2.2)
- **連続状態の交換** — 我々は KS(2/3) の局所交換、先方は FAC の自己相互作用
  補正つき局所密度近似

## 5. 使い方とコスト

```powershell
julia +1.11 -t 4 src/ionization.jl 79 L3 300 --kdirac        # F(s)
julia +1.11 -t 4 src/ionization.jl gos 79 L3 --kdirac        # GOS
julia +1.11 -t 4 src/ionization.jl edge 79 L3 300 --kdirac   # EELS
```

`--rel` (SRC) とは**排他** (上位互換なので両立させると処方が曖昧になる)。
model_id の基底が `...-KDIRAC2C-...-v3k` に替わる。

コストは Au L3 @300 keV の QUICK で 4 s → 5 s。部分波が約 2 倍、RK4 が
Numerov より重く、さらに 4 分割するので**原理的には 10–30 倍**だが、
連続状態は全体の一部なので実効は小さい。本番求積での実測は未取得。

⚠ **出荷既定は SRC のまま。**差し替えはテーブル全再生成とセットで、作者判断。
