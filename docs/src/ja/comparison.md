# 文献との比較

[Verification](verification.md) のページは、出荷テーブルが公表された参照からどれだけ
離れているかを**数値で**述べている。このページは同じ比較を**曲線として**見せる —
代表元素として **Si と Fe** の 2 つに絞り、一致の「形」が見えるようにした:
どこで重なり、どこで離れ始め、どのくらいの速さで離れるか。

どの図も描いているのは**比か相対偏差**であって、参照値そのものではない。
公表された数表・フィット係数・GPL コードの出力は、いかなる形でもこのリポジトリに
入っていない ([CONTRIBUTING](https://github.com/seto77/Temari/blob/main/CONTRIBUTING.md)
参照)。乖離の図は比較の性質を伝えるが、他人の仕事を再公表することにはならない。
ここにある図はすべて 1 本のスクリプト `tools/make_comparison_figures.py` が、
出荷テーブルと手元に置いた参照の複製から生成している。

!!! note "パネルの読み方"
    横軸は常に $s = \sin\theta/\lambda$ [Å⁻¹]。縦軸は参照に対するパーセントで、
    ゼロの破線が**参照そのもの**。曲線が枠から出るところでは (上端に張り付けずに)
    線を切り、どこへ行ったかをラベルに書いた。相対偏差は、因子自体が小さくなる
    大 $s$ で小さな絶対残差を拡大して見せる — それが問題になる箇所では本文に
    絶対値を添えた。

## 1. X 線散乱因子 f_x(s)

**dataset-factors v1.0.0** (Dirac SCF + KLI 形式の厳密交換) を、Olukayode,
Froese Fischer & Volkov (2023) の数値 Dirac–Hartree–Fock 表 **OFFV1** — フィット
ではなく*計算された*参照 — と、誰もが使う 2 つの解析パラメータ化に突き合わせた:
Waasmaier–Kirfel (5 Gauss + 定数、$s \le 6$ Å⁻¹ でフィット) と、*International
Tables* 収録の Cromer–Mann (4 Gauss + 定数、$s \le 2$ Å⁻¹ でフィット)。4 者とも
OFFV1 自身の 62 点格子上で評価している — 参照は内挿せず、出荷テーブル側をその節点で
契約どおりのスプライン (7681 節点。内挿誤差はここで見える差より桁違いに小さい) で読む。

![Si と Fe の f_x: Temari / Waasmaier–Kirfel / Cromer–Mann の DHF からの相対偏差](../assets/figures/fx_vs_literature.svg)

図が示すこと:

- **$s \approx 2$ Å⁻¹ より下では、どの曲線も DHF と 1 % を切って一致する。**
  Temari は 0–6 Å⁻¹ の*全域*で DHF から 0.26 % (Si)・0.17 % (Fe) 以内 —
  絶対値で最大 0.011 e (Si)・0.023 e (Fe) — に留まる。同じ物理 (Dirac、交換のみ、
  相関なし) の計算であって、それへのフィットではないからである。
- **Cromer–Mann はフィット範囲の $s = 2$ Å⁻¹ を過ぎると枠から出る**: Si で
  $s = 3$ において +32 %、$s = 6$ で +415 %、Fe で −9 % と +28 %。「小 $s$ で一致し、
  大 $s$ で離れる」古典的な形だが、これはパラメータ化の性質であって、フィット元の
  Hartree–Fock 原子の性質ではない。
- **Waasmaier–Kirfel は $s = 6$ まで持つ**が、$s < 2$ で最大 0.24 % (Si) / 0.49 % (Fe)
  振れ、遠端では 2.2 % (Si) まで振れる。この 2.2 % は 0.005 e — フィットの絶対残差 —
  で、$f_x$ が 0.22 e まで落ちたところでの値である。

Verification ページの RMS 表 (Si / Fe で $s \le 2$ の 0.087 % / 0.079 %) は、
青い曲線の要約統計量である。

## 2. 電子散乱因子 f_e(s)

同じデータセット、同じ参照。DHF に別建ての $f_e$ 表は無いので、参照は OFFV1 から
Mott–Bethe 関係式 $f_e = (Z - f_x)/(8\pi^2 a_0 s^2)$ — 出荷 $f_e$ と同じ第一 Born・
γ 無しの規約 — で導き、OFFV1 の最初の節点 $s = 0.01$ から描いた。文献側の曲線は
Kirkland の 3 Lorentz + 3 Gauss フィット (*Advanced Computing in Electron
Microscopy*、Lorentz 型の裾を持ち $s \le 6$ Å⁻¹ でフィット) と、*International
Tables* 収録の Peng ら (1996) (5 Gauss、$s \le 2$ Å⁻¹ でフィット)。

![Si と Fe の f_e: Temari / Kirkland / Peng の DHF (Mott–Bethe 経由) からの相対偏差](../assets/figures/fe_vs_literature.svg)

図が示すこと:

- **Peng はフィット範囲の $s = 2$ Å⁻¹ を過ぎると枠から出て**、そのまま潰れる:
  $s = 3$ で −55 % (Si) / −47 % (Fe)、$s = 6$ では実質 −100 %。真の $f_e$ が
  $s^{-2}$ (Rutherford) でしか落ちないところで、Gauss 関数は指数的に死ぬ。
  *International Tables* が $2 < s \le 6$ 用の第 2 の Peng 係数を別に載せているのは
  このためで、多くのソフトが同梱しているのは第 1 の組である。
- **Kirkland は $s \approx 0.2$ Å⁻¹ から遠端まで DHF を約 0.1 % 以内で追う**。
  Lorentz 型の裾が正しい $s^{-2}$ 漸近を持つからで、逸脱は Si の $s \to 0$ (+0.7 %)
  の 1 箇所だけ。
- **Temari は $s \approx 0.3$ Å⁻¹ 以上で DHF と 0.25 %、$s \approx 0.5$ 以上で
  0.1 % で一致するが、$s \to 0$ では下にずれる: $s = 0.01$ で −0.65 % (Si)・
  −2.0 % (Fe)**。これは $f_x$ の比較では
  分解できず $f_e$ の比較でだけ見える唯一の箇所である。$s = 0$ 近傍の $f_e$ は
  欠損 $Z - f_x$ で決まり、それは密度の動径 2 次モーメント ($f_e(0) = a_0 M_2/3$。
  最外殻が支配する) が決める小さな数なので、そこでの 2 % の差は $f_x$ では 0.03 % の
  差にしかならず、パネル 1 では見えない。出所は次項で同定する。

### s → 0 の不足はどこから来るか

同じ量を全元素で掃く — $s = 0.02$ Å⁻¹ での Temari の $f_e$ / DHF の $f_e$。これは
共通の $s^2$ 項を除けば $\langle r^2 \rangle$ の比そのものである — と、ばらつきではなく
パターンが出る:

![Z = 2–86 での s = 0.02 における f_e / f_e^DHF − 1 と、Krieger, Li & Iafrate (1992) の ⟨r²⟩ KLI/HF 比の重ね描き](../assets/figures/fe0_vs_Z.svg)

- **希ガスはすべてゼロに乗る** (He, Ne, Ar, Kr, Xe, Rn: −0.07 … +0.13 %)。
  Pd (4d¹⁰、5s 無し: +0.3 %) も同様。
- **凹みは d ブロック**: 3d・4d 列は −1.7 … −2.1 % (Sc–Ni、Zr–Rh。Y は −1.4 %、
  Tc は −1.7 %)、5d 列は −0.9 … −1.5 % (Hf–Hg)、そして半充填または充填した 3d 殻の
  上に 4s 電子が 1 個だけ乗る Cr (−3.9 %)・Cu (−3.4 %) で最深。主族は周期ごとに
  ゼロへ戻り、ランタノイドは −1.2 … −1.8 % に居る。
- **白抜きの菱形は Temari の数値ではない**。KLI 近似を導入した論文 Krieger, Li &
  Iafrate (1992) 自身の Table III から読んだ比
  $\langle r^2 \rangle_{\rm KLI}/\langle r^2 \rangle_{\rm HF} - 1$ で、彼らが表にした
  閉殻 10 原子分。**Be, Ne, Mg, Ar, Ca, Zn, Kr, Sr, Cd, Xe のすべてで、塗り潰しの点に
  0.07 ポイント以内で重なる** — Zn の −1.8 % (0.07 の当該例)、Cd の −1.3 % も含めて。
  Temari の非相対論 KLI はこれらの原子で論文の KLI 列を印字 4 桁で再現する (selftest
  T20 が Ne と Ar をゲート、Mg・Ca・Zn・Sr・Cd も同じ方法で確認済) ので、この一致は
  「近似とその参照」の一致であって、2 つの誤差の偶然ではない。

よって容疑は同定された: **不足は KLI 近似そのものを追っている**。閉殻 10 原子については
直接の一致で、KLI 対 HF の $\langle r^2 \rangle$ が公表されていない開殻の d 元素については
同じパターンからの推論である (有限 $s$ での Dirac+KLI 対 DHF の比較を、非相対論の
KLI 対 HF の比較と並べている — 相対論と $s^2$ の寄与は、両方が揃う原子では 0.07 ポイントの
水準まで相殺していると見える)。同じ表で厳密交換ポテンシャル (OEP) は 10 原子すべて —
Zn を含めて — で Hartree–Fock と 0.1 % 以内に一致しているので、欠けているのは KLI が
OEP から落とす項 (軌道シフト項) である。それが拡がった $n$s 電子を緻密な $(n-1)$d 殻の
上で僅かに強く束縛しすぎる、というのは Zn/Cd/Cr/Cu のパターンの自然な読みであって、
ここで別途証明したものではない。出荷テーブルへの帰結は有界で局所的: $f_x$ は d ブロック
全元素で DHF から 0.22 % 以内 (Sc 0.21 %、Cr 0.17 %、Fe 0.17 %、Cu 0.15 %、Au 0.07 %。
最悪点は $s$ = 0.3–0.7 Å⁻¹ で、そこでは欠損が $Z$ の小さな割合しかない)、$f_e$ は
$s \ge 0.4$ Å⁻¹ で d ブロック 0.16 % 以内・$s \ge 0.5$ で全元素 0.14 % 以内、$f_e$ の
$s \to 0$ が d ブロックで最大 2 %、Cr と Cu で 4 % 低い。遷移金属の $f_e(0)$ や
平均内部ポテンシャルを使う人は知っておくべきで、通常の $s$ での構造因子を使う人には
見えない。

## 3. 内殻イオン化形状因子 F(s)

**dataset v5.0.0** (κ 分解 Dirac 連続状態、緩和 core-hole 終状態) を、この量に
存在する 2 つの参照 — Oxley & Allen (2000) の表と、µSTEM に同梱される形状因子 —
に突き合わせた。両参照は Hartree–Slater 原子ポテンシャルと、放出電子の 1 成分
(Schrödinger) 連続波を共有している。比べるのは $E_0 = 200$ keV での**正規化形状**
$F(s)/F(0)$ で、参照の格子点上で取る (Temari の 0.05 Å⁻¹ 表をそこへ内挿し、参照は
内挿しない)。Oxley & Allen の L 表は L 殻全体なので、第 3 パネルでは出荷の
L₁・L₂・L₃ 行を $N_0$ 重みで合成し、µSTEM 側は別々の 2s と 2p を足した — *同じ*
Temari 合成形状を各参照で割るので、2 種の記号どうしも比べられる (副産物の検査:
Temari の $N_0(\mathrm{L_1}) / [N_0(\mathrm{L_2}) + N_0(\mathrm{L_3})]$ は 0.187、
µSTEM の $F_{2s}(0)/F_{2p}(0)$ は 0.189)。

![Si K・Fe K・Fe L 殻の F(s)/F(0) (200 keV): µSTEM および Oxley–Allen との比 − 1](../assets/figures/F_vs_literature.svg)

図が示すこと:

- **1 % 以内の一致は、Si K で $s \approx 0.75$ Å⁻¹ まで、Fe K で ≈ 2.5 まで、
  Fe L 殻で ≈ 0.3 まで (µSTEM に対して)**。それを過ぎると Temari の形状は両参照より
  **速く**、単調に落ちる: Si K は $s = 5$ で −22 %、Fe K は −8 %、Fe L 殻は $s = 2$
  で −7 %。100・300 keV でも絵は同じ (Si K の曲線は 3 電圧とも $s = 0.5$–0.75 の間で
  −1 % を横切る)。軽い元素ほど・浅い殻ほど離れ始めが早い — ここでは Fe K が最良の例
  であって、典型ではない。(位置関係の参考: Si K の $s = 1$ で、引退した v3 表
  (スカラー相対論連続状態) は µSTEM に対して −2.6 %、それより古い非相対論の v2 は
  −1.5 %、v5 は −1.7 % — κ 分解 Dirac 連続状態は形状を非相対論の結果から 0.2 ポイント
  以内へ戻した。真の相対論効果が小さいのだから、そうなるのが正しい。)
- **2 つの参照どうしも食い違う**。L 殻で顕著で、分子を同じ Temari 合成形状にすると
  $s = 1.25$ で Oxley–Allen の L 殻全体は −14 %、µSTEM の 2s + 2p は約 −5 % —
  つまりそこで Oxley–Allen は µSTEM より 11 % ほど上にある ($s = 0.625$ では
  1.6 %)。K では両参照は $s = 2.5$ まで 1.5 % (Si)・0.1 % (Fe) で互いに一致する。
- **L 殻の比は $s = 2$ で終わる**。$F$ が $s \approx 2.7$ Å⁻¹ 付近で符号を変える
  (出荷の $F$ は符号付き — [Data](data.md) 参照) ので、ゼロを跨ぐ比には情報が無い。

大 $s$ でどちらが真値に近いかは、この図では決まらない — $F(s)$ をその水準で分解
できる実験は無い。分かっているのは、それがどれだけ効くかである:
[伝播の測定](https://github.com/seto77/Temari/blob/main/docs/observable_propagation_2026-08-13.md)
によれば、STEM-EDX/ALCHEMI の観測量が感じるのは $s < 2$ Å⁻¹ だけで、$s > 4$ の寄与は
(試した 1 結晶 1 方位について) 10⁻⁹ の水準だった。曲線が離れる領域は、それらの観測量
にとっては効かない領域であり、効く領域は一致している領域である。

## 図の再生成

```bash
python tools/make_comparison_figures.py              # Si と Fe、E0 = 200 keV
python tools/make_comparison_figures.py --z 14,26,79 # 列を増やす
python tools/make_comparison_figures.py --e0 300     # F(s) の E0 を変える
```

スクリプトは参照がローカルディスクにあることを前提にする (リポジトリには無い —
何をどこに置くかは `refs/README.md` の索引にある)。書き出すのは比と偏差だけで、
出力先は `docs/src/assets/figures/`。端末にも同じ偏差を印字するが、参照値は決して
印字しない。SVG が運んでいるのは比そのもの (分解能はおよそ 10⁻⁴ パーセント点) —
つまり導出された比較の図であり、それが CONTRIBUTING の引いた線である: 乖離と比は
公開してよく、転記した値は駄目。
