**端区間集中の機構**: not-a-knot は最初の 2 区間を単一の 3 次で覆う。
f_x(s) は K の偶関数で低 s では N − c₂s² + c₄s⁴ だが、3 次には s⁴ を吸収する

(M₄ 大 = アルカリ・アルカリ土類・軽ランタノイド) で大きい。誤差プロファイルは
端の 1–2 中点だけ内部の約 10 倍のスパイクになる (Au 実測: 1.42e-09 →
−5.7e-10 → −3.2e-11 → 以後 −1.4e-10 前後で滑らか)。

| 規約 | 最悪 | 超過元素 |

| not-a-knot (現行 §4.9) | Cs 1.111e-08 = **1.222×B_repr** | 2 (Cs・Ba) |
| **左端 clamped + 右端 NAK** | Cs 1.119e-09 = **0.123×B_repr** | **0** |
| 同 + 有効数字 11 桁丸め合成 | Cs 1.481e-09 = **0.163×B_repr** | **0** |

- ⚠ これは §4.9 の「not-a-knot」決定の再議になるので**作者判断**。

## 3. f_e (経路 D) — 検査可能域で 84/84 合格。⚠ 低 s に検査不能域がある

### 3.1 ⚠⚠ 素朴な全中点判定は床を測ってしまう (最初の試走で発見)

全中点で max を取ると Au 1.24e-07 Å = 13.6×B_repr,e と出るが、**これは補間誤差
ではない**。差を f_x 相当に引き戻す (×K²/2a₀) と ±1e-12 電子級で符号ランダム —
**検証値 (Mott–Bethe 構成) が f_x の求積丸め床 ε を 2a₀/K² 倍に増幅して持つ**
ためで、`certify_fe.jl` §4.23.6 が水準差で踏んだのと同型の床である
([[signal-below-tolerance]])。

⇒ 判定は**検査可能域**で行う: 元素ごとに ε̂ を実測し (最低 8 中点の引き戻しの
中央値。certify_fe の eps_est と同じ流儀)、床 2a₀ε̂/K² が予算の 1/10 以下になる
**s ≥ s_ok = √(20a₀ε̂/B_repr,e)/(4πa₀)** を検査し、下は検査不能として別掲する
(不合格と別分類、[[fixed-threshold-assumes-sn]])。閾値は床の定義から決まり、
合否を見て動かしてはいない。ε̂ の窓依存 (8 点 vs 16 点) は 0.14–1.30 倍。

### 3.2 結果

| 量 | 値 |
|---|---|
| 最悪 (検査可能域) | **Z=30 Zn 3.009e-09 Å = 0.331×B_repr,e** ✅ |
| 次点 | Z=21 Sc 0.244 / Z=6 C 0.240 |
| 合格 | **84 / 84** |
| ε̂ (f_x の丸め床) | 中央 8.68e-13 / 最大 3.26e-12 電子 (Z=79) |
| s_ok | 中央 0.0048 / 最大 0.0093 Å⁻¹ (Z=79) |
| 検査不能中点 | 元素あたり 1–12 点、全体 503 / 645,120 (0.078 %) |

- ε̂ は v1 の certify_fe 実測 (水準差の床、中央 4.21e-13 / 最大 1.73e-12) の
  約 2 倍 — スプライン差はスプライン係数による増幅を含むためで、整合的
- **検査不能域の真の補間誤差は構造的に極小**: t = s² 上では区間幅が
  h_t(i) = (2i−1)Δ² で、最初の区間は 6.1e-07 と検査可能域直上 (s~0.01、
  h_t ~1.7e-05) の 1/27。同じ f_e⁗(t) なら誤差は (1/27)⁴ ≈ 2e-06 倍 —
  実測 6e-10 Å 級から外挿して 1e-15 Å 級で、床のはるか下。f_e(t) は t=0 で
  解析的 (級数 a₀[M₂/3 − λtM₄/60 + …]) なので f⁗ の発散も無い
- f_e スプラインの端条件は変更不要 (t 上の傾き −a₀λM₄/60 ≠ 0 なので
  clamped にする理由も無い)

### 3.3 ⚠⚠ 発見 — 出荷の f_e 節点値を Mott–Bethe で構成すると床が予算を食う

検査不能域の床は測定だけの問題ではない。**出荷表の f_e 節点値そのものを
f_e = 2a₀(Z−f_x)/K² で作る限り、低 s 節点は同じ丸めゆらぎを持つ**。
最小非零節点 s₁ = 7.8125e-04 での 2a₀ε̂/K₁² (= fluct_ship):

| 量 | 値 |
|---|---|
| 最悪 | **Z=79 Au 1.28e-07 Å = 1.41×B_num,e** |
| B_num,e = 9.09e-08 Å 超過 | **6 元素** (Au 79 / At 85 / Lu 71 / Po 84 / Tl 81 / Hf 72) |
| 0.5×B_num,e 超過 | 29 元素 |

これは格子誤差 (実測最悪 3.82e-08) とも停止誤差 (2.64e-08) とも独立に足される
第 3 の項で、**素朴な MB 構成では T_comp,e = 1e-7 Å (案 A) が成立しない**。
§4.23.6 の「値の側では桁落ちは無害 (最小節点 4e-09 Å)」は Z=6 の ε ≈ 1e-13 の
話であり、**また 1 元素からの外挿だった** — 重元素の ε は 1 桁大きい。

### 3.4 ★ 対処の実測 — δ 形求積 (1−j₀ を直接求積) で床が構造的に消える

$$Z - f_x(K) = \int \rho(r)\,[1 - j_0(Kr)]\,4\pi r^2\,dr$$

を**差を取らずに直接求積**する (1−j₀ は小引数でテイラー、大引数で直接評価)。
被積分関数が非負・全項同符号なので桁落ちが構造的に無く、和の丸めは値に対する
**相対** 誤差 (~1e-15 級) に留まり、1/K² 増幅を受けない。
プロトタイプ = `scratchpad/deficit_proto.jl` (production 非接触):

- **大 s では素朴な差 (N − f_x) と相対 3e-16〜9e-15 で一致** (Z=6、s = 0.5–6) —
  同じ量を計算している
- 低 s では MB 構成との差がそのまま **MB 側の床の実測**になる: Z=6 default 格子で
  最小節点 1.47e-10 Å、1/K² で減衰 — 床は δ 形には無い
- s→0 で展開 a₀(M₂/3 − K²M₄/60) と整合 (最小節点で差 2.3e-10 Å、
  s とともに増える分は展開側の 3 項目打ち切り)
- ⚠ 2 階差分による床の可視化は失敗した — 真の曲率 h²f_e″ (~5e-05 Å) が
  床より大きく、隠してしまう。床は「MB − δ形」の直接差で見るのが正しい
- (dt/16 = 出荷実スケール 32 万点での確認は §3.5)

### 3.5 dt/16 (出荷実スケール) での確認 — 床の実測 1.5e-08 Å (Z=6)、δ 形は不変

同じ処方 (production 停止・`dirac_true_midpoint_v1`) を dt/16 (n_r = 323,400) で
解いて比較した:

| | default 格子 (n_r ≈ 2 万) | **dt/16 (n_r = 32.3 万)** |
|---|---|---|
| MB − δ形 @最小節点 s₁ [Å] | 1.47e-10 | **1.51e-08** |
| δ形 − 展開 @s₁ [Å] | 2.317e-10 | **2.317e-10 (同一)** |
| 大 s の naive との相対差 | 3e-16〜9e-15 | 5e-14〜6e-14 |

- **MB 構成の床は出荷実スケールで 100 倍悪化する** (逐次和の丸め蓄積は
  点数にほぼ比例)。Z=6 で 1.5e-08 Å — ε̂ から予測した 9.7e-09 と同オーダーで、
  §3.3 の fluct_ship の実測的裏づけになる (Au は ε̂ が 13 倍なので ~1e-07 級)
- **δ形 − 展開 の差は格子を 16 倍細かくしても小数点以下まで同一** —
  この差は求積誤差ではなく展開側の 3 項目 (M₆) 打ち切りであり、
  δ 形の求積誤差は格子に依らず相対 ~1e-13 以下に留まる
- 大 s の一致 (5e-14) は「δ 形と MB が同じ量を計算している」ことの確認

## 4. JSON 十進丸め — 有効数字 11 桁を推奨

全元素の最悪 (合成 = max(節点上の往復差, 丸めた節点でスプライン→中点誤差)):

| 有効数字 | f_x 合成 (clamped-left) | f_e 合成 (NAK on t、検査可能域) |
|---|---|---|
| 10 桁 | 節点丸めだけで 5.0e-09 = 0.55×B_repr | 6.97e-09 = 0.767× |
| **11 桁** | **1.48e-09 = 0.163×** | **3.03e-09 = 0.334×** |
| 12 桁 | 補間支配で 11 桁と不変 | 同左 |
| 17 桁 (往復厳密) | 往復差 0 (実装の検算) | 同左 |

- **11 桁で丸めの寄与は補間誤差の下に消える**。12 桁にしても変わらない
- 10 桁は f_x で予算の半分を丸めが食う (currentNAK なら 1.57× で超過)
- ⚠ s 軸は丸めの対象にしない — 格子は「s_i = 6i/7680」という式で定義し、
  JSON に書く場合も表示用とする (契約は式が正)

## 5. T_comp,e 凍結への含意 (指示書 §2-2 は「超えたら作者判断へ戻す」)

数値誤差 (格子 3.82e-08 + 停止 2.64e-08) と表現誤差 (補間 0.331× +
丸め 11 桁) は T_comp,e = 1e-7 Å (案 A) に収まる。**しかし §3.3 の
MB 構成ゆらぎ (最悪 1.41×B_num,e) が判明した以上、凍結は f_e 節点値の
構成法の決定とセットでなければならない**:

1. **δ 形求積を出荷生成に採用する** (推奨) — 床が構造的に消え、案 A が
   全項目で成立する。生成コードは `xray_form_factor` の変種 1 本
   (f_x の出荷値には触れない)。採用時は選択検査として
   「大 s で MB 構成と相対 ~1e-14 一致 / s→0 で モーメント展開と整合」を
   ゲート化する
2. 採用しない場合 — 対象から低 s 節点を外すか (契約の弱化)、
   T_comp,e を ~2e-7 Å へ緩めるか (6 元素の超過を収める) の二択になる

いずれも**作者判断**。f_x 側の clamped-left (§2.1) も同時に判断すること。

## 6. この測定が答えていないこと

- **中点でない内部点** (1/4・3/4 点など) は測っていない。3 次スプラインの
  区間内誤差は中点近傍で最大になるので中点が代表になる、という標準的性質に
  依拠している (X11 の 121 点測定では 1/4・1/2・3/4 点を使ったが、
  v1 副本が持つ検証点は中点だけ)
- f_e の検証点は s 上の中点であり、**t 上では区間の中点ではない** (低 t 側に
  寄った内部点)。t 区間中点での誤差は測っていない (h_t⁴ 論証で覆う)
- ~~Tm 69 / Yb 70 (v1 副本なし)~~ — **08-15 に埋めた** (冒頭の追記)
- ε̂ はスプライン差からの間接推定 (係数増幅込みで真の単点床の ~2 倍)。
  δ 形求積が採用されれば低 s の直接測定が可能になり、この推定自体が不要になる
- 丸めの桁数は**科学記法の有効数字**で測った。固定小数点で書く場合は別の測定が要る
