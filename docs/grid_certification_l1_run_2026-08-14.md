## 3. ⚠ 判定規則の欠陥 1 件 — H の分類順序 (凍結後に発見、規則は変えていない)

(‖Δρ₃‖₁ ≤ 1e-9) より先に評価する**順序で書かれ、事前登録 §3.3 の表も同順だった。
H は D₂ = 1.5e-14 / D₃ = 7.4e-14 と床の 4 桁下 (明白な低信号) なのに、

  (§3.2「低信号なら q₂₃ は検査不能」) からすれば low_signal を先に評価すべきだった
