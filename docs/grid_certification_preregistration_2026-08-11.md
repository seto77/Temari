## 1. 認証する命題

> 処方 = 完全 Dirac SCF + 厳密交換 (KLI)、数値 backend = `dirac_true_midpoint_v1`、
> 動径格子 = 対数メッシュ r ∈ [1e-7, 60] a₀ / **dt = GRID_DT/16 = 6.25e-05**
> (n_r = 323,400) で解いた中性原子の f_x(s) は、**同じ処方の格子極限**との差が
> s ∈ [0, 6] Å⁻¹ の評価点上で **B_grid = 6×10⁻⁸ 電子**以下である。

⚠ **「格子極限」であって「真値」ではない**。モデル誤差 (KLI vs DHF、~2.6×10⁻³ 電子)
は 4 桁大きく、**別の層**である (計画書 §3・§4.14)。混ぜて書かない。

採用格子は**作者決定 (2026-08-11)**。dt/8 (Au で B_grid の 0.27) ではなく
**1 段細かい dt/16** を選んだ理由は、測ったのが 4/86 元素であり、未測定元素への
余裕を取りたいから。

## 3. 凍結する判定式

水準 L2 = dt/4、L3 = dt/8、**L4 = dt/16**、(L5 = dt/32)。tight 解を g(L) と書き
δ_k = g(L_k) − g(L_{k+1}) とする。**すべて点ごとに**計算し、最後に最大を取る。

⚠⚠ **ある点の比を別の点の最大差に当てない**。`grid_study` が実際にそれをやって
いた (codex 指摘)。

### 3.1 上限

| 条件 | 式 | 由来 |
|---|---|---|
| L5 を測っていない | E(L4) ≤ \|δ_3\| · q\*/(1−q\*) = **\|δ_3\|** | Σ_{k≥4}\|δ_k\| ≤ \|δ_3\|(q\*+q\*²+…) |
| L5 を測った | E(L4) ≤ \|δ_4\| · 1/(1−q\*) = **2\|δ_4\|** | Σ_{k≥4}\|δ_k\| ≤ \|δ_4\|(1+q\*+…) |

### 3.2 2 つの q — **同じ数にしない**

| 記号 | 値 | 役割 |
|---|---|---|
| `Q_GATE` | **0.35** | **観測ゲート**。q = \|δ_last\|/\|δ_prev\| がこれ以下かつ同符号なら「縮んでいる」 |
| `Q_TAIL` | **0.5** | **尾の外挿**。観測ゲートより保守的にする |

⚠⚠ 1 段 q ≤ 0.35 を観測しても、**その先の全段で続く保証は無い** (codex)。
観測と仮定を別の数にすることで、その距離を明示する。理想値は p=2 の 0.25。

### 3.3 点の分類

| 分類 | 条件 |
|---|---|
| `ok` | \|δ_prev\| > 床、同符号、q ≤ 0.35 |
| `low_signal` | \|δ_prev\| ≤ 床 かつ (\|δ_last\| ≤ 床 または \|δ_last\| ≤ \|δ_prev\|) |
| `violating` | それ以外 (符号反転 / q > 0.35 / 雑音から**増えている**) |

床 = **その元素で実測した U の 1/2** (U = 採用段の \|f_prod − f_tight\|)。
⚠ 固定値にしない — 軽元素では δ 自体が停止ノイズと同程度まで小さくなるので、
固定床だと**ほぼ全点が形式的に未解決**になり認証が空回りする (codex)。
⚠ `low_signal` は不合格ではない。上限の値そのものは有効なので判定には入る。

### 3.4 合否

元素が**合格**なのは、次の全部が成り立つとき:

1. 出荷 7681 節点 (s=0 を除く) の max 上限 ≤ B_grid = 6e-08
2. 中点 7680 点の max 上限 ≤ B_grid
3. 採用段の **U ≤ B_scf = 9.09e-09** (停止の判定。格子とは別勘定)
4. `violating` 点が **0**
5. 全水準の SCF が収束

⚠ **停止分を B_grid から払わない。**格子と停止は別の配分であり、
「観測した合成差を B_grid に当てる」のは**保守的ですらない** (相殺しうる。codex)。

## 6. 結果をどう書くか — **言い換えの規約**

⚠⚠ 次の表現は**使わない**:

- 「格子極限との差が 6×10⁻⁸ 以下であることを**証明した**」
- 「厳密上界」「数学的保証」
- 「連続 s ∈ [0,6] 全域を認証した」

使う表現 (codex の起草をそのまま採る):

> Z = 1…86 の全元素について、出荷 7681 節点上で**事前登録した多段収束試験**を
> 実施した。各離散化段の解析解に対する 2 次収束、全元素の dt/4–dt/16 における
> 点別収縮、および層別標本・異常元素の dt/32 検証に基づき、将来段の収縮率を
> q ≤ 0.5 とする**保守的な尾の評価のもとで**、dt/16 の推定残差が
> B_grid = 6×10⁻⁸ 電子以下であることを確認した。

短く呼ぶなら **「全 Z の事前登録済み経験的数値認証」**。必ず併記する:

- **条件つきの尾の評価**であること
- 主保証は**離散 7681 節点**であること
- 中点 7680 点は**独立なピーク探索**であること
- 対象は**規格化後の f_x** であること
- SCF 停止・端点切断・表現誤差は**別試験**であること

| 範囲外 | なぜ |
|---|---|
| s > 6 Å⁻¹ | 評価点の外。求積は s ≈ 24 まで機械精度だが (計画書 §4.5)、格子認証はしていない |
| **節点と節点の間** | 主保証は離散点。中点は探索であって連続保証ではない。連続域は**表現誤差 B_repr** の仕事 |

## 9. 診断量 (合否には使わないが必ず記録する)

各水準について: `converged` / `n_r` / 秒 / 規格化前の f_x(0) と補正量 /
M₀・M₂・M₄ / 動径分位点 r₅₀・r₉₀・r₉₉ / (n,l) ごとの占有加重平均固有値 /
KLI ポテンシャルの絶対最大 / z_asym。
水準間では**入れ子格子を使った点ごとの密度差**も (dyadic 細分なので
細かい格子の奇数番目が粗い格子と**ビット同一**になる。⚠ 点数は 2n−1
ぴったりにはならないので重なる範囲だけ比べる)。

⚠ **Dirac の節数を n−l−1 と決め打ちで検査しない** (codex)。κ>0 では大・小成分の
節則が非相対論の表記と一致しないことがある。shooting に**要求した**節数を
記録するに留める。
